## 환경을 두 층으로 나누는 이유

### 층 A: 교육용 CPU 환경

이 저장소의 네 Python 스크립트는 NumPy와 Matplotlib만으로 핵심 원리를 보여 줍니다. CUDA, C++ 컴파일러, COLMAP 없이도 실행됩니다.

### 층 B: 실무용 GPU 환경

실제 장면은 수십만~수백만 Gaussian을 매 프레임 투영하고 정렬해야 합니다. CUDA 기반의 tile rasterizer가 필요하므로 Nerfstudio/gsplat 또는 Graphdeco 공식 구현을 별도 환경에 설치합니다.

권장 기준:

- 운영체제: Ubuntu 22.04/24.04가 CUDA 확장 빌드에 가장 수월함
- GPU: NVIDIA CUDA GPU
- VRAM: 작은 장면은 약 8 GB부터 시도 가능, 고화질 장면은 12~24 GB 이상 권장
- 저장공간: 원본 이미지, COLMAP 결과, 체크포인트를 합쳐 장면당 수 GB 고려

원 공식 구현은 논문 수준 품질 학습에 CUDA Compute Capability 7.0 이상과 24 GB VRAM을 안내합니다. Nerfstudio의 기본 `splatfacto` 문서는 대략 6 GB, `splatfacto-big`은 약 12 GB 메모리 구성을 제시하지만 장면과 해상도에 따라 달라집니다.

## 환경 확인

```powershell
python --version
python -c "import numpy; print(numpy.__version__)"
```

명령 해설:

- `python --version`: 현재 Python 버전을 출력합니다.
- `python -c`: 뒤따르는 문자열을 짧은 Python 프로그램으로 실행합니다.
- `import numpy`: 수치 계산 패키지를 불러옵니다.
- `numpy.__version__`: 설치된 NumPy 버전 문자열입니다.
