# 8장. 용어와 단축어 사전

## 핵심 기술

| 표기 | 전체 이름 | 쉬운 뜻 |
|---|---|---|
| 3DGS | 3D Gaussian Splatting | 3D 타원형 점들을 화면에 뿌려 장면을 그리는 방법 |
| GS | Gaussian Splatting | Gaussian 기반 splatting 전체를 가리키는 약칭 |
| NeRF | Neural Radiance Fields | 신경망으로 위치·방향별 밀도와 색을 나타내는 장면 표현 |
| NVS | Novel View Synthesis | 보지 않은 새 카메라 시점의 영상 생성 |
| RF | Radiance Field | 공간의 빛과 밀도를 나타내는 장 |
| SfM | Structure from Motion | 여러 사진에서 카메라와 3D 구조 동시 복원 |
| MVS | Multi-View Stereo | 여러 시점으로 조밀한 깊이·표면 복원 |
| SLAM | Simultaneous Localization and Mapping | 위치 추정과 지도 생성을 동시에 수행 |
| SH | Spherical Harmonics | 방향에 따른 색 변화를 나타내는 기저함수 |
| PLY | Polygon File Format | 점·면 속성을 담는 3D 파일 형식 |
| glTF | GL Transmission Format | 실시간 3D 자산 전달 표준 |
| GLB | binary glTF | glTF JSON과 buffer를 묶은 바이너리 파일 |
| SPZ | 압축 Gaussian splat 형식 | 전송·저장을 줄이기 위한 압축 표현 |
| LOD | Level of Detail | 거리·성능에 맞춰 세부 수준 변경 |

## 수학·카메라

| 표기 | 전체 이름 | 뜻 |
|---|---|---|
| `μ` | mu / mean | Gaussian 중심 |
| `σ` | sigma / standard deviation | 1D 퍼짐 정도 |
| `Σ` | covariance matrix | 여러 축의 크기·상관·방향 |
| `R` | rotation matrix | 회전 행렬 |
| `t` | translation vector | 이동 벡터 |
| `K` | camera intrinsic matrix | 초점거리와 주점을 담는 행렬 |
| `J` | Jacobian matrix | 입력 변화에 대한 출력 변화의 미분 |
| `q` | quaternion | 4개 수로 3D 회전을 표현 |
| FoV/FOV | Field of View | 카메라 시야각 |
| pose | position + orientation | 카메라 위치와 방향 |
| extrinsic | external camera parameters | 세계↔카메라 변환 |
| intrinsic | internal camera parameters | 초점거리·주점·skew |

## 렌더링

| 용어 | 뜻 |
|---|---|
| splat | 한 primitive의 영향을 화면 픽셀들에 퍼뜨리는 연산 |
| rasterization | 기하 primitive를 픽셀 값으로 변환 |
| alpha | 불투명도 또는 coverage |
| compositing | 여러 색과 alpha를 순서대로 합성 |
| transmittance | 앞의 물질을 통과해 남은 빛의 비율 |
| culling | 보이지 않거나 기여가 작은 primitive 제거 |
| tile | 화면을 나눈 작은 사각 블록 |
| aliasing | sampling 부족으로 생기는 계단·깜빡임 |
| popping | 이동 중 요소가 갑자기 나타나거나 사라지는 현상 |
| floater | 실제 표면과 떨어져 떠 있는 잘못된 Gaussian |

## 학습·평가

| 표기 | 전체 이름 | 방향 |
|---|---|---|
| GD | Gradient Descent | gradient 반대 방향으로 loss 감소 |
| SGD | Stochastic Gradient Descent | 일부 표본으로 gradient 추정 |
| Adam | Adaptive Moment Estimation | 모멘텀·적응 학습률 optimizer |
| L1 | Mean Absolute Error 계열 | 낮을수록 좋음 |
| PSNR | Peak Signal-to-Noise Ratio | 높을수록 좋음 |
| SSIM | Structural Similarity Index Measure | 높을수록 좋음 |
| LPIPS | Learned Perceptual Image Patch Similarity | 낮을수록 좋음 |
| GT | Ground Truth | 비교 기준 정답 |
| VRAM | Video Random Access Memory | GPU 메모리 |
| FPS | Frames Per Second | 초당 프레임 수 |
