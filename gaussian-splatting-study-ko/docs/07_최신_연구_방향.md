# 7장. 2023~2026 최신 연구와 기술 방향

기준일: 2026-08-09. 논문의 상태는 published, accepted, preprint, withdrawn를 구분해야 합니다. 아래는 학회·저자 프로젝트·공식 저장소를 우선한 학습 지도이며, 수치는 각 논문의 평가 설정 안에서만 해석해야 합니다.

## 1단계: 기반 형성 — 2023

### 3D Gaussian Splatting for Real-Time Radiance Field Rendering

- Kerbl 등, ACM Transactions on Graphics / SIGGRAPH 2023
- 핵심: anisotropic 3D Gaussian, adaptive density control, visibility-aware tile rasterizer
- 의미: radiance field를 명시적 primitive로 바꾸며 고품질 실시간 렌더링을 현실화
- 학습 링크: [논문](https://doi.org/10.1145/3592433), [공식 코드](https://github.com/graphdeco-inria/gaussian-splatting)

먼저 이 논문의 representation, rasterization, optimization을 구분해서 읽어야 후속 논문의 개선점이 보입니다.

## 2단계: 화질·기하·aliasing 개선 — 2024

### Mip-Splatting

- CVPR 2024
- 문제: 학습 시점과 다른 해상도·거리에서 aliasing과 dilation 발생
- 방향: 3D smoothing filter와 2D Mip filter로 scale 변화에 강한 렌더링
- [CVF 논문](https://openaccess.thecvf.com/content/CVPR2024/html/Yu_Mip-Splatting_Alias-free_3D_Gaussian_Splatting_CVPR_2024_paper.html)

### 2D Gaussian Splatting

- SIGGRAPH 2024 계열
- 문제: 부피형 3D Gaussian이 실제 표면 기하와 어긋날 수 있음
- 방향: oriented 2D disk/surfel을 사용해 surface reconstruction과 view synthesis를 함께 개선
- [프로젝트](https://surfsplatting.github.io/)

### SuGaR

- CVPR 2024
- 문제: 3DGS에서 편집 가능한 mesh를 얻기 어려움
- 방향: Gaussian을 표면에 정렬하고 mesh를 추출해 Gaussian과 mesh 편집 workflow 연결
- [CVF 논문](https://openaccess.thecvf.com/content/CVPR2024/html/Guédon_SuGaR_Surface-Aligned_Gaussian_Splatting_for_Efficient_3D_Mesh_Reconstruction_and_CVPR_2024_paper.html)

### Scaffold-GS와 계층형 3DGS

- sparse anchor/feature에서 필요한 Gaussian을 생성하거나, 대규모 장면을 계층적으로 표현
- 방향: Gaussian을 모두 독립 저장하는 비용을 줄이고 LOD·대규모 rendering으로 확장
- [Scaffold-GS CVF 논문](https://openaccess.thecvf.com/content/CVPR2024/html/Lu_Scaffold-GS_Structured_3D_Gaussians_for_View-Adaptive_Rendering_CVPR_2024_paper.html)
- [Hierarchical 3D Gaussians 공식 코드](https://github.com/graphdeco-inria/hierarchical-3d-gaussians)

## 3단계: 동적 장면·SLAM·생성 — 2024~2025

### 4D Gaussian Splatting

- 시간 축을 추가해 Gaussian 위치·모양·외관의 변화를 모델링
- 적용: 사람, 공연, 스포츠, volumetric video
- 핵심 난제: 장기 추적, topology 변화, 메모리, 시간 일관성
- [CVF 논문](https://openaccess.thecvf.com/content/CVPR2024/html/Wu_4D_Gaussian_Splatting_for_Real-Time_Dynamic_Scene_Rendering_CVPR_2024_paper.html)

### Gaussian-SLAM / GS-SLAM

- offline COLMAP 자세를 전제로 하지 않고 tracking과 mapping을 함께 수행
- 적용: 로봇, AR, 실시간 공간 지도
- 난제: drift, loop closure, dynamic object, geometry accuracy
- [Gaussian Splatting SLAM](https://arxiv.org/abs/2312.06741)
- [GS-SLAM](https://arxiv.org/abs/2311.11700)

### Feed-forward generalizable reconstruction

장면마다 수만 step을 최적화하는 대신, 학습된 네트워크가 소수의 입력 이미지에서 Gaussian을 한 번에 예측하는 흐름입니다.

- sparse-view 입력에서 빠른 재구성
- 데이터 prior를 이용하지만 domain shift에 취약
- 2025년 Generative Densification은 feed-forward 모델의 Gaussian 부족으로 인한 고주파 세부 손실을 학습형 densification으로 다룸
- [CVPR 2025 Generative Densification](https://openaccess.thecvf.com/content/CVPR2025/html/Nam_Generative_Densification_Learning_to_Densify_Gaussians_for_High-Fidelity_Generalizable_3D_CVPR_2025_paper.html)

## 4단계: 단일 이미지와 즉시 재구성 — 2025~2026

### Apple SHARP

- 한 장의 이미지에서 metric 3D Gaussian representation을 한 번의 feed-forward pass로 예측
- 표준 GPU에서 1초 미만의 nearby-view synthesis를 목표
- 의미: 장면별 최적화에서 foundation-like regression으로 이동
- 한계: 입력에 보이지 않은 영역과 큰 시점 이동은 여전히 본질적으로 모호
- [Apple 프로젝트](https://apple.github.io/ml-sharp/), [논문](https://arxiv.org/abs/2512.10685)

### Immediate / on-the-fly reconstruction

- unordered 또는 unposed image stream에서도 전역 일관성을 빠르게 회복하려는 방향
- 촬영 종료 후 긴 batch optimization을 기다리지 않고 획득과 재구성을 겹침
- [Graphdeco i3dgs 공식 코드](https://github.com/graphdeco-inria/i3dgs)
- [Graphdeco on-the-fly NVS](https://github.com/graphdeco-inria/on-the-fly-nvs)

## 5단계: 물리와 편집 가능한 장면 — 2025~2026

### inverse rendering과 relighting

기존 SH는 촬영 당시 조명과 재질을 얽어서 저장합니다. 최신 방향은 geometry, material, direct/indirect illumination, subsurface scattering을 분리해 조명을 바꿀 수 있게 합니다.

- [ICLR 2026 Radiometrically Consistent Gaussian Surfels](https://openreview.net/forum?id=lKqE7UuMvp)
- [ICLR 2026 SSD-GS](https://openreview.net/forum?id=7m2Dqz9g05)

### physics-aware Gaussian

Gaussian을 particle처럼 다뤄 deformation, fracture, contact simulation과 시각화를 연결합니다. 그래픽 자산이 수동적 재생 대상에서 simulation state로 확장되는 흐름입니다.

- [ICLR 2026 Fracture-GS](https://openreview.net/forum?id=zcAwK50ft0)
- [Real2Sim for autonomous driving](https://arxiv.org/abs/2605.13591)

## 6단계: kernel 자체의 재검토 — 2026

Gaussian은 편리하지만 무한 지지 영역, 투영 근사, 정렬 문제를 가집니다. 2026년에는 splatting을 더 일반적인 함수·inverse problem 관점에서 재정의하거나 다른 kernel로 확장하는 연구가 등장했습니다.

- [ICLR 2026 Universal Beta Splatting](https://openreview.net/forum?id=51JEkjP0gF): Gaussian을 N차원 anisotropic Beta kernel로 일반화
- [ICLR 2026 Splat Regression Models](https://openreview.net/forum?id=rubeJmT1XM): model·inverse problem·optimization을 분리하는 통합 이론
- [Gaussian Point Splatting](https://doi.org/10.1145/3811272): 기존 splatting의 sampling과 reconstruction 문제를 더 엄밀히 다룸

## 7단계: 표준 자산과 산업 배포 — 2026

Khronos의 `KHR_gaussian_splatting` release candidate는 3DGS를 연구용 PLY 관행에서 glTF 기반 상호운용 자산으로 옮기는 중요한 신호입니다.

예상 방향:

- 기본 Gaussian 속성의 공통 schema
- SPZ/L-GSC 등 압축 extension
- glTF viewer, geospatial engine, XR runtime 간 교환
- LOD, streaming, semantic metadata 결합
- OpenUSD 등 다른 3D 표준과 정렬

[Khronos 공식 발표](https://www.khronos.org/news/press/gltf-gaussian-splatting-press-release)

## 기술 방향을 한 장으로 정리

| 병목 | 연구 방향 | 실무 효과 |
|---|---|---|
| 장면별 긴 최적화 | feed-forward, on-the-fly | 즉시 캡처·미리보기 |
| 많은 메모리 | pruning, quantization, anchors, hierarchy | 모바일·웹 배포 |
| 정적 장면 | 4D, deformation, streaming | 공연·스포츠·로봇 |
| 표면 부정확 | 2D surfel, regularization, mesh hybrid | 편집·충돌·측정 |
| 조명 고정 | inverse rendering, relighting | VFX·전자상거래 |
| pose 필요 | SLAM, pose-free reconstruction | 현장 실시간 지도 |
| 포맷 파편화 | glTF/OpenUSD 표준화 | 도구 간 교환 |
| Gaussian 한계 | beta/point/kernel 이론 | 더 정확한 rasterization |

## 다음 연구 주제를 고르는 질문

1. 입력은 다중 사진, 영상, 단일 이미지, LiDAR 중 무엇인가?
2. 출력은 보기 좋은 새 시점, 정확한 표면, 편집 가능한 자산 중 무엇인가?
3. offline 품질과 online 속도 중 무엇이 우선인가?
4. 장면은 정적인가, 움직이는가?
5. 목표 장치는 server GPU, desktop, mobile, browser, XR 중 무엇인가?
6. scale·좌표·semantic label이 필요한가?

이 답에 따라 논문을 선택해야 하며, 최신 논문이라는 이유만으로 모든 파이프라인에 더 좋은 것은 아닙니다.
