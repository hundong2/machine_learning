# 2장. Gaussian Splatting을 위한 수학

## 1. 1차원 Gaussian

평균 `μ`와 표준편차 `σ`를 가진 정규분포의 모양은 다음과 같습니다.

```text
G(x) = exp(-(x - μ)² / (2σ²))
```

- `μ`(mu, 뮤): 봉우리의 중심
- `σ`(sigma, 시그마): 퍼짐의 크기
- `exp`: 자연상수 `e`의 지수함수

확률밀도의 정규화 상수는 생략했습니다. splatting에서는 주로 상대적인 커널 모양과 alpha가 중요하기 때문입니다.

## 2. 2차원 anisotropic Gaussian

3D Gaussian이 카메라 화면에 투영되면 타원형 2D Gaussian이 됩니다.

```text
G(p) = exp(-1/2 · (p-μ)ᵀ Σ⁻¹ (p-μ))
```

- `p`: 현재 픽셀의 2D 좌표
- `μ`: 화면에 투영된 중심
- `Σ`(Sigma): 2×2 covariance matrix, 타원의 크기와 방향
- `ᵀ`: transpose, 행과 열 바꿈
- `⁻¹`: inverse, 역행렬
- anisotropic: 방향마다 퍼짐이 다른 이방성

Mahalanobis distance `(p-μ)ᵀΣ⁻¹(p-μ)`가 작으면 중심에 가깝고, 크면 타원 바깥입니다.

## 3. 3D Gaussian 파라미터

하나의 3D Gaussian은 보통 다음 값을 가집니다.

| 파라미터 | shape | 의미 |
|---|---|---|
| 중심 `μ` | `(3,)` | 세계 좌표 `(x,y,z)` |
| scale `s` | `(3,)` | 세 주축의 크기 |
| rotation `q` | `(4,)` | quaternion 회전 |
| opacity `α` | `(1,)` | 불투명도 |
| SH coefficients | 여러 개 | 시점 의존 색 |

회전행렬 `R`과 대각 scale 행렬 `S`로 3D covariance를 만듭니다.

```text
Σ₃D = R S Sᵀ Rᵀ
```

실제 구현은 scale을 양수로 유지하기 위해 지수함수를, quaternion 길이를 1로 유지하기 위해 정규화를, opacity를 0~1로 유지하기 위해 sigmoid를 사용하는 경우가 많습니다.

## 4. 카메라 좌표

세계 점 `X_world`를 카메라 좌표로 바꿉니다.

```text
X_camera = R_cw X_world + t_cw
```

`cw`는 camera-from-world, 즉 세계 좌표를 카메라 좌표로 변환한다는 표기입니다. 문헌과 라이브러리에 따라 반대 방향 행렬을 저장하므로 convention을 반드시 확인해야 합니다.

카메라 좌표 `(X,Y,Z)`를 픽셀로 투영합니다.

```text
u = f_x X/Z + c_x
v = f_y Y/Z + c_y
```

- `f_x`, `f_y`: 초점거리의 픽셀 단위 값
- `c_x`, `c_y`: principal point, 주점
- `u`, `v`: 영상의 가로·세로 좌표
- `Z`: 카메라 앞쪽 깊이

이를 camera intrinsic matrix `K`로 묶습니다.

```text
K = [[f_x, 0,   c_x],
     [0,   f_y, c_y],
     [0,   0,   1  ]]
```

## 5. covariance의 3D→2D 투영

원근 투영은 비선형이므로 중심 주변에서 Jacobian `J`로 1차 근사합니다.

```text
Σ₂D ≈ J R_cw Σ₃D R_cwᵀ Jᵀ
```

Jacobian은 입력 좌표가 조금 변할 때 출력 픽셀이 얼마나 변하는지를 모은 미분 행렬입니다. 이 근사가 3D 타원을 화면의 2D 타원으로 바꾸는 핵심입니다.

## 6. front-to-back alpha compositing

카메라에 가까운 Gaussian부터 색을 누적합니다.

```text
C = Σᵢ Tᵢ αᵢ cᵢ
Tᵢ = Πⱼ<ᵢ (1 - αⱼ)
```

- `cᵢ`: i번째 Gaussian의 색
- `αᵢ`: 해당 픽셀에서의 유효 alpha
- `Tᵢ`: 앞의 Gaussian들을 통과한 transmittance

코드에서는 다음 두 줄로 이해할 수 있습니다.

```python
image += transmittance * alpha * color
transmittance *= 1.0 - alpha
```

정렬이 틀리면 반투명 색 혼합 순서가 달라져 popping과 경계 artifact가 생깁니다.

## 7. 학습에 필요한 미분

렌더 이미지 `I_render`와 실제 사진 `I_gt`의 차이를 loss로 계산합니다.

```text
L = (1-λ) L1(I_render, I_gt) + λ D-SSIM(I_render, I_gt)
```

- `L1`: 픽셀 절대 오차
- `SSIM`: Structural Similarity Index Measure, 구조적 유사도
- `D-SSIM`: 보통 `(1-SSIM)/2` 형태의 차이 손실
- `λ`(lambda): 두 손실의 비중

미분 가능한 rasterizer가 loss의 gradient를 Gaussian의 위치, scale, rotation, opacity, SH 계수까지 전달하고 optimizer가 파라미터를 갱신합니다.
