# 4장. 직접 구현 실습

이 장의 목적은 상용 3DGS를 재현하는 것이 아니라, 고속 CUDA 코드가 감추는 계산을 작은 NumPy 프로그램으로 눈에 보이게 만드는 것입니다.

## 실습 1. 1D Gaussian

```powershell
python scripts/01_gaussian_1d.py
```

관찰할 것:

- `mu`를 바꾸면 중심이 이동합니다.
- `sigma`를 키우면 곡선이 넓어집니다.
- `exp` 안의 음수 제곱 때문에 중심에서 멀수록 값이 빠르게 줄어듭니다.

결과: `outputs/01_gaussian_1d.png`

## 실습 2. 2D anisotropic Gaussian

```powershell
python scripts/02_gaussian_2d.py
```

관찰할 것:

- `scale_x`, `scale_y`가 타원의 두 축 길이를 정합니다.
- rotation matrix가 covariance의 방향을 바꿉니다.
- `(H,W,2)` 좌표 배열과 `(2,)` 중심 벡터의 broadcasting을 확인합니다.

결과: `outputs/02_gaussian_2d.png`

## 실습 3. pinhole camera projection

```powershell
python scripts/03_camera_projection.py
```

관찰할 것:

- 같은 `(X,Y)`라도 `Z`가 커지면 화면 중심에 가까워집니다.
- focal length가 커지면 물체가 확대됩니다.
- 카메라 뒤 `Z <= 0`인 점은 투영 대상이 아닙니다.

결과: `outputs/03_camera_projection.png`

## 실습 4. 교육용 mini splat renderer

```powershell
python scripts/04_mini_splat_renderer.py
```

이 코드는 다음 순서를 그대로 구현합니다.

1. 세계 좌표 Gaussian을 pinhole camera로 투영
2. 깊이와 초점거리를 이용해 화면 scale 근사
3. 가까운 순서로 정렬
4. 각 Gaussian의 2D weight 계산
5. opacity와 weight로 pixel alpha 계산
6. front-to-back compositing
7. RGB 이미지와 alpha 이미지 저장

결과:

```text
outputs/04_mini_splat_rgb.png
outputs/04_mini_splat_alpha.png
```

## 교육용 구현에서 일부러 생략한 것

| 생략 | 실무 구현 |
|---|---|
| 3D covariance의 정확한 Jacobian 투영 | `Σ₂D = J R Σ₃D Rᵀ Jᵀ` |
| tile binning | CUDA tile 기반 교차 검사 |
| SH 색 | viewing direction에 따른 SH 평가 |
| gradient | PyTorch/CUDA backward kernel |
| densification | gradient 통계 기반 clone/split/prune |
| 수백만 Gaussian | packed storage와 병렬 정렬 |

교육용 코드를 이해한 뒤 `gsplat.rasterization()` API의 `means`, `quats`, `scales`, `opacities`, `colors`, `viewmats`, `Ks`가 각각 어느 단계에 들어가는지 연결해 보세요.

## 연습 문제

1. Gaussian 하나의 `z`를 2배로 바꾸고 화면 크기 변화를 설명하세요.
2. 두 Gaussian의 깊이를 서로 바꿔 alpha 합성 결과가 달라지는지 확인하세요.
3. `background_color`를 흰색으로 바꾸세요.
4. `scale_x != scale_y`와 회전을 추가해 타원 splat으로 확장하세요.
5. 렌더 결과를 목표 이미지와 비교하는 L1 loss를 구현하세요.

## 정답 확인 기준

- 코드가 실행되는 것보다 shape를 말할 수 있는지가 중요합니다.
- 각 단계에서 값의 단위가 world unit인지 pixel인지 구분해야 합니다.
- RGB는 `(H,W,3)`, alpha/transmittance는 `(H,W,1)`로 유지하면 broadcasting이 명확합니다.
