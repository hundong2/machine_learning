# 3장. 3D Gaussian Splatting 핵심 원리

## 1. 한 문장 정의

3DGS는 장면을 수많은 반투명 3D 타원체로 명시적으로 저장하고, 카메라 화면에 빠르게 투영·합성하면서 실제 사진과 같아지도록 각 타원체의 파라미터를 학습하는 방법입니다.

## 2. NeRF와 무엇이 다른가?

| 항목 | 전형적 NeRF | 3DGS |
|---|---|---|
| 표현 | 신경망 안의 implicit field | Gaussian 목록인 explicit field |
| 렌더링 | ray 위 다수 점을 샘플링 | Gaussian을 화면에 rasterize |
| 장점 | 연속적 표현, 연구 생태계 | 빠른 학습·실시간 렌더링·직접 편집 |
| 약점 | 렌더링 비용 | 메모리·정렬·기하 정확도·편집 일관성 |

`implicit`는 좌표를 넣어야 값이 나오는 숨은 함수 표현이고, `explicit`는 위치·크기 등을 직접 저장하는 표현입니다.

## 3. 입력부터 결과까지

```text
다중 시점 사진
  → SfM으로 카메라 자세와 sparse point cloud 추정
  → 점마다 초기 Gaussian 생성
  → 임의 카메라에서 렌더링
  → 실제 사진과 loss 계산
  → gradient로 Gaussian 파라미터 갱신
  → 필요한 곳 clone/split, 불필요한 곳 prune
  → 반복 후 PLY와 viewer용 자산 출력
```

- `SfM`: Structure from Motion, 여러 사진의 대응점을 이용해 카메라 움직임과 3D 구조를 함께 추정
- `sparse point cloud`: 모든 표면을 채우지 않은 성긴 3D 점 집합
- `clone`: 작은 Gaussian을 복제해 표현 밀도 증가
- `split`: 큰 Gaussian을 더 작은 여러 Gaussian으로 분할
- `prune`: 영향이 작은 Gaussian 제거

## 4. 왜 구면조화함수인가?

표면 색은 보는 방향에 따라 달라질 수 있습니다. 원 논문은 Spherical Harmonics(SH, 구면조화함수) 계수로 방향에 따른 색 변화를 저비용으로 표현합니다.

- SH degree 0: 방향과 무관한 한 가지 색
- degree가 높음: 반짝임과 시점 의존 변화를 더 잘 표현
- 비용: 계수 수, 메모리, 계산량 증가

SH는 실제 재질과 조명을 분리하지 않습니다. 촬영 당시 조명 효과를 시점 함수로 근사한 것이므로 자유로운 relighting에는 inverse rendering 계열 방법이 필요합니다.

## 5. 타일 기반 rasterization

모든 픽셀이 모든 Gaussian을 검사하면 비용이 너무 큽니다. 고속 구현은 화면을 작은 tile로 나눕니다.

1. Gaussian을 화면에 투영해 영향을 주는 tile을 찾습니다.
2. tile-Gaussian 쌍을 만듭니다.
3. tile 안에서 깊이 순으로 정렬합니다.
4. 각 픽셀이 관련 Gaussian만 front-to-back으로 합성합니다.
5. transmittance가 거의 0이면 뒤의 Gaussian 계산을 일찍 끝냅니다.

`gsplat`의 공식 문서도 투영, tile 교차, 정렬, alpha compositing으로 rasterization 단계를 설명합니다.

## 6. adaptive density control

처음의 SfM 점만으로는 얇은 구조와 세부 무늬를 표현하기 어렵습니다. 학습 중 screen-space gradient와 scale 등을 보고 Gaussian 수를 바꿉니다.

- 세부가 부족한 영역: clone 또는 split
- 지나치게 큰 Gaussian: split
- opacity가 매우 낮은 Gaussian: prune
- 너무 커져 장면을 가리는 Gaussian: reset/prune 정책 적용

이 과정은 품질을 높이지만 Gaussian 수와 VRAM을 급격히 늘릴 수 있으므로 densification 종료 시점, 임계값, 최대 개수를 운영 지표로 관리해야 합니다.

## 7. 학습 가능한 값과 제약

| 실제 값 | 내부 파라미터화 예 | 이유 |
|---|---|---|
| scale > 0 | `exp(raw_scale)` | 음수 크기 방지 |
| opacity ∈ (0,1) | `sigmoid(raw_opacity)` | 합성 안정성 |
| unit quaternion | `q / ||q||` | 유효 회전 유지 |
| RGB/view color | SH coefficients | 시점 의존 외관 |

## 8. 실패를 원인별로 읽기

| 현상 | 가능한 원인 | 우선 조치 |
|---|---|---|
| floaters | 잘못된 대응점, 배경, 과도한 densification | 마스크, 이미지 정리, prune 강화 |
| needle/spike | 비정상적으로 긴 anisotropic scale | scale regularization |
| 빈 구멍 | 시점 부족, SfM 누락 | 촬영 중첩 증가 |
| 흐림 | 초점·모션 블러, 낮은 해상도 | 입력 선별, 셔터 속도 개선 |
| 색 깜빡임 | 자동 노출/화이트밸런스 변화 | 수동 노출, exposure compensation |
| 시점 이동 시 popping | 근사 정렬·aliasing | antialiasing, 정렬 개선 계열 사용 |

## 9. 원 논문의 세 기여

1. 고품질 장면을 위한 anisotropic 3D Gaussian 표현
2. 세부를 자동으로 늘리고 줄이는 interleaved optimization/density control
3. 실시간 렌더링을 위한 visibility-aware tile rasterizer

이후 연구는 거의 모두 이 세 축 중 하나 이상을 개선하거나, 동적·생성·SLAM·재조명 같은 새 문제로 확장합니다.
