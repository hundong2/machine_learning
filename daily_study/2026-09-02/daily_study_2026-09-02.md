# [2026-09-02] 오늘 학습: 스칼라·벡터 & 지도·비지도·강화학습

> **오늘의 핵심 문장:** 인공지능은 현실의 대상을 **벡터**로 바꾸고, 정답·숨은 구조·보상 중 어떤 **학습 신호**를 받느냐에 따라 서로 다른 방식으로 규칙을 개선한다.

오늘은 주성분분석(PCA, Principal Component Analysis: 데이터의 분산이 큰 방향을 찾아 적은 축으로 압축하는 기법)까지 가는 수학 여정의 첫 단추인 **스칼라와 벡터**를 배운다. 동시에 AI 전체 지도를 먼저 펼쳐, **지도학습·비지도학습·강화학습**이 무엇을 보고 무엇을 배우는지 구분한다. 다음 학습의 `행렬과 선형 변환 → 단층 퍼셉트론`을 이해하기 위한 출발점이다.

## 1. 지식의 씨앗: 이 개념들은 왜 탄생했을까?

### 1.1 수학의 문제: 현실을 어떻게 계산 가능한 형태로 옮길까?

현실의 정보는 대개 한 숫자로 충분하지 않다. 사람 한 명을 키만으로 설명하면 체중, 나이, 수면 시간 같은 정보가 사라진다. 사진 한 장도 “밝기”라는 숫자 하나가 아니라 수많은 픽셀의 밝기와 색을 함께 가져야 한다.

- **스칼라**는 온도, 가격, 손실값처럼 크기 하나만 필요한 대상을 표현한다.
- **벡터**는 위치, 속도, 한 사람의 여러 특성처럼 여러 숫자를 순서 있게 묶어 표현한다.

좌표라는 생각이 등장하면서 기하학의 점을 숫자 묶음으로 계산할 수 있게 되었고, 이후 벡터는 물리학의 힘과 속도뿐 아니라 데이터의 여러 특성을 담는 공통 언어가 되었다. 머신러닝이 보는 이미지는 “고양이 사진” 자체가 아니라 픽셀이나 특징을 늘어놓은 벡터다. 즉, **벡터화는 현실을 계산 가능한 데이터로 번역하는 과정**이다.

### 1.2 AI의 문제: 모든 상황에서 ‘정답지’가 주어지는가?

초기의 통계적 패턴 인식은 입력과 정답을 함께 모아 규칙을 학습했다. 하지만 현실에서는 세 가지 서로 다른 문제가 생긴다.

1. 스팸 메일처럼 정답을 붙일 수 있는 문제에서는 **입력과 정답의 관계**를 배우고 싶다.
2. 고객 데이터처럼 정답이 없을 때는 데이터 안의 **숨은 무리와 구조**를 발견하고 싶다.
3. 로봇 주행처럼 한 번의 선택이 다음 상황을 바꿀 때는 여러 행동 끝에 얻는 **장기적 결과**를 좋게 만들고 싶다.

그래서 학습 방식도 갈라졌다.

- **지도학습:** 정답이 가르친다.
- **비지도학습:** 데이터 자체의 구조가 단서가 된다.
- **강화학습:** 환경과 상호작용하며 받은 보상이 방향을 알려 준다.

### 1.3 오늘 두 트랙이 만나는 지점

오늘의 단순화된 모형에서는 세 학습 방식 모두 관측을 숫자 벡터로 **인코딩**, 즉 계산 가능한 숫자 표현으로 바꾼다고 가정한다. 실제 시스템은 텐서, 토큰, 그래프, 이산 상태도 사용하지만 결국 모델이 계산할 수 있는 수치 표현이 필요하다.

$$
\text{현실의 대상} \longrightarrow \mathbf{x} \in \mathbb{R}^{d}
$$

그 뒤에 붙는 학습 신호가 다르다.

$$
\begin{aligned}
\text{지도학습} &: (\mathbf{x}, y) \\
\text{비지도학습} &: \mathbf{x} \\
\text{강화학습} &: (\mathbf{s}_t, a_t, r_t, \mathbf{s}_{t+1})
\end{aligned}
$$

입력 벡터 $\mathbf{x}$와 상태 벡터 $\mathbf{s}_t$, 회귀 타깃이나 보상에 쓰이는 스칼라 $y$, $r_t$, 분류 타깃에 쓰이는 범주 레이블 $y$ 또는 벡터 $\mathbf{y}$가 오늘 수학과 AI를 잇는 핵심 부품이다.

## 2. 친절한 용어 사전

### 2.1 수학 언어

| 용어 | 표기 | 초보자 해설 |
|---|---|---|
| 실수 | $a \in \mathbb{R}$ | 수직선 위에 놓을 수 있는 보통의 수다. 음수, $0$, 소수도 포함한다. |
| 스칼라 | $a$ | 숫자 하나로 표현되는 양이다. 볼륨 조절기의 한 칸처럼 “얼마나 큰가”를 나타낸다. |
| 벡터 | $\mathbf{x}$ | 여러 숫자를 정해진 순서로 묶은 것이다. 여러 칸이 있는 서랍에 각 특징을 한 칸씩 넣은 모습과 같다. 굵은 글씨는 벡터임을 표시한다. |
| 성분 | $x_j$ | 벡터의 $j$번째 숫자다. 키·체중 벡터라면 첫 성분은 키, 둘째 성분은 체중일 수 있다. |
| 차원 | $d$ | 벡터가 가진 성분의 개수다. $\mathbf{x} \in \mathbb{R}^{d}$는 실수 성분 $d$개를 가진다는 뜻이다. |
| 열벡터 | $\mathbf{x}=[x_1,\ldots,x_d]^\top$ | 숫자를 세로로 세운 벡터다. 위첨자 $\top$은 행과 열을 뒤집는 **전치**를 뜻한다. |
| 좌표 | $(x_1,x_2)$ | 기준축에 대해 한 점의 위치를 숫자로 기록한 것이다. 좌표가 같아도 각 축의 의미가 무엇인지 알아야 해석할 수 있다. |
| 노름 | $\lVert\mathbf{x}\rVert_2$ | 벡터의 길이를 재는 함수다. 아래첨자 $2$는 각 성분의 제곱을 사용하는 유클리드 노름임을 뜻한다. |
| 단위벡터 | $\mathbf{u}=\mathbf{x}/\lVert\mathbf{x}\rVert_2$ | 길이가 $1$인 벡터다. 크기를 떼고 방향만 보고 싶을 때 사용한다. |
| 인덱스 | $i,j,t$ | 위치를 세는 꼬리표다. 보통 $i$는 샘플 번호, $j$는 특징 번호, $t$는 시간 단계를 나타낸다. |

### 2.2 AI 학습 언어

| 용어 | 표기 | 초보자 해설 |
|---|---|---|
| 샘플 | $\mathbf{x}^{(i)}$ | 데이터 한 건이다. 위첨자 $(i)$는 거듭제곱이 아니라 $i$번째 샘플이라는 표지다. |
| 특징 | $x_j$ | 모델이 판단에 사용하는 측정값이다. 집값 예측에서 면적, 방 수, 역까지의 거리 등이 특징이다. |
| 레이블·타깃 | $y$ 또는 $\mathbf{y}$ | 맞혀야 할 정답이다. 회귀에서는 연속적인 스칼라일 수 있다. 분류에서는 범주 레이블이나 원-핫 벡터를 쓰며, 원-핫은 정답 범주의 칸만 $1$, 나머지는 $0$인 벡터다. 범주 ID가 숫자여도 그 크기에는 의미가 없다. |
| 예측 | $\widehat{y}$ 또는 $\widehat{\mathbf{y}}$ | 모델이 내놓은 추정 답이다. 이 문맥에서 모자 기호는 “관측된 진짜 값이 아니라 추정값”을 표시한다. |
| 모델 | $f_{\boldsymbol{\theta}}$ | 입력을 출력으로 바꾸는 조절 가능한 함수다. 레시피에 비유하면 $\boldsymbol{\theta}$는 재료 비율과 조리 시간이다. |
| 파라미터 | $\boldsymbol{\theta}$ | 학습 중 바뀌는 모델 내부 숫자 묶음이다. 신경망에서는 가중치와 편향이 여기에 속한다. |
| 데이터셋 | $\mathcal{D}$ | 여러 샘플을 모은 학습용 묶음이다. |
| 손실 | $\ell$, $\mathcal{L}$ | $\ell$은 샘플 하나의 벌점, $\mathcal{L}$은 여러 샘플의 벌점을 모은 전체 목적 함수다. 보통 작을수록 좋게 설계한다. |
| 배치 |  | 전체 데이터 중 한 번의 계산에 함께 넣는 작은 묶음이다. |
| 에포크 |  | 학습 데이터 전체를 한 차례 모두 사용한 횟수다. |
| 학습 |  | 데이터를 보고 파라미터를 조정하는 과정이다. |
| 추론 |  | 학습이 끝난 모델로 새 입력의 답을 계산하는 과정이다. |
| 지도학습 |  | 입력과 정답 쌍으로 입력에서 정답으로 가는 규칙을 배운다. |
| 비지도학습 |  | 사람이 붙인 정답 없이 데이터의 군집, 압축 표현, 분포 같은 구조를 찾는다. |
| 잠재 변수 | $z$ | 직접 주어지지 않았지만 데이터를 설명하기 위해 모델이 추정하는 숨은 값이다. 군집 번호가 한 예다. `Latent`는 “겉으로 드러나지 않은”이라는 뜻이다. |
| 에이전트 |  | 강화학습에서 행동을 선택하는 주체다. 로봇, 게임 캐릭터, 소프트웨어 에이전트가 될 수 있다. |
| 환경 |  | 에이전트의 행동을 받아 다음 상태와 보상을 돌려주는 세계다. |
| 상태 | $\mathbf{s}_t$ | 시각 $t$에 의사결정에 필요한 상황을 나타낸 벡터다. |
| 행동 | $a_t$ | 시각 $t$에 에이전트가 고른 선택이다. |
| 보상 | $r_t$ | 방금 행동의 결과가 얼마나 바람직했는지 환경이 주는 스칼라 신호다. |
| 정책 | $\pi_{\boldsymbol{\theta}}$ | 상태를 보고 행동을 고르는 규칙이다. 파라미터 $\boldsymbol{\theta}$로 조절된다. |
| 에피소드 |  | 시작부터 종료까지 이어지는 한 번의 상호작용 묶음이다. 게임 한 판에 해당한다. |
| 할인율 | $\gamma$ | 먼 미래 보상을 현재보다 얼마나 작게 볼지 정한다. 계속되는 무한 지평선 문제에서는 보통 $0 \le \gamma < 1$이고, 끝이 있는 에피소드에서는 $\gamma=1$도 쓸 수 있다. |

## 3. 수학의 해부학 (증명과 원리)

### 3.1 스칼라: 판단의 결과를 숫자 하나로 압축하기

온도 $23.5$, 상품 가격 $10{,}000$, 모델의 손실 $0.12$처럼 한 축만 필요한 값은 스칼라다. 두 스칼라 $a,b \in \mathbb{R}$에는 익숙한 사칙연산을 적용할 수 있다.

$$
a+b,\qquad a-b,\qquad ab,\qquad \frac{a}{b}\;(b\ne 0)
$$

대부분의 경사 기반 학습은 여러 샘플과 목표에서 생긴 오차를 최종 스칼라 목적 함수 $\mathcal{L}$로 집계한다. 그러면 파라미터가 수백만 개여도 한 기준의 증가와 감소를 비교할 수 있다. 여러 목표를 동시에 두는 다목적 학습도 가능하지만, 그때는 목표별 손실을 결합하거나 목표 사이의 절충 관계를 따로 다룬다.

### 3.2 벡터: 여러 특징을 한 개체로 묶기

어떤 학생의 공부 시간, 수면 시간, 모의고사 점수를 각각 $x_1,x_2,x_3$라 하면 다음처럼 한 벡터로 묶을 수 있다.

$$
\mathbf{x}
=
\begin{bmatrix}
x_1\\
x_2\\
x_3
\end{bmatrix}
\in \mathbb{R}^{3}
$$

중요한 점은 **순서가 의미의 일부**라는 것이다. 첫 칸이 공부 시간이라고 약속했다면 모든 샘플에서 첫 칸은 공부 시간이어야 한다.

일반적인 $d$차원 벡터는 다음과 같다.

$$
\mathbf{x}
=
\begin{bmatrix}
x_1 & x_2 & \cdots & x_d
\end{bmatrix}^{\top}
$$

여기서 $d$는 샘플 수가 아니라 **샘플 하나를 설명하는 특징 수**다. 샘플이 $N$개라면 $\mathbf{x}^{(1)},\ldots,\mathbf{x}^{(N)}$처럼 벡터가 $N$개 존재한다.

### 3.3 벡터 연산은 무엇을 뜻할까?

#### 덧셈: 변화량을 더한다

두 벡터의 차원이 같을 때 같은 위치의 성분끼리 더한다.

$$
\mathbf{x}+\mathbf{v}
=
\begin{bmatrix}
x_1+v_1\\
\vdots\\
x_d+v_d
\end{bmatrix}
$$

기하학적으로 $\mathbf{x}$의 끝에서 $\mathbf{v}$만큼 이동한 새 위치다. 데이터 관점에서는 “현재 특징에 변화량을 적용한다”는 뜻이다.

#### 스칼라배: 크기를 조절한다

스칼라 $c$를 벡터에 곱하면 모든 성분이 같은 비율로 변한다.

$$
c\mathbf{x}
=
\begin{bmatrix}
cx_1\\
\vdots\\
cx_d
\end{bmatrix}
$$

길이는 다음처럼 $|c|$배가 된다.

$$
\begin{aligned}
\lVert c\mathbf{x}\rVert_2
&=\sqrt{\sum_{j=1}^{d}(cx_j)^2} \\
&=\sqrt{c^2}\sqrt{\sum_{j=1}^{d}x_j^2} \\
&=|c|\,\lVert\mathbf{x}\rVert_2
\end{aligned}
$$

$|c|>1$이면 길이가 늘고, $0<|c|<1$이면 줄며, $c<0$이면 방향이 반대로 뒤집힌다. $c=0$이면 영벡터가 되어 방향이 없다. 신경망에서 개별 가중치는 특정 입력 성분의 영향력을 키우거나 줄인다는 점에서 이 생각과 연결된다.

#### 길이: 여러 성분을 하나의 크기로 모은다

2차원 벡터 $\mathbf{x}=[x_1,x_2]^{\top}$를 직각삼각형의 두 변으로 보면 피타고라스 정리로 길이가 나온다.

$$
\lVert\mathbf{x}\rVert_2^2=x_1^2+x_2^2
$$

양변에 제곱근을 취하면 다음과 같다.

$$
\lVert\mathbf{x}\rVert_2=\sqrt{x_1^2+x_2^2}
$$

이 원리를 $d$차원으로 확장하면 유클리드 노름이 된다.

$$
\lVert\mathbf{x}\rVert_2
=\sqrt{\sum_{j=1}^{d}x_j^2}
$$

벡터의 각 성분을 길이로 나누면 방향은 유지하면서 길이가 $1$인 단위벡터를 얻는다.

$$
\mathbf{u}
=\frac{\mathbf{x}}{\lVert\mathbf{x}\rVert_2},
\qquad \mathbf{x}\ne\mathbf{0}
$$

실제로 길이를 확인해 보자.

$$
\lVert\mathbf{u}\rVert_2
=\sqrt{\sum_{j=1}^{d}\left(\frac{x_j}{\lVert\mathbf{x}\rVert_2}\right)^2}
=\sqrt{\frac{\sum_{j=1}^{d}x_j^2}{\lVert\mathbf{x}\rVert_2^2}}
=1
$$

단, 영벡터 $\mathbf{0}$은 길이가 $0$이므로 나눌 수 없다.

#### 두 샘플 사이 거리: 차이 벡터의 길이

두 샘플 $\mathbf{x}$와 $\mathbf{v}$가 얼마나 다른지 가장 단순하게 재는 방법은 차이 벡터의 길이를 보는 것이다.

$$
\operatorname{dist}(\mathbf{x},\mathbf{v})
=\lVert\mathbf{x}-\mathbf{v}\rVert_2
=\sqrt{\sum_{j=1}^{d}(x_j-v_j)^2}
$$

이 식은 뒤에서 비지도학습의 군집화가 “가까운 벡터끼리 모으는” 원리를 수식으로 구현할 때 바로 사용된다.

### 3.4 이미지도 결국 벡터가 된다

흑백 픽셀 네 개의 밝기가 $0$에서 $255$ 사이의 값이라면 이미지를 다음 벡터로 펼칠 수 있다.

$$
\mathbf{x}
=
\begin{bmatrix}
12\\
240\\
128\\
64
\end{bmatrix}
\in\mathbb{R}^{4}
$$

컴퓨터는 이 벡터만으로 원래 픽셀의 위치 관계를 자동으로 알지 못한다. “어느 성분이 어느 픽셀인가”라는 배열 규칙도 함께 지켜야 한다. 이후 배울 행렬과 텐서, 즉 숫자를 둘 이상의 축으로 배열한 구조는 이 관계를 더 자연스럽게 보존한다.

| 수학 부품 | AI에서 맡는 역할 | 예시 |

| 스칼라 $y$ | 하나의 회귀 정답 | 집값 |
| 범주 레이블 $y$ 또는 타깃 벡터 $\mathbf{y}$ | 하나의 분류 정답 | 크기에 의미가 없는 클래스 ID 또는 원-핫 벡터 |

## 4. 🤖 인공지능 기초 빌드업 (Core AI Fundamentals)

### 4.1 공통 골격: 표현, 학습 신호, 목적

이 문서에서는 이해를 위해 관측을 벡터로 인코딩한다고 가정한다. 이 전형적 형태에서 세 방식은 각자의 기준에 따라 모델 파라미터를 바꾼다.

```text
[현실의 관측]
      ↓ 특징 추출
[숫자 벡터]
      ↓ 학습 방식에 맞는 신호
[조절 가능한 모델]
      ↓
[예측 · 구조 발견 · 행동 선택]
```

차이는 “좋은 결과가 무엇인지 알려 주는 신호”에 있다.

### 4.2 지도학습: 정답과 예측의 차이를 줄인다

지도학습 데이터셋은 입력 벡터와 정답의 쌍이다.

$$
\mathcal{D}_{\text{sup}}
=\left\{\left(\mathbf{x}^{(i)},y^{(i)}\right)\right\}_{i=1}^{N}
$$

여기서 $y^{(i)}$는 정답을 대표하는 일반 기호다. 회귀에서는 스칼라이고, 분류에서는 크기 순서가 없는 범주 레이블 또는 원-핫·확률 벡터가 될 수 있다.

모델은 입력 벡터를 예측으로 바꾼다.

$$
\widehat{y}^{(i)}
=f_{\boldsymbol{\theta}}\left(\mathbf{x}^{(i)}\right)
$$

각 예측의 오차를 샘플 하나의 손실 함수 $\ell$로 재고, 이를 평균한 전체 손실 $\mathcal{L}$을 작게 만드는 파라미터 $\boldsymbol{\theta}$를 찾는다.

$$
\mathcal{L}(\boldsymbol{\theta})
=\frac{1}{N}\sum_{i=1}^{N}
\ell\!\left(
f_{\boldsymbol{\theta}}\left(\mathbf{x}^{(i)}\right),
y^{(i)}
\right)
$$

아직 손실 함수와 최적화법을 배우지 않았으므로 오늘은 **정답과 예측을 비교할 숫자 기준이 필요하다**는 구조만 기억하자.

- **회귀:** 집값, 온도처럼 연속적인 수를 예측한다.
- **분류:** 스팸 여부, 질병 종류처럼 범주를 예측한다.

예를 들어 집 하나를 $\mathbf{x}=[\text{면적},\text{방 수},\text{역까지 거리}]^{\top}$로 표현하고 실제 가격 $y$를 붙이면 지도학습 샘플 하나가 된다.

### 4.3 비지도학습: 정답 없이 구조를 찾는다

비지도학습 데이터셋에는 사람이 붙인 정답 $y$가 없다.

$$
\mathcal{D}_{\text{unsup}}
=\left\{\mathbf{x}^{(i)}\right\}_{i=1}^{N}
$$

그렇다고 아무 기준도 없는 것은 아니다. 대표적인 K-means 군집화는 각 샘플을 가까운 중심 벡터에 배정해 전체 거리를 줄인다. 군집 수 $K$를 먼저 정하고, $K$개의 중심을 $\mathbf{c}_1,\ldots,\mathbf{c}_K$, 샘플 $i$의 숨은 군집 번호를 $z_i$라 하자. 목적 함수 $J$는 모든 샘플과 배정된 중심 사이의 제곱 거리를 더한 값이다.

$$
J
=\sum_{i=1}^{N}
\left\lVert
\mathbf{x}^{(i)}-\mathbf{c}_{z_i}
\right\rVert_2^2
$$

실제 최적화 문제는 다음처럼 중심과 군집 배정을 함께 고르는 것이다.

$$
J^\star
=\min_{\mathbf{c}_1,\ldots,\mathbf{c}_K,\;z_1,\ldots,z_N}J
\qquad
\text{단, }\mathbf{c}_k\in\mathbb{R}^{d},\;
z_i\in\{1,\ldots,K\}
$$

학습은 제곱 거리의 합을 가장 작게 만드는 군집 배정 $z_i$와 중심 $\mathbf{c}_k$를 찾으며, 그 가능한 최솟값이 $J^\star$다. 정답 레이블은 없지만 **“같은 군집의 벡터는 가까워야 한다”라는 목적 함수**는 있다.

또 다른 비지도학습은 고차원 벡터를 중요한 정보가 남도록 더 낮은 차원에 압축한다. 앞으로 도달할 PCA가 바로 이 계열이다.

### 4.4 강화학습: 연속된 행동의 장기 결과를 좋게 만든다

강화학습에서는 데이터셋이 처음부터 고정되어 있기보다 에이전트가 환경과 상호작용하며 경험을 만든다.

```text
[상태 관찰] → [정책이 행동 선택] → [환경이 변화]
     ↑                              ↓
     └──────── [다음 상태와 보상] ──┘
```

시각 $t$에서 정책은 상태 벡터 $\mathbf{s}_t$를 보고 행동 $a_t$를 선택한다. 확률적 정책은 다음처럼 여러 행동에 확률을 주고 그중 하나를 뽑는다.

$$
a_t \sim \pi_{\boldsymbol{\theta}}(\,\cdot\mid\mathbf{s}_t)
$$

기호 $\sim$은 정책이 정한 확률에 따라 행동을 뽑는다는 뜻이고, 세로선 $\mid$는 “상태 $\mathbf{s}_t$가 주어졌을 때”라는 조건을 뜻한다. 반면 결정론적 정책은 같은 상태에서 한 행동을 바로 정한다.

$$
a_t=\pi_{\boldsymbol{\theta}}(\mathbf{s}_t)
$$

환경은 선택된 행동을 받아 보상 $r_t$와 다음 상태 $\mathbf{s}_{t+1}$를 돌려준다.

좋은 정책은 당장 받는 보상 하나가 아니라 미래까지 누적한 수익을 크게 만든다. 보상이 유한한 범위 안에 있다면 아래 무한 합은 계속되는 문제에서 $0 \le \gamma < 1$일 때 수렴한다. 유한 에피소드에서는 종료 시점까지만 더하므로 $\gamma=1$도 사용할 수 있다.

$$
G_t
=r_t+\gamma r_{t+1}+\gamma^2r_{t+2}+\cdots
=\sum_{k=0}^{\infty}\gamma^k r_{t+k}
$$

- $\gamma=0$이면 현재 보상만 본다.
- $\gamma$가 $1$에 가까우면 먼 미래의 결과도 중요하게 본다.

예를 들어 미로 로봇의 상태 벡터에는 위치와 센서값이 들어가고, 행동은 상하좌우 이동이며, 목표 도착에는 양의 보상, 충돌에는 음의 보상을 줄 수 있다. 중간 단계에 정답 행동을 일일이 알려 주지 않아도 장기 보상을 통해 정책을 배운다.

### 4.5 세 학습 방식 비교

| 질문 | 지도학습 | 비지도학습 | 강화학습 |
|---|---|---|---|
| 주로 받는 정보 | 입력 $\mathbf{x}$와 정답 $y$ | 입력 $\mathbf{x}$ | 상태 $\mathbf{s}_t$, 행동 $a_t$, 보상 $r_t$, 다음 상태 $\mathbf{s}_{t+1}$ |
| 직접적인 교사 | 사람이 붙인 레이블 | 없음 | 환경의 보상 |
| 대표 목표 | 새 입력의 정답 예측 | 군집·분포·압축 표현 발견 | 장기 누적 보상 최대화 |
| 대표 과제 | 분류, 회귀 | 군집화, 차원 축소 | 게임, 로봇, 순차 의사결정 |
| 벡터의 역할 | 샘플 특징 표현 | 거리와 구조 계산 | 현재 상태 표현 |
| 스칼라의 역할 | 회귀 타깃·손실 표현 | 거리·목적 함수 표현 | 보상·수익 표현 |

### 4.6 오늘 수학이 실제로 맞물리는 방식

1. **표현:** 현실의 한 사례를 특징 벡터 $\mathbf{x}$ 또는 상태 벡터 $\mathbf{s}_t$로 만든다.
2. **비교:** 지도학습은 예측과 정답의 차이를, 비지도학습은 벡터 사이의 거리를 비교한다.
3. **평가:** 여러 차원의 결과를 손실 $\mathcal{L}$, 목적 함수 $J$, 보상 $r_t$ 같은 스칼라로 모은다.
4. **개선:** 모델은 그 스칼라 평가가 좋아지도록 파라미터 벡터 $\boldsymbol{\theta}$를 바꾼다. 이 변경 방향을 계산하는 도구가 나중에 배울 그래디언트다.

즉, 오늘의 단순화에서는 **벡터가 모델이 보는 세계의 수치 표현이고 스칼라 목적값이 모델이 얼마나 잘하고 있는지 알려 주는 점수**라고 생각하면 좋다.

### 4.7 초보자가 흔히 하는 오해와 주의할 점

#### 오해 1: “벡터는 화살표이고 데이터는 숫자 목록이니 서로 다르다.”

화살표와 숫자 목록은 같은 벡터를 바라보는 두 관점이다. 화살표는 방향과 길이를 보여 주는 기하학적 표현이고, 숫자 목록은 컴퓨터가 계산하기 쉬운 좌표 표현이다.

#### 오해 2: “벡터의 차원이 크면 데이터 샘플이 많다는 뜻이다.”

차원 $d$는 샘플 하나의 특징 수이고, 샘플 수 $N$은 그런 벡터가 몇 개 있는지다. 둘은 독립적이다.

#### 오해 3: “가까운 벡터는 언제나 비슷한 데이터다.”

거리의 의미는 특징 선택과 단위에 좌우된다. 키를 센티미터로 쓰고 소득을 원 단위로 쓰면 소득의 큰 숫자가 거리를 압도할 수 있다. 그래서 실제 학습 전에는 스케일 조정이 중요하다.

#### 오해 4: “비지도학습은 목표가 없다.”

사람이 준 레이블이 없을 뿐, 거리 최소화·복원 오차 최소화 같은 수학적 목적은 있다. 그 목적이 우리가 원하는 의미와 일치하는지는 별도로 검증해야 한다.

#### 오해 5: “강화학습의 보상은 매 순간 정답 행동을 알려 준다.”

보상은 결과의 좋고 나쁨만 말할 수 있고, 어떤 과거 행동이 책임져야 하는지는 직접 알려 주지 않는다. 늦게 도착한 보상을 이전 행동에 나누어 돌리는 **신용 할당 문제**가 강화학습의 핵심 난점이다.

#### 오해 6: “레이블이 있으면 무조건 객관적인 진실이다.”

레이블은 측정 오류나 사람의 편향을 포함할 수 있다. 지도학습 모델은 주어진 정답표의 품질을 넘어 자동으로 진실을 알아내지 못한다.

#### 보너스: 자기지도학습은 어디에 속할까?

자기지도학습은 데이터 일부를 가리거나 다음 토큰을 맞히는 식으로 **데이터 자체에서 임시 정답을 만든다**. 사람이 직접 레이블을 달지 않지만, 학습 계산은 입력과 만들어진 타깃을 비교하므로 지도학습 형태를 활용한다. “비지도 대 지도”의 단순한 이분법보다 **학습 신호를 어떻게 만들었는가**를 보는 편이 정확하다.

### 5.1 VLM: Gemini의 Agentic Video Understanding — 필요한 장면만 능동적으로 본다

Google은 2026-09-01 Gemini 3.7 Flash, 3.6 Flash, 3.5 Flash-Lite에 **에이전틱 영상 이해** 기능을 공개했다. 기존 정적 방식은 영상을 기본 $1\,\mathrm{FPS}$처럼 고정된 속도로 읽는다. 새 방식은 질문의 목적에 맞춰 모델이 영상 구간을 검색하고, 필요한 부분을 다시 살피며, 프레임·오디오·자막 중 어떤 신호를 사용할지 동적으로 고른다.

```text
[사용자 질문]
      ↓
[영상의 관련 구간 탐색]
      ↓
[필요한 신호와 세밀도 선택]
      ↓
[집중 재검토]
      ↓
[근거를 모아 답변]
```

Google은 자체 표준 영상 분석 평가에서 토큰 사용량을 최대 $88\%$, 비용을 최대 $66\%$ 줄이면서 품질을 최대 $7\%$ 높였다고 보고했다. 이는 공급사 자체 평가의 최대 개선치이므로 모든 영상·하드웨어·질문에서 보장되는 수치로 받아들이면 안 된다.

**엔지니어 인사이트 (Impact)**

- VLM의 경쟁축이 “모든 프레임을 한 번에 많이 넣기”에서 **질문에 필요한 증거를 찾아 선택적으로 다시 보기**로 이동하고 있다.
- 긴 강의, 회의, 감시 영상은 중요한 순간이 전체에서 희소하다. 능동 샘플링은 컨텍스트 토큰과 비용을 아끼면서 빠른 움직임 구간만 더 높은 시간 해상도로 검사할 수 있다.
- 정적 처리가 나쁜 것은 아니다. 짧고 지연 시간이 중요한 영상은 탐색 단계가 추가되어 지연 특성이 달라질 수 있으므로 정적 처리가 더 단순할 수 있다. 작업 길이와 질문 유형별로 정확도·비용·지연 시간을 함께 측정해야 한다.
- 오늘 배운 강화학습 관점으로 보면 `현재까지 본 증거 → 다음에 살필 구간 선택 → 새 관측`이라는 상태·행동 루프와 닮았다. 다만 공식 발표만으로 이 기능 자체가 강화학습으로 훈련되었다고 단정할 수는 없다. **동작 구조의 유사성**과 **학습 방법**은 구분해야 한다.

**직접 읽기:** [Google 공식 발표](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-agentic-video-in-gemini/) · [Gemini API 공식 개발 문서](https://ai.google.dev/gemini-api/docs/video-understanding#agentic-video-understanding)

### 5.2 오픈 LLM: IBM Granite 4.2 — 답변 모델에서 행동 학습 모델로

IBM은 2026-08-25 상업적 이용과 수정·재배포를 폭넓게 허용하는 Apache 2.0 라이선스로 Granite 4.2의 3B·8B·30B 모델을 공개했다. B는 billion, 즉 파라미터 약 10억 개 단위를 뜻한다. 모두 dense 방식의 decoder-only 추론 LLM이며, 답을 내기 전 계산 예산을 다르게 쓰는 thinking·non-thinking·low-effort thinking 모드와 네이티브 도구 호출을 제공한다. 공식 기술 설명에 따르면 약 15T 토큰으로 사전학습했고 기본 시퀀스 길이는 131,072이며, 장문맥 학습 단계에서는 512K까지 확장했다. 여기서 T는 trillion, 즉 1조 단위이고 K는 약 1천 단위다.

특히 8B와 30B 모델은 실제 샌드박스 환경에서 행동 결과를 보상으로 받는 다단계 에이전틱 강화학습(RL)을 거쳤다. 아래에서 SFT는 정답 예시로 미세조정하는 Supervised Fine-Tuning, RLVR은 자동 검증 가능한 보상을 쓰는 Reinforcement Learning with Verifiable Rewards, SWE는 실제 Software Engineering 과제, RLHF는 사람의 선호 피드백을 반영하는 Reinforcement Learning from Human Feedback를 뜻한다.

$$
\text{SFT}
\longrightarrow \text{RLVR}
\longrightarrow \text{기술 강화}
\longrightarrow \text{SWE}
\longrightarrow \text{터미널}
\longrightarrow \text{검색}
\longrightarrow \text{RLHF}
$$

3B 모델에는 SWE·터미널·검색 에이전틱 RL 단계가 없다는 크기별 차이를 주의해야 한다. IBM은 8비트 부동소수점 형식인 FP8, 4비트 형식인 NVFP4·MXFP4, 그리고 `llama.cpp` 생태계에서 널리 쓰는 모델 파일 형식 GGUF 변형도 함께 제공해 서버와 로컬 환경에서 메모리·속도 요구에 맞춰 실험할 선택지를 넓혔다.

**엔지니어 인사이트 (Impact)**

- 오픈 모델의 목표가 “좋은 문장을 생성하기”를 넘어 **도구를 사용해 실제 과업을 끝내기**로 이동하고 있다. 이는 오늘 배운 강화학습의 `상태 → 행동 → 결과 보상` 구조가 LLM 에이전트 훈련에 직접 들어간 사례다.
- 생각 예산 모드는 쉬운 요청에는 짧게, 어려운 요청에는 길게 추론하도록 정확도와 비용을 배포 시점에 조절하는 방향을 보여 준다.
- Apache 2.0 가중치와 여러 양자화 형식은 온프레미스 실험 장벽을 낮춘다. 다만 모델 라이선스가 열려 있어도 학습 데이터 전체가 공개되었다는 뜻은 아니며, IBM 자체 벤치마크는 동일 하드웨어·프롬프트·평가 코드로 독립 재현해야 한다.
- 실무 검증에서는 평균 점수만 보지 말고 도구 호출 성공률, 잘못된 행동의 복구율, 긴 작업의 누적 실패율, GPU 메모리, 지연 시간을 함께 측정해야 한다.

### 5.3 두 소식에서 읽어야 할 하나의 흐름

2026년 9월 초의 공통 키워드는 **선택과 행동**이다.

- 멀티모달 모델은 모든 입력을 수동적으로 소비하지 않고 필요한 증거를 선택해 관찰한다.
- 오픈 LLM은 정답 문장을 흉내 내는 데서 멈추지 않고 실제 환경에서 행동하고 결과로 학습한다.

오늘의 기초와 연결하면, 두 흐름 모두 `관찰 → 선택·행동 → 추가 관찰`의 반복 루프를 활용한다. 다만 결과를 스칼라 보상으로 바꾸어 학습한 사실이 공개된 사례는 여기서는 Granite 4.2이며, Gemini 기능의 학습 방법은 공식 발표만으로 알 수 없다.

## 6. 오늘의 메타인지 질문 (스스로 묻고 답하기)

### 질문

같은 배달 로봇 센서 관측 $\mathbf{x}=[\text{거리},\text{속도},\text{배터리}]^{\top}$를 사용하더라도 지도학습·비지도학습·강화학습 문제는 어떻게 달라지는가? 각 방식에서 벡터와 스칼라가 맡는 역할까지 설명해 보자.

### 모범 답안

이 문제에서는 세 방식 모두 현실의 관측을 같은 특징 벡터 $\mathbf{x}$로 표현할 수 있지만, **어떤 학습 신호가 추가되고 무엇을 최적화하는지**가 다르다.

- 지도학습에서는 $\mathbf{x}$에 “앞에 장애물이 있는가” 같은 범주 레이블 $y$를 붙여 $f_{\boldsymbol{\theta}}(\mathbf{x})$가 $y$를 잘 예측하도록 학습한다. 벡터는 입력이고, 범주 레이블은 원하는 답을, 스칼라 손실은 예측 오차를 나타낸다.
- 비지도학습에서는 $y$ 없이 여러 $\mathbf{x}$를 보고 비슷한 주행 상황을 군집화하거나 더 작은 잠재 표현으로 압축한다. 벡터 사이 거리나 복원 오차를 스칼라 목적 함수로 만들어 구조를 찾는다.
- 강화학습에서는 관측을 상태 벡터 $\mathbf{s}_t$로 보고 행동 $a_t$를 선택한다. 환경이 충돌, 에너지 사용, 도착 성공을 보상 $r_t$로 돌려주며, 정책은 장기 수익 $G_t$를 크게 만들도록 학습한다.

따라서 벡터는 이 예에서 세 방식이 공유하는 **세계의 수치 표현**이다. 레이블은 원하는 답을 제공하고, 스칼라 목적 함수와 보상은 서로 다른 방식으로 **좋고 나쁨을 알려 주는 신호**다.
