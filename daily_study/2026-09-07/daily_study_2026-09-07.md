# [2026-09-07] 오늘 학습: 편미분·그래디언트 & 손실 함수(MSE·교차 엔트로피)

> **오늘의 핵심 문장:** 손실 함수는 모델의 여러 종류의 실수를 숫자 하나로 모으고, 그래디언트는 각 파라미터를 아주 조금 움직였을 때 그 숫자가 어느 방향으로 얼마나 변하는지 알려 주는 나침반이다.

지난 학습에서는 뉴런이 내적과 편향으로 증거를 모으고, ReLU나 Sigmoid 같은 비선형 활성화 함수가 그 증거를 새 특징으로 바꾸는 과정을 배웠다. 그러나 XOR 예제의 가중치는 사람이 직접 골랐다. 모델이 스스로 더 나은 가중치를 찾으려면 먼저 두 가지가 필요하다.

1. 현재 예측이 얼마나 나쁜지를 재는 **손실 함수**가 있어야 한다.
2. 각 파라미터를 바꿀 때 손실이 어떻게 변하는지를 재는 **편미분과 그래디언트**가 있어야 한다.

오늘의 연결은 다음 한 줄이다.

$$
\underbrace{\boldsymbol{\theta}}_{\text{가중치와 편향}}
\xrightarrow{\text{모델}}
\underbrace{\widehat{y}}_{\text{예측}}
\xrightarrow{\text{손실 함수}}
\underbrace{L(\boldsymbol{\theta})}_{\text{실수의 스칼라 점수}}
\xrightarrow{\text{편미분}}
\underbrace{\nabla_{\boldsymbol{\theta}}L}_{\text{모든 파라미터의 변화 신호}}
$$

여기서 $\boldsymbol{\theta}$는 모델이 학습해야 할 모든 파라미터를 모은 벡터다. 오늘은 이 나침반을 **계산하고 해석하는 법**까지 다룬다. 나침반을 따라 실제로 반복 이동하는 경사하강법과, 깊은 신경망 전체에 변화 신호를 전달하는 오차역전파는 다음 학습에서 이어 간다.

## 1. 지식의 씨앗: 이 개념들은 왜 탄생했을까?

### 1.1 수학의 문제: 순간의 변화를 어떻게 숫자로 잴까?

자동차가 $2$시간 동안 $120\,\mathrm{km}$를 갔다면 평균 속력은 $60\,\mathrm{km/h}$다. 하지만 운전자가 정확히 한 시점에 얼마나 빠르게 달렸는지는 전체 거리와 전체 시간만으로 알 수 없다. 아주 짧은 시간 간격의 평균 변화율을 구하고, 그 간격을 $0$에 한없이 가깝게 줄이는 생각이 필요하다. 이것이 **미분**의 출발점이다.

함수 $f(x)$에서 입력을 $x$에서 $x+h$로 바꿨을 때 평균 변화율은

$$
\frac{f(x+h)-f(x)}{h}
$$

이다. $h$를 $0$에 가깝게 보내 얻는 순간 변화율이 도함수 $f'(x)$다.

17세기 후반 뉴턴과 라이프니츠가 운동과 변화 문제를 풀기 위해 미적분을 서로 독립적으로 체계화했다. 오늘날 AI가 쓰는 표기와 계산법은 더 발전했지만, “아주 작은 입력 변화가 출력을 얼마나 바꾸는가?”라는 질문은 같다.

AI 모델에는 손잡이가 하나가 아니라 수백만 개에서 수천억 개까지 있을 수 있다. 가중치 하나만 움직이고 나머지를 고정했을 때 손실이 어떻게 변하는지를 재는 도구가 **편미분**이고, 모든 편미분을 한데 모은 벡터가 **그래디언트**다.

### 1.2 AI의 문제: “틀렸다”를 모델이 계산할 수 있는 숫자로 바꿀 수 없을까?

사람은 “예측이 꽤 틀렸다”라고 말할 수 있지만 컴퓨터는 그 문장만으로 파라미터를 고칠 수 없다. 예측과 정답의 차이를 하나의 스칼라로 바꾸는 규칙이 필요하다. 이 규칙이 **손실 함수**다.

- 집값처럼 연속적인 값을 예측할 때는 오차를 제곱한 **평균제곱오차(MSE)**가 자연스럽다.
- 고양이·개처럼 범주를 예측할 때는 정답 범주에 얼마나 높은 확률을 주었는지를 재는 **교차 엔트로피**가 자연스럽다.

손실을 스칼라 하나로 만드는 이유는 단순히 보기 편해서가 아니다. 모든 파라미터가 공동으로 개선해야 할 **공통 목표**를 만들기 위해서다.

### 1.3 왜 오차를 그냥 더하거나 정답 개수만 세면 안 될까?

회귀에서 잔차를 $e_i=\widehat{y}_i-y_i$라 하자. 잔차를 그대로 더하면 양수와 음수가 상쇄될 수 있다.

$$
(-10)+10=0
$$

두 예측은 각각 크게 틀렸는데 합은 $0$이다. 절댓값을 쓰면 상쇄는 막을 수 있지만 $0$에서 뾰족해 미분을 다룰 때 별도의 주의가 필요하다. 제곱은 부호를 없애고 큰 오차를 더 강하게 벌주며 매끄럽게 미분된다. 르장드르는 1805년에 최소제곱법을 출판했고, 가우스는 1809년에 천체 궤도 추정과 연결해 설명했다. 관측 오차가 섞인 천문·측량 문제를 푸는 이 생각이 오늘의 회귀 손실로 이어졌다.

분류 정확도도 그대로 학습 목표로 쓰기 어렵다. 정답 여부만 세면 확률 $0.51$과 $0.99$가 모두 같은 “정답 한 개”다. 파라미터를 아주 조금 바꿔도 예측 범주가 바뀌기 전까지 정확도는 그대로이므로, 어디로 움직여야 더 나아지는지 섬세한 신호를 주지 못한다. 통계학의 로그가능도와 섀넌이 1948년에 체계화한 정보이론의 로그 척도는 확률적 예측을 연속적으로 평가하는 토대가 되었고, 교차 엔트로피는 정답에 준 확률을 통해 이 문제를 해결한다.

### 1.4 오늘 두 트랙이 만나는 지점: 손실 지형

파라미터가 두 개 $w,b$인 모델의 손실을 $L(w,b)$라고 하자. 가로축을 $w$, 세로축을 $b$, 높이를 손실로 보면 하나의 지형이 생긴다.

```text
손실 L
  ↑             높은 손실
  │          ╱￣￣￣￣╲
  │        ╱            ╲
  │      ╱      ↓         ╲
  │    ╱      낮은 곳       ╲
  └──────────────────────────→ (w, b)
```

편미분 $\partial L/\partial w$는 $b$를 고정하고 동서 방향으로 본 경사이고, $\partial L/\partial b$는 $w$를 고정하고 남북 방향으로 본 경사다. 두 값을 모은

$$
\nabla L(w,b)
=
\begin{bmatrix}
\dfrac{\partial L}{\partial w}\\[4pt]
\dfrac{\partial L}{\partial b}
\end{bmatrix}
$$

는 현재 위치에서 손실이 가장 빠르게 증가하는 방향을 가리킨다. 지난 학습의 내적과 코시–슈바르츠 부등식이 이 사실을 정확히 증명해 준다.

## 2. 친절한 용어 사전

### 2.1 수학 언어

| 용어 | 표기 | 초보자 해설 |
|---|---|---|
| 함수 | $y=f(x)$ | 입력을 정해진 규칙으로 출력에 대응시키는 기계다. |
| 변화량 | $\Delta x$, $\Delta f$ | 바뀐 값에서 원래 값을 뺀 양이다. $\Delta f=f(x+\Delta x)-f(x)$다. |
| 평균 변화율 | $\Delta f/\Delta x$ | 일정 구간에서 입력 한 단위당 출력이 평균적으로 얼마나 변했는지 나타낸다. |
| 극한 | $\lim_{h\to0}$ | $h$를 실제로 $0$으로 나누는 것이 아니라, $0$에 끝없이 가까워질 때 값이 어디에 가까워지는지 묻는 개념이다. |
| 도함수 | $f'(x)$, $df/dx$ | 입력이 하나인 함수의 순간 변화율이다. 해당 점에서 접선의 기울기이기도 하다. |
| 편미분 | $\partial f/\partial x_j$ | 입력이 여러 개일 때 하나만 움직이고 나머지를 고정해 잰 순간 변화율이다. |
| 그래디언트 | $\nabla f$ | 모든 편미분을 좌표 순서대로 모은 열벡터다. 유클리드 공간에서 가장 빠른 증가 방향을 가리킨다. |
| 실수 공간 | $\mathbb{R}^n$ | 실수 $n$개를 좌표로 갖는 공간이다. 모델 파라미터 $n$개를 한 점으로 생각할 때 쓴다. |
| 전치 | $\mathbf{x}^{\top}$ | 행과 열을 뒤집는 연산이다. 열벡터를 전치하면 행벡터가 되어 다른 벡터와 내적할 수 있다. |
| 특징 차원 | $d$ | 샘플 하나를 표현하는 입력 숫자의 개수다. |
| 일 벡터 | $\mathbf{1}_N$ | 모든 성분이 $1$인 $N$차원 열벡터다. 같은 편향을 샘플 $N$개에 더할 때 쓴다. |
| 파라미터 벡터 | $\boldsymbol{\theta}$ | 모델의 모든 가중치와 편향을 한 줄로 모았다고 생각한 벡터다. |
| 방향벡터 | $\mathbf{u}$ | 어느 방향으로 움직일지를 나타내는 벡터다. 방향만 비교할 때는 $\lVert\mathbf{u}\rVert_2=1$로 둔다. |
| 방향미분 | $D_{\mathbf{u}}f$ | $\mathbf{u}$ 방향으로 아주 조금 움직였을 때 함수가 얼마나 빠르게 변하는지 나타낸다. |
| 등고선 | $f(\mathbf{x})=c$ | 함수값이 같은 점들을 이은 선이다. 지도에서 높이가 같은 점을 잇는 선과 같다. |
| 선형 근사 | $f(\mathbf{x}+\Delta\mathbf{x})\approx f(\mathbf{x})+\nabla f(\mathbf{x})^{\top}\Delta\mathbf{x}$ | 아주 가까운 곳에서는 매끄러운 곡면을 접평면으로 근사할 수 있다는 뜻이다. |
| 연쇄법칙 | $dL/dw=(dL/dz)(dz/dw)$ | 합성된 함수에서 바깥 변화율과 안쪽 변화율을 곱하는 규칙이다. |
| 미분 가능 |  | 해당 점 근처를 하나의 선이나 평면으로 잘 근사할 수 있는 성질이다. |

### 2.2 AI 학습 언어

| 용어 | 표기 | 초보자 해설 |
|---|---|---|
| 파라미터 | $w,b,\mathbf{W}$ | 데이터로부터 조정되는 모델 내부의 손잡이다. |
| 예측 | $\widehat{y}$ | 모델이 입력을 보고 내놓은 값이다. 모자 기호는 “추정한 값”이라는 뜻이다. |
| 정답·레이블 | $y$ | 학습 데이터가 제공하는 목표 값이나 범주다. |
| 잔차 | $e=\widehat{y}-y$ | 예측에서 정답을 뺀 부호 있는 차이다. |
| 손실 | $\ell_i$ | 샘플 하나에서 예측이 얼마나 나쁜지 재는 스칼라다. |
| 목적 함수 | $L$ | 여러 샘플의 손실과 필요하면 정규화 항까지 합쳐 모델이 최적화할 전체 목표다. 문맥에 따라 손실 함수와 비슷하게 부른다. |
| 회귀 |  | 집값이나 온도처럼 연속적인 수치를 예측하는 문제다. |
| 분류 |  | 고양이·개처럼 미리 정한 범주 중 하나 또는 여러 개를 예측하는 문제다. |
| 평균제곱오차 | MSE | 잔차를 제곱해 평균낸 손실이다. 큰 오차를 더 강하게 벌준다. |
| 확률 | $p$ | 사건이 일어날 모델의 믿음을 $0$과 $1$ 사이 숫자로 나타낸 값이다. 서로 배타적이고 모든 경우를 포함한 범주들의 확률 합은 $1$이다. 독립적인 여러 라벨의 확률은 합이 $1$일 필요가 없다. |
| 로그 | $\ln p$ | 곱을 합으로 바꾸는 함수다. $0<p\le1$이면 $\ln p\le0$이고, $p$가 $0$에 가까울수록 매우 큰 음수가 된다. |
| 가능도 | $P(\text{관측 데이터}\mid\boldsymbol{\theta})$ | 현재 파라미터의 모델이 실제 관측 데이터를 얼마나 그럴듯하게 설명하는지를 나타낸다. |
| 가우시안 분포 | $\mathcal{N}(\mu,\sigma^2)$ | 평균 $\mu$ 주변에 종 모양으로 퍼지는 연속 확률분포다. $\sigma^2$은 퍼짐의 크기인 분산이다. |
| Bernoulli 분포 |  | 결과가 $0$ 또는 $1$인 사건 하나를 확률 $p$로 표현하는 분포다. |
| 범주형 분포 |  | 서로 배타적인 여러 범주 중 하나가 나올 확률을 나타내는 분포다. |
| 교차 엔트로피 | CE | 정답 분포와 모델 확률 분포의 어긋남을 재는 손실이다. 정답에 낮은 확률을 주면 크게 벌준다. |
| 이진 교차 엔트로피 | BCE | 두 범주 문제에 쓰며, 여러 라벨을 독립적으로 예측할 때도 라벨마다 적용하는 교차 엔트로피다. |
| 다중 라벨 분류 |  | 샘플 하나가 여러 라벨을 동시에 가질 수 있는 문제다. 각 라벨을 독립적인 이진 사건처럼 다루는 경우가 많다. |
| 원-핫 벡터 | $\mathbf{y}$ | 정답 범주 위치만 $1$이고 나머지는 $0$인 벡터다. |
| 로짓 | $z_k$ | Sigmoid나 Softmax에 넣기 전의 제한 없는 실수 점수다. 확률 그 자체가 아니다. |
| Sigmoid | $\sigma(z)$ | 이진 로짓 하나를 $(0,1)$ 범위의 확률로 바꾼다. |
| Softmax | $p_k$ | 여러 로짓을 합이 $1$인 범주 확률들로 바꾼다. |
| 배치 |  | 한 번에 묶어 계산하는 샘플들의 작은 꾸러미다. |
| 리덕션 | `mean`, `sum` | 샘플별 손실을 평균낼지 더할지 정하는 방식이다. 이에 따라 그래디언트 크기도 달라진다. |

## 3. 수학의 해부학 (증명과 원리)

### 3.1 도함수는 평균 변화율의 극한이다

함수 $f(x)$에서 입력을 $x$에서 $x+h$로 움직이면 두 점을 잇는 할선의 기울기는

$$
\frac{f(x+h)-f(x)}{h}
$$

이다. $h\ne0$일 때만 이 비율을 계산할 수 있다. 도함수는 $h=0$을 직접 대입하지 않고, $h$가 $0$으로 가까워질 때의 극한으로 정의한다.

$$
\boxed{
f'(x)
=\lim_{h\to0}
\frac{f(x+h)-f(x)}{h}
}
$$

가장 기본적인 $f(x)=x^2$를 정의에서 미분해 보자.

$$
\begin{aligned}
f'(x)
&=\lim_{h\to0}\frac{(x+h)^2-x^2}{h}\\
&=\lim_{h\to0}\frac{x^2+2xh+h^2-x^2}{h}\\
&=\lim_{h\to0}\frac{h(2x+h)}{h}\\
&=\lim_{h\to0}(2x+h)\\
&=2x
\end{aligned}
$$

셋째 줄에서 약분할 때는 $h\ne0$이다. 약분한 뒤 극한을 취하므로 $0$으로 나누지 않는다. $x=3$이면 $f'(3)=6$이다. 이는 $x$를 아주 조금 늘릴 때 $x^2$가 입력 변화량의 약 $6$배만큼 증가한다는 뜻이다.

### 3.2 손실 하나를 미분해 보자

입력 $x=2$, 정답 $y=5$인 샘플 하나에 대해 편향 없는 선형 모델을

$$
\widehat{y}=wx=2w
$$

로 두자. 제곱오차는

$$
L(w)=(\widehat{y}-y)^2=(2w-5)^2
$$

이다. 전개한 뒤 정의로 미분할 수도 있고, 뒤에서 배울 연쇄법칙을 사용하면

$$
\frac{dL}{dw}
=2(2w-5)\cdot2
=4(2w-5)
$$

이다. $w=1$에서는

$$
L(1)=(2-5)^2=9,
\qquad
\frac{dL}{dw}\bigg|_{w=1}=-12
$$

이다. 음수 기울기는 $w$를 아주 조금 늘리면 손실이 감소하는 쪽이라는 뜻이다. 예를 들어 $w$를 $0.001$만큼 늘리는 변화 $\Delta w=0.001$에는

$$
\Delta L
\approx
\frac{dL}{dw}\Delta w
=-12\times0.001
=-0.012
$$

라는 1차 근사를 얻는다. 실제로

$$
L(1.001)-L(1)
=(2.002-5)^2-9
=-0.011996
$$

이므로 작은 변화에서는 근사가 매우 가깝다.

### 3.3 편미분은 다른 손잡이를 잠시 고정한다

이제 편향 $b$도 넣어

$$
\widehat{y}=2w+b,
\qquad
L(w,b)=(2w+b-5)^2
$$

로 두자. 편의를 위해 잔차를

$$
e=2w+b-5
$$

라고 쓰면 $L=e^2$이다.

$b$를 상수처럼 고정하고 $w$만 바꾼 편미분은

$$
\frac{\partial L}{\partial w}
=2e\frac{\partial e}{\partial w}
=2e\cdot2
=4e
$$

이다. 반대로 $w$를 고정하고 $b$만 바꾸면

$$
\frac{\partial L}{\partial b}
=2e\frac{\partial e}{\partial b}
=2e\cdot1
=2e
$$

이다. $(w,b)=(1,0)$에서는 $e=-3$이므로

$$
\frac{\partial L}{\partial w}=-12,
\qquad
\frac{\partial L}{\partial b}=-6
$$

이다. 편미분은 다른 변수가 현실에서 아무 영향도 없다고 선언하는 것이 아니다. 특정 좌표축 방향의 영향을 분리해 측정하기 위해 계산하는 순간에만 나머지를 고정한다.

### 3.4 그래디언트는 모든 좌표 방향의 변화율을 모은다

$n$개의 변수를 가진 스칼라 함수 $f:\mathbb{R}^n\to\mathbb{R}$의 그래디언트는

$$
\boxed{
\nabla f(\mathbf{x})
=
\begin{bmatrix}
\dfrac{\partial f}{\partial x_1}\\
\dfrac{\partial f}{\partial x_2}\\
\vdots\\
\dfrac{\partial f}{\partial x_n}
\end{bmatrix}
}
$$

이다. 앞의 손실에서는

$$
\nabla L(w,b)
=
\begin{bmatrix}
4(2w+b-5)\\
2(2w+b-5)
\end{bmatrix}
$$

이고

$$
\nabla L(1,0)
=
\begin{bmatrix}
-12\\
-6
\end{bmatrix}
$$

이다. 파라미터 변화량을

$$
\Delta\boldsymbol{\theta}
=
\begin{bmatrix}
\Delta w\\
\Delta b
\end{bmatrix}
$$

라고 하면 작은 변화에서

$$
\boxed{
L(\boldsymbol{\theta}+\Delta\boldsymbol{\theta})
-L(\boldsymbol{\theta})
\approx
\nabla L(\boldsymbol{\theta})^{\top}
\Delta\boldsymbol{\theta}
}
$$

이다. 지난 학습의 **내적**이 다시 등장했다. 그래디언트와 이동 방향의 내적이 양수면 손실이 국소적으로 증가하고, 음수면 감소하며, $0$이면 그 방향의 1차 변화가 없다.

### 3.5 왜 그래디언트가 가장 빠른 증가 방향인가?

길이가 $1$인 방향벡터 $\mathbf{u}$를 따라 움직일 때 방향미분은

$$
D_{\mathbf{u}}f
=\nabla f^{\top}\mathbf{u}
$$

이다. 내적의 기하학적 공식에 따르면

$$
D_{\mathbf{u}}f
=\lVert\nabla f\rVert_2
\lVert\mathbf{u}\rVert_2
\cos\theta
=\lVert\nabla f\rVert_2\cos\theta
$$

이다. 또는 코시–슈바르츠 부등식으로

$$
\left|
\nabla f^{\top}\mathbf{u}
\right|
\le
\lVert\nabla f\rVert_2
\lVert\mathbf{u}\rVert_2
=\lVert\nabla f\rVert_2
$$

를 얻는다. $\nabla f\ne\mathbf{0}$일 때 다음이 성립한다.

- $\mathbf{u}=\nabla f/\lVert\nabla f\rVert_2$이면 $D_{\mathbf{u}}f=\lVert\nabla f\rVert_2$로 가장 빠르게 증가한다.
- $\mathbf{u}=-\nabla f/\lVert\nabla f\rVert_2$이면 $D_{\mathbf{u}}f=-\lVert\nabla f\rVert_2$로 가장 빠르게 감소한다.

여기서 “가장 빠르다”는 현재 점, 매우 작은 이동, 유클리드 길이가 같은 방향들을 비교한 **국소적 진술**이다. 멀리 이동한 뒤에도 같은 방향이 최선이라는 보장은 없다.

앞의 예제에서

$$
\left\lVert\nabla L(1,0)\right\rVert_2
=\sqrt{(-12)^2+(-6)^2}
=6\sqrt{5}
$$

이므로 가장 빠른 감소 단위방향은

$$
-\frac{\nabla L}{\lVert\nabla L\rVert_2}
=
\begin{bmatrix}
2/\sqrt{5}\\
1/\sqrt{5}
\end{bmatrix}
$$

이다.

### 3.6 그래디언트는 조건을 만족하는 점에서 등고선의 접선에 수직이다

$f$가 미분 가능하고 $\nabla f\ne\mathbf{0}$인 점을 생각하자. 같은 함수값 $c$를 유지하며 움직이는 매끄러운 등고선 위의 위치를 $\boldsymbol{\gamma}(s)$라고 쓰자. $s$는 선을 따라 위치를 표시하는 숫자이고 $\boldsymbol{\gamma}'(s)$는 그 점에서 등고선이 향하는 접선벡터다.

등고선에서는 항상

$$
f\bigl(\boldsymbol{\gamma}(s)\bigr)=c
$$

이므로 양변을 $s$로 미분하면 연쇄법칙에 따라

$$
0
=\frac{d}{ds}
f\bigl(\boldsymbol{\gamma}(s)\bigr)
=\nabla f\bigl(\boldsymbol{\gamma}(s)\bigr)^{\top}
\boldsymbol{\gamma}'(s)
$$

이다. 내적이 $0$이므로 그래디언트와 **그 점의 등고선 접선**은 수직이다. 등고선 위에서 멀리 떨어진 두 점을 잇는 현과 항상 수직이라는 뜻은 아니다.

```text
          ∇f  가장 빠른 증가
           ↑
     ──────●──────  같은 높이의 등고선
          접선 →
```

등산 지도에서 등고선을 가로질러 수직으로 오를 때 고도가 가장 빨리 변하는 것과 같다. 손실 지형에서도 그래디언트는 현재 등고선을 수직으로 가로지르는 방향이다.

### 3.7 연쇄법칙은 합성된 변화율을 이어 붙인다

AI 계산은 여러 함수의 합성이다. 예를 들어

$$
w\longrightarrow z=wx+b
\longrightarrow p=\sigma(z)
\longrightarrow L(p)
$$

처럼 이어진다. $w$가 손실에 미치는 변화율은 중간 경로의 변화율을 곱해 구한다.

$$
\boxed{
\frac{dL}{dw}
=\frac{dL}{dp}
\frac{dp}{dz}
\frac{dz}{dw}
}
$$

여러 경로가 한 변수로 모이면 각 경로의 기여를 더한다. 이 원리가 깊은 신경망 전체에 조직적으로 적용된 것이 오차역전파다. 오늘은 손실 함수 안에서 필요한 짧은 연쇄만 직접 계산하고, 전체 계산 그래프의 역전파는 다음 학습에서 다룬다.

자주 쓰는 기본 미분 규칙은 다음과 같다.

$$
\frac{d}{dx}c=0,
\qquad
\frac{d}{dx}x^n=nx^{n-1},
\qquad
\frac{d}{dx}\ln x=\frac{1}{x}\quad(x>0)
$$

Sigmoid의 미분은

$$
\sigma(z)=\frac{1}{1+e^{-z}}
$$

에서 다음처럼 유도된다.

$$
\begin{aligned}
\sigma'(z)
&=\frac{d}{dz}(1+e^{-z})^{-1}\\
&=\frac{e^{-z}}{(1+e^{-z})^2}\\
&=\frac{1}{1+e^{-z}}
\left(1-\frac{1}{1+e^{-z}}\right)\\
&=\boxed{\sigma(z)\bigl(1-\sigma(z)\bigr)}
\end{aligned}
$$

이다. 이 간결한 형태가 이진 교차 엔트로피와 결합할 때 중요한 소거를 만든다.

### 3.8 그래디언트가 $\mathbf{0}$이면 최소일까?

반드시 그렇지 않다. $f'(x)=0$인 점은 1차 변화가 사라진 **정지점**일 뿐이다.

- $f(x)=x^2$에서는 $x=0$이 최솟값이다.
- $f(x)=-x^2$에서는 $x=0$이 최댓값이다.
- $f(x)=x^3$에서는 $x=0$에서 기울기가 $0$이지만 양쪽으로 계속 증가한다.
- 여러 변수에서는 어떤 방향으로는 올라가고 다른 방향으로는 내려가는 안장점도 있다.

따라서 그래디언트는 강력한 국소 정보지만 함수의 전체 모양을 혼자 알려 주지는 않는다.

## 4. 🤖 인공지능 기초 빌드업 (Core AI Fundamentals)

### 4.1 모델 학습의 세 부품: 예측, 손실, 그래디언트

샘플 $N$개가 있고, 모델의 예측을 $\widehat{y}_i=f_{\boldsymbol{\theta}}(\mathbf{x}_i)$라 하자. 학습 계산은 다음처럼 읽는다.

```text
입력 xᵢ ──> 모델 fθ ──> 예측 ŷᵢ ──> 샘플 손실 ℓ(ŷᵢ, yᵢ)
                 │                         │
                 └──── 파라미터 θ <── 그래디언트 ∇θL
```

전체 목적 함수의 기본 형태는

$$
L(\boldsymbol{\theta})
=\frac{1}{N}
\sum_{i=1}^{N}
\ell\left(
f_{\boldsymbol{\theta}}(\mathbf{x}_i),y_i
\right)
$$

이다. 손실 함수는 예측과 정답을 비교하고, 그래디언트는 그 결과를 각 파라미터의 변화 신호로 번역한다.

### 4.2 MSE: 연속값 오차를 제곱해 평균낸다

평균제곱오차는

$$
\boxed{
L_{\mathrm{MSE}}
=\frac{1}{N}
\sum_{i=1}^{N}
(\widehat{y}_i-y_i)^2
}
$$

이다. 이름을 식과 대응시키면 다음과 같다.

1. **오차:** $\widehat{y}_i-y_i$
2. **제곱:** $(\widehat{y}_i-y_i)^2$
3. **평균:** $N$개를 더해 $N$으로 나눔

일부 교재는 $1/N$ 대신 $1/(2N)$을 사용한다. 양의 상수배는 손실을 최소로 만드는 파라미터를 바꾸지 않으며, $1/2$은 미분할 때 제곱에서 나오는 계수 $2$를 없애 식을 짧게 만든다. 다른 자료의 그래디언트와 비교할 때 이 관례를 먼저 확인해야 한다.

단일 출력 선형회귀

$$
\widehat{y}_i=\mathbf{w}^{\top}\mathbf{x}_i+b
$$

에 대해 잔차를 $e_i=\widehat{y}_i-y_i$라 하면

$$
L_{\mathrm{MSE}}
=\frac{1}{N}\sum_{i=1}^{N}e_i^2
$$

이고, 연쇄법칙으로

$$
\boxed{
\nabla_{\mathbf{w}}L_{\mathrm{MSE}}
=\frac{2}{N}
\sum_{i=1}^{N}
e_i\mathbf{x}_i
}
$$

$$
\boxed{
\frac{\partial L_{\mathrm{MSE}}}{\partial b}
=\frac{2}{N}
\sum_{i=1}^{N}e_i
}
$$

를 얻는다. 각 샘플은 `잔차 × 입력`만큼 가중치 그래디언트에 기여한다. 입력 성분 $x_{ij}$의 절댓값이 크면 같은 잔차라도 해당 가중치 $w_j$에 더 큰 변화 신호를 낸다.

행렬로 샘플을 행마다 쌓아

$$
\mathbf{X}\in\mathbb{R}^{N\times d},
\qquad
\mathbf{e}=\mathbf{X}\mathbf{w}+b\mathbf{1}_N-\mathbf{y}
$$

라 하면

$$
\nabla_{\mathbf{w}}L_{\mathrm{MSE}}
=\frac{2}{N}\mathbf{X}^{\top}\mathbf{e}
$$

이다. 지난 학습의 행렬곱과 내적이 “오차를 파라미터 방향으로 모으는 장치”로 사용된다.

#### 왜 제곱은 큰 오차에 민감한가?

오차의 절댓값이 $1,2,10$이면 제곱은 $1,4,100$이다. 큰 오차 한 개가 평균을 지배할 수 있다. 이는 큰 실수를 강하게 줄여야 할 때 장점이지만, 센서 오류나 잘못된 라벨처럼 이상치가 있을 때는 단점이다. MSE가 항상 최고의 회귀 손실은 아니다. 평균절대오차나 Huber 손실 같은 대안은 이후에 다룬다.

#### MSE와 확률 모델의 연결

각 샘플의 정답이 서로 독립이고, 모델 예측 주변에서 같은 **고정된** 분산 $\sigma^2$의 가우시안 잡음을 가진다고 가정하자.

$$
y_i=\widehat{y}_i+\varepsilon_i,
\qquad
\varepsilon_i\sim\mathcal{N}(0,\sigma^2)
$$

이때 데이터의 음의 로그가능도는

$$
-\ln P(\mathbf{y}\mid\boldsymbol{\theta})
=\frac{N}{2}\ln(2\pi\sigma^2)
+\frac{1}{2\sigma^2}
\sum_{i=1}^{N}
(y_i-\widehat{y}_i)^2
$$

가 된다. $\sigma^2$가 고정되어 있으면 첫 항은 모델 파라미터에 관해 상수이므로, 이 가능도를 최대화하는 파라미터와 MSE를 최소화하는 파라미터가 같다. 즉, MSE는 단순한 취향이 아니라 특정한 잡음 가정 아래 최대가능도 추정과 연결된다. 실제 오차 분포가 크게 다르면 이 가정도 다시 점검해야 한다.

### 4.3 이진 교차 엔트로피: 정답 사건의 확률을 평가한다

4.3절부터 4.5절까지는 **샘플 하나의 손실**을 $\ell$로 쓰고, 샘플 $N$개의 평균 손실은 $L=(1/N)\sum_i\ell_i$로 구분한다.

두 범주 문제에서 정답을 $y\in\{0,1\}$, 모델이 $y=1$에 주는 확률을 $p$라 하자. 정답의 가능도는

$$
P(y\mid p)=p^y(1-p)^{1-y}
$$

로 한 식에 쓸 수 있다.

- $y=1$이면 $P(y\mid p)=p$다.
- $y=0$이면 $P(y\mid p)=1-p$다.

가능도를 크게 만드는 것과 음의 로그가능도를 작게 만드는 것은 같은 목표다. 로그를 취하면 곱이 합으로 바뀌고 계산도 쉬워진다.

$$
\boxed{
\ell_{\mathrm{BCE}}
=-\left[
y\ln p+(1-y)\ln(1-p)
\right]
}
$$

정답이 $y=1$이면 $\ell=-\ln p$다.

| $p$ | 해석 | $-\ln p$ |
|---:|---|---:|
| $0.99$ | 정답에 매우 확신 | 약 $0.010$ |
| $0.50$ | 반반 | 약 $0.693$ |
| $0.01$ | 정답과 반대로 매우 확신 | 약 $4.605$ |

틀린 확신을 크게 벌주기 때문에 정확도보다 훨씬 풍부한 학습 신호를 준다.

여러 라벨을 동시에 가질 수 있는 다중 라벨 문제에서는 라벨마다 독립적인 Sigmoid 확률과 BCE를 사용한다. 이 확률들은 서로 배타적인 범주가 아니므로 합이 $1$일 필요가 없다.

### 4.4 Sigmoid와 BCE가 만나면 로짓 그래디언트가 $p-y$가 된다

이진 분류 뉴런의 로짓과 확률을

$$
z=\mathbf{w}^{\top}\mathbf{x}+b,
\qquad
p=\sigma(z)
$$

라고 하자. 먼저 BCE를 $p$로 미분하면

$$
\frac{\partial\ell}{\partial p}
=-\frac{y}{p}
+\frac{1-y}{1-p}
$$

이다. Sigmoid의 미분은

$$
\frac{dp}{dz}=p(1-p)
$$

이므로 연쇄법칙에 따라

$$
\begin{aligned}
\frac{\partial\ell}{\partial z}
&=\frac{\partial\ell}{\partial p}
\frac{dp}{dz}\\
&=\left(
-\frac{y}{p}
+\frac{1-y}{1-p}
\right)p(1-p)\\
&=-y(1-p)+(1-y)p\\
&=\boxed{p-y}
\end{aligned}
$$

이다. 이어서

$$
\boxed{
\nabla_{\mathbf{w}}\ell=(p-y)\mathbf{x}
}
$$

$$
\boxed{
\frac{\partial\ell}{\partial b}=p-y
}
$$

를 얻는다. 분류 확률이 정답보다 크면 양의 신호, 작으면 음의 신호가 전달된다.

예를 들어 $z=0$이면 $p=0.5$다. 정답이 $y=1$일 때

$$
\ell=-\ln0.5=\ln2\approx0.693,
\qquad
\frac{\partial\ell}{\partial z}=0.5-1=-0.5
$$

이다. 입력이 $\mathbf{x}=[2,1]^{\top}$이라면

$$
\nabla_{\mathbf{w}}\ell
=-0.5
\begin{bmatrix}
2\\
1
\end{bmatrix}
=
\begin{bmatrix}
-1\\
-0.5
\end{bmatrix}
$$

이다.

샘플 $N$개의 BCE를 평균내면

$$
L_{\mathrm{BCE}}
=\frac{1}{N}\sum_{i=1}^{N}\ell_i,
\qquad
\nabla_{\mathbf{w}}L_{\mathrm{BCE}}
=\frac{1}{N}\sum_{i=1}^{N}(p_i-y_i)\mathbf{x}_i
$$

가 된다. `sum` 리덕션을 사용하면 $1/N$이 붙지 않는다.

### 4.5 다중분류 교차 엔트로피: 정답 범주의 로짓을 상대적으로 끌어올린다

$K$개 범주의 로짓을 $z_1,\dots,z_K$라 하자. Softmax는 이를 확률로 바꾼다.

$$
p_k
=\frac{e^{z_k}}
{\sum_{j=1}^{K}e^{z_j}}
$$

정답 원-핫 벡터를 $\mathbf{y}$라 하면 다중분류 교차 엔트로피는

$$
\boxed{
\ell_{\mathrm{CE}}
=-\sum_{k=1}^{K}y_k\ln p_k
}
$$

이다. 정답 범주의 인덱스를 $t$라 하면 $y_t=1$이고 나머지는 $0$이므로

$$
\ell_{\mathrm{CE}}=-\ln p_t
$$

이다. Softmax 식을 넣으면

$$
\begin{aligned}
\ell_{\mathrm{CE}}
&=-\sum_{k=1}^{K}y_k
\left[
z_k-\ln\left(\sum_{j=1}^{K}e^{z_j}\right)
\right]\\
&=-\sum_{k=1}^{K}y_kz_k
+\left(\sum_{k=1}^{K}y_k\right)
\ln\left(\sum_{j=1}^{K}e^{z_j}\right)\\
&=-z_t+\ln\left(\sum_{j=1}^{K}e^{z_j}\right)
\end{aligned}
$$

이다. 마지막 줄에서는 원-핫 정답의 성질 $\sum_k y_k=1$과 $\sum_k y_kz_k=z_t$를 사용했다. 이제 로짓 $z_k$로 편미분하면

$$
\begin{aligned}
\frac{\partial\ell_{\mathrm{CE}}}{\partial z_k}
&=-\frac{\partial z_t}{\partial z_k}
+\frac{1}{\sum_j e^{z_j}}
\frac{\partial}{\partial z_k}
\sum_j e^{z_j}\\
&=-\mathbb{1}[k=t]
+\frac{e^{z_k}}{\sum_j e^{z_j}}\\
&=-y_k+p_k\\
&=\boxed{p_k-y_k}
\end{aligned}
$$

여기서 $\mathbb{1}[k=t]$는 조건이 참이면 $1$, 거짓이면 $0$인 지시 함수이며 원-핫 성분 $y_k$와 같다.

가 된다. 정답 범주에는 $p_t-1<0$인 신호가, 오답 범주에는 $p_k>0$인 신호가 생긴다.

로짓이

$$
\mathbf{z}
=
\begin{bmatrix}
2\\
1\\
0
\end{bmatrix}
$$

이면 확률은 약

$$
\mathbf{p}
\approx
\begin{bmatrix}
0.6652\\
0.2447\\
0.0900
\end{bmatrix}
$$

이다. 정답이 둘째 범주라면

$$
\ell=-\ln p_2
=-\ln(0.244728\ldots)
\approx1.4076
$$

이고

$$
\nabla_{\mathbf{z}}\ell
=\mathbf{p}-\mathbf{y}
\approx
\begin{bmatrix}
0.6652\\
-0.7553\\
0.0900
\end{bmatrix}
$$

이다. 세 성분의 합은 반올림 오차를 제외하면 $0$이다. 모든 로짓에 같은 상수를 더해도 Softmax 확률이 변하지 않으므로, 그래디언트도 공통 이동 방향에는 변화 신호를 주지 않는다.

배치 평균에서는

$$
L_{\mathrm{CE}}
=\frac{1}{N}\sum_{i=1}^{N}\ell_i,
\qquad
\frac{\partial L_{\mathrm{CE}}}{\partial z_{i,k}}
=\frac{1}{N}(p_{i,k}-y_{i,k})
$$

처럼 각 샘플의 로짓 그래디언트에도 $1/N$이 붙는다.

### 4.6 MSE와 교차 엔트로피 중 무엇을 써야 할까?

| 질문 | MSE | 교차 엔트로피 |
|---|---|---|
| 대표 문제 | 연속값 회귀 | 이진·다중 범주 분류, 다음 토큰 예측 |
| 비교 대상 | 예측값과 정답값의 거리 | 모델 확률분포와 정답분포 |
| 기본 확률 해석 | 고정 분산 가우시안 잡음 | Bernoulli 또는 범주형 분포의 음의 로그가능도 |
| 큰 실수 처리 | 오차 제곱으로 강하게 반영 | 정답에 거의 $0$ 확률을 준 틀린 확신을 강하게 반영 |
| 출력층과의 흔한 결합 | 선형 출력 | BCE는 Sigmoid, 다중 CE는 Softmax |

서로 배타적인 $K$개 범주 중 정답이 하나면 Softmax와 다중분류 CE를 사용한다. 한 샘플에 “고양이”와 “실내”처럼 여러 라벨이 동시에 참일 수 있으면 라벨별 Sigmoid와 BCE를 사용하며, 각 확률의 합은 $1$일 필요가 없다.

이 표는 흔한 기본 선택을 보여 줄 뿐 절대 법칙은 아니다. 확률값 자체를 회귀하거나 분포를 맞추는 문제처럼 목적에 따라 다른 조합도 가능하다. 핵심은 데이터가 무엇을 의미하고 어떤 오차를 줄이려는지 먼저 정하는 것이다.

### 4.7 오늘의 수학과 AI 부품을 1:1로 연결하기

| 수학 도구 | AI에서 맡는 역할 |
|---|---|
| 도함수 $dL/dw$ | 파라미터 하나를 움직였을 때 손실의 순간 변화율을 잰다. |
| 편미분 $\partial L/\partial\theta_j$ | 다른 파라미터를 고정한 좌표축 방향의 변화 신호를 잰다. |
| 그래디언트 $\nabla_{\boldsymbol{\theta}}L$ | 모든 파라미터에 필요한 1차 변화 정보를 같은 모양으로 모은다. |
| 내적 $\nabla L^{\top}\Delta\boldsymbol{\theta}$ | 특정 파라미터 이동이 손실을 늘릴지 줄일지 근사한다. |
| 코시–슈바르츠 부등식 | 음의 그래디언트가 같은 길이의 작은 이동 중 가장 빠른 감소 방향임을 보인다. |
| 연쇄법칙 | `파라미터 → 로짓 → 확률 → 손실`의 변화율을 이어 붙인다. |
| 제곱 함수 | 회귀 잔차의 부호를 없애고 큰 오차를 강조한다. |
| 로그 함수 | 정답 확률의 곱을 손실의 합으로 바꾸고 틀린 확신을 크게 벌준다. |
| MSE | 연속값 예측을 위한 스칼라 목적을 만든다. |
| 교차 엔트로피 | 분류 확률과 정답분포를 비교하는 스칼라 목적을 만든다. |

### 4.8 구현에서 꼭 지켜야 할 수치 안정성

수학식만 보고 $p=\sigma(z)$를 계산한 뒤 $\ln p$를 직접 구하면 큰 로짓에서 $p$가 컴퓨터의 유한한 정밀도 때문에 정확히 $0$이나 $1$로 반올림될 수 있다. 그러면 $\ln0$이 발생한다.

실제 프레임워크는 로짓에서 직접 안정적으로 계산하는 결합 연산을 제공한다.

- PyTorch의 `BCEWithLogitsLoss`에는 **확률이 아니라 로짓**을 넣는다. 내부에서 Sigmoid와 BCE를 안정적으로 결합한다.
- PyTorch의 `CrossEntropyLoss`에는 **Softmax를 거치지 않은 로짓**을 넣는다. 단일 정답 범주 문제의 기본 타깃은 보통 원-핫 벡터가 아니라 정수 범주 인덱스다.
- 샘플 손실을 평균내는지 더하는지 확인해야 한다. `mean`과 `sum`은 같은 최적점을 가질 수 있어도 그래디언트 크기가 다르다.

다중분류에서는 다음과 같은 `log-sum-exp` 형태를 사용한다.

$$
\ln\left(\sum_j e^{z_j}\right)
=m+\ln\left(\sum_j e^{z_j-m}\right),
\qquad
m=\max_j z_j
$$

가장 큰 로짓 $m$을 먼저 빼면 지수값이 폭발하는 것을 막으면서 결과는 정확히 유지된다.

### 4.9 초보자가 흔히 하는 오해와 주의할 점

#### 오해 1: “미분은 $0$으로 나누는 계산이다.”

도함수는 $h=0$을 대입한 비율이 아니라 $h\ne0$인 평균 변화율의 **극한**이다.

#### 오해 2: “편미분하면 다른 변수의 영향이 사라진다.”

다른 변수를 영원히 무시하는 것이 아니다. 한 좌표 방향의 민감도를 분리해서 재는 순간에만 고정한다. 전체 변화는 그래디언트와 이동 벡터의 내적으로 합쳐진다.

#### 오해 3: “그래디언트가 가리키는 쪽으로 가면 손실이 줄어든다.”

그래디언트는 가장 빠른 **증가** 방향이다. 국소적으로 줄이는 방향은 음의 그래디언트다.

#### 오해 4: “그래디언트가 $0$이면 학습이 끝난 최솟값이다.”

최댓값, 안장점, 평평한 구간에서도 그래디언트가 $0$일 수 있다. 수치적으로 매우 작다는 사실도 전역 최적을 보장하지 않는다.

#### 오해 5: “손실과 정확도는 같은 값이다.”

손실은 파라미터 변화에 민감한 학습용 목적이고, 정확도는 특정 임계값 뒤의 정답 개수를 세는 평가 지표다. 손실이 줄어도 원하는 제품 지표가 반드시 좋아지는 것은 아니다.

#### 오해 6: “MSE는 이상치에도 안전하다.”

제곱 때문에 큰 잔차의 영향이 급격히 커진다. 이상치가 데이터 오류인지 중요한 드문 사례인지 먼저 판단해야 한다.

#### 오해 7: “교차 엔트로피에는 예측 범주 번호를 그대로 넣는다.”

손실의 수학적 입력은 확률분포와 정답분포다. 프레임워크가 정수 범주 인덱스를 받는 경우 내부에서 그 인덱스를 원-핫 정답과 같은 의미로 처리한다.

#### 오해 8: “Softmax나 Sigmoid를 먼저 적용할수록 안전하다.”

결합 손실 함수가 로짓을 직접 받도록 설계된 경우 먼저 적용하면 중복 계산과 수치 불안정을 만들 수 있다. API 계약을 확인해야 한다.

#### 오해 9: “교차 엔트로피가 낮으면 확률이 완벽하게 보정됐다.”

학습·검증 분포에서 낮은 평균 손실은 유용한 신호지만, 분포 이동과 데이터 오염, 하위 집단별 오류를 숨길 수 있다. 예측 확률이 실제 빈도와 맞는지를 보는 **보정 평가**, 입력이 조금 달라져도 성능을 유지하는지를 보는 **강건성 평가**, 안전 평가가 별도로 필요하다.

#### 오해 10: “ReLU는 $0$에서 미분되므로 항상 같은 도함수를 가진다.”

ReLU는 $0$에서 왼쪽 기울기 $0$과 오른쪽 기울기 $1$이 달라 고전적으로 미분되지 않는다. 딥러닝 프레임워크는 최적화 계산을 계속하기 위해 미분되지 않는 점에서 대신 사용할 수 있는 허용 기울기인 **부분기울기** 중 특정 값을 관례로 선택한다.

### 5.1 GPT-6 Astra: 긴 에이전트 작업의 핵심이 “한 번의 답”에서 “변화 가능한 실행”으로

**오늘의 수학과 연결**

모델의 사전학습 손실 $L_{\mathrm{train}}$ 하나가 낮다고 해서 장기 에이전트가 제품에서 잘 작동한다는 뜻은 아니다. 실제 시스템은 다음처럼 여러 평가량을 가진다.

$$
\mathbf{m}
=
\begin{bmatrix}
\text{과업 완수율}\\
\text{총 지연 시간}\\
\text{토큰·도구 비용}\\
\text{사람 개입 횟수}\\
\text{안전 위반율}
\end{bmatrix}
$$

이를 하나의 운영 목적 함수로 합치려면 예를 들어

$$
J
=\lambda_1L_{\mathrm{failure}}
+\lambda_2C_{\mathrm{latency}}
+\lambda_3C_{\mathrm{money}}
+\lambda_4R_{\mathrm{safety}}
$$

처럼 가중치를 정해야 한다. 어떤 $\lambda_j$를 택하느냐에 따라 “좋은 에이전트”의 방향이 달라진다. 손실 함수를 설계한다는 것은 곧 시스템이 무엇을 중요하게 여길지 정하는 일이다.

### 5.2 arm-gemma-e4b: 교차 엔트로피를 낮추는 데이터의 “방향”이 능력을 결정한다

COPA 연구팀은 2026-09-03 arXiv 사전논문 v1을 제출하고, 다음 날 공개 글을 통해 아르메니아어 LLM 생태계를 공개했다.

- **ArmWeb:** 전역 중복 제거와 평가셋 오염 제거를 거친 아르메니아어 뉴스 $437$만 문서, Gemma-4 토크나이저 기준 약 $33$억 토큰
- **ArmSTEM:** 영어–아르메니아어 수학·과학 문제 $37.3$만 쌍, 그중 $32.4$만 개는 단계별 풀이 포함
- **arm-gemma-e4b:** Gemma-4-E4B를 총 $100$억 토큰으로 계속 사전학습한 기본 모델
- **공개 범위:** 말뭉치 파이프라인, 번역·검증 절차, 학습 혼합비와 하이퍼파라미터, 평가 설정, 모델 가중치

공개 학습 혼합비는 ArmWeb $69\%$, 아르메니아어 ArmSTEM $4\%$, 영어 ArmSTEM $2\%$, 영어 FineWeb-Edu 리플레이 $20\%$, 코드 Stack-smol $5\%$다. 시퀀스 길이는 $4096$, 전역 배치는 $512$개 시퀀스, 학습률은 $3\times10^{-5}$ 코사인 스케줄이며 시드는 $42$다. 모델 카드는 이 체크포인트가 지시 튜닝이나 채팅 템플릿이 없는 **기본 모델**임을 명시한다. 기본 구조의 컨텍스트 상한은 $128$K지만 계속 사전학습은 길이 $4096$까지만 사용했으며, 그보다 긴 문맥의 동작은 별도로 평가하지 않았다.

언어모델의 다음 토큰 학습은 다중분류 교차 엔트로피다. 문맥 $x_{<t}$ 뒤의 실제 토큰을 $x_t$라 하자. $T$는 손실을 평균낼 토큰 수, $p_{t,k}$는 위치 $t$에서 어휘의 $k$번째 토큰에 준 모델 확률, $y_{t,k}$는 실제 토큰이 그 항목이면 $1$인 원-핫 정답 성분이다. 토큰 하나의 손실과 전체 평균은

$$
\ell_t
=-\ln P_{\boldsymbol{\theta}}
\left(x_t\mid x_{<t}\right),
\qquad
L_{\mathrm{LM}}
=\frac{1}{T}\sum_{t=1}^{T}\ell_t
$$

이다. 각 토큰의 로짓 $z_{t,k}$에 대한 그래디언트는 오늘 유도한 것과 똑같이

$$
\frac{\partial\ell_t}{\partial z_{t,k}}
=p_{t,k}-y_{t,k},
\qquad
\frac{\partial L_{\mathrm{LM}}}{\partial z_{t,k}}
=\frac{1}{T}(p_{t,k}-y_{t,k})
$$

이다. 그러나 **어떤 토큰을 얼마나 자주 보여 주는가**가 평균 그래디언트의 방향을 바꾼다. 각 데이터 출처에서의 평균 손실을 $L_s$라 정의하면 공개 혼합비의 전체 목적은

$$
\begin{aligned}
L_{\mathrm{mixture}}
&=0.69L_{\mathrm{ArmWeb}}
+0.04L_{\mathrm{STEM\text{-}HY}}\\
&\quad+0.02L_{\mathrm{STEM\text{-}EN}}
+0.20L_{\mathrm{English}}
+0.05L_{\mathrm{code}}
\end{aligned}
$$

이고 미분의 선형성에 따라

$$
\begin{aligned}
\nabla L_{\mathrm{mixture}}
&=0.69\nabla L_{\mathrm{ArmWeb}}
+0.04\nabla L_{\mathrm{STEM\text{-}HY}}\\
&\quad+0.02\nabla L_{\mathrm{STEM\text{-}EN}}
+0.20\nabla L_{\mathrm{English}}
+0.05\nabla L_{\mathrm{code}}
\end{aligned}
$$

이다. 실제 미니배치의 그래디언트는 표본 구성에 따라 흔들리지만, 혼합비대로 무작위 추출할 때의 기대값은 이 가중합을 따른다. 혼합비가 단순한 데이터 관리 숫자가 아니라 파라미터가 향할 평균 방향을 정하는 계수인 이유다.

저자들의 6개 과제 제로샷 우도 평가에서 공개 모델의 평균 정확도는 기본 Gemma-4-E4B의 $0.48$에서 $0.50$으로 올랐다. 반면 뉴스 중심 데이터와 높은 학습률 $10^{-4}$를 사용한 대조군은 평균이 $0.41$로 떨어졌고, Belebele 아르메니아어 독해 점수는 기본 모델 $0.619$에서 $0.407$로 하락했다. $3\times10^{-5}$의 더 작은 학습률과 소량의 검증된 STEM 데이터를 섞은 공개 모델은 Belebele $0.716$을 보고했다. 낮은 학습률과 ArmSTEM 혼합이 이 설정에서 망각을 상쇄한 사례다. 다만 저자들은 STEM 내용, 질문답변 형식, 번역 검증의 기여를 분리하지 못했다.

**엔지니어 인사이트 (Impact)**

- “저자원 언어 데이터를 더 넣는다”만으로 충분하지 않다. 도메인이 좁은 뉴스 교차 엔트로피를 계속 줄이면 독해·지식 능력이 약해질 수 있다. 언어, 도메인, 형식의 혼합비를 최적화 변수처럼 다뤄야 한다.
- 학습 손실이 내려가도 벤치마크 오염으로 평가가 부풀 수 있다. 이 프로젝트는 $13$-gram 중복 검사와 시간상 뒤쪽의 테스트 분할을 제공한다. 데이터 계보와 디컨태미네이션은 모델 크기만큼 중요한 엔지니어링 자산이다.
- 공개 재현성에도 경계가 있다. 코드 저장소는 한 $100$억 토큰 실행에 H100 $128$장에서 약 $10$시간이 걸린다고 적는다. 원시 뉴스 크롤 데이터베이스는 재배포되지 않으며, 공개 ArmWeb은 그 파이프라인의 출력물이다. 누구나 공개 파일을 볼 수 있다는 것과 원자료부터 같은 비용으로 전 과정을 재현할 수 있다는 것은 다르다.
- 논문 표 7의 다섯 계속 사전학습 설정은 각각 단일 학습 실행이라 시드 평균이 없다. ArmBench 품사 태깅 정확도는 기본 모델 $0.180$에서 News-CPT $0.000$, 공개 모델 $0.010$, STEM-CPT-full $0.000$으로 모두 하락했다.
- 라이선스도 하나로 뭉뚱그리면 안 된다. 코드 저장소는 MIT, ArmWeb 묶음은 ODC-BY 1.0이지만 원문 권리는 각 게시자에게 남고, ArmSTEM은 원본별 라이선스를 따르며, 모델은 Gemma 이용 조건을 따른다. 모델에는 별도 안전 튜닝도 없다.

### 5.3 두 소식에서 읽어야 할 하나의 흐름

두 사례의 공통점은 **좋은 모델을 단일 숫자로 정의할 수 없다는 것**이다.

- Astra는 긴 컨텍스트와 도구 호출 능력을 제공하지만, 실제 가치는 완료율·지연·비용·안전이라는 제품 수준의 여러 목적에서 결정된다.
- arm-gemma-e4b는 같은 다음 토큰 교차 엔트로피를 사용해도 데이터 혼합비가 달라지면 언어 유창성, 독해, 지식 사이의 이동 방향이 달라짐을 보여 준다.

손실 함수는 학습할 방향을 만들지만, 어떤 데이터를 평균내고 어떤 지표를 따로 측정할지는 사람이 정한다. 최신 AI 엔지니어링의 핵심은 더 큰 모델을 고르는 데서 끝나지 않고 **목적 함수, 데이터 분포, 시스템 평가를 함께 설계하는 것**이다.

## 6. 오늘의 메타인지 질문 (스스로 묻고 답하기)

### 질문

입력 $x=2$인 선형 점수 모델

$$
z=wx+b
$$

를 생각하자.

1. 회귀 문제에서 정답이 $y=5$, 현재 $(w,b)=(1,0)$이고 $L_{\mathrm{MSE}}=(z-y)^2$일 때 예측, 잔차, 손실, 그래디언트 $\nabla_{(w,b)}L$을 구하라.
2. 같은 점에서 손실을 가장 빠르게 줄이는 단위방향을 구하라. 그 방향이 왜 음의 그래디언트인지 내적으로 설명하라.
3. 별개의 이진분류 문제에서 정답이 $y=1$, 현재 $(w,b)=(0,0)$이고 $p=\sigma(z)$일 때 BCE, $\partial L/\partial z$, $\partial L/\partial w$, $\partial L/\partial b$를 구하라.
4. 두 문제의 그래디언트 크기가 다른 것이 왜 모순이 아닌지 설명하라.

### 모범 답안

회귀 문제에서는

$$
z=1\cdot2+0=2
$$

이고 잔차와 손실은

$$
e=z-y=2-5=-3
$$

$$
L=e^2=9
$$

이다. $z=wx+b$이므로

$$
\frac{\partial z}{\partial w}=x=2,
\qquad
\frac{\partial z}{\partial b}=1
$$

이다. 연쇄법칙으로

$$
\frac{\partial L}{\partial w}
=2e\frac{\partial z}{\partial w}
=2(-3)(2)
=-12
$$

$$
\frac{\partial L}{\partial b}
=2e\frac{\partial z}{\partial b}
=2(-3)(1)
=-6
$$

이므로

$$
\nabla_{(w,b)}L
=
\begin{bmatrix}
-12\\
-6
\end{bmatrix}
$$

이다.

그래디언트의 노름은

$$
\lVert\nabla L\rVert_2
=\sqrt{144+36}
=6\sqrt{5}
$$

이므로 가장 빠른 감소 단위방향은

$$
\mathbf{u}_{\min}
=-\frac{\nabla L}{\lVert\nabla L\rVert_2}
=
\begin{bmatrix}
2/\sqrt{5}\\
1/\sqrt{5}
\end{bmatrix}
$$

이다. 길이가 $1$인 임의의 $\mathbf{u}$에 대해 방향미분은 $\nabla L^{\top}\mathbf{u}$다. 코시–슈바르츠 부등식에 의해 그 최솟값은 $-\lVert\nabla L\rVert_2$이고, $\mathbf{u}$가 그래디언트의 정확한 반대 방향일 때 달성된다.

이진분류 문제에서는

$$
z=0\cdot2+0=0,
\qquad
p=\sigma(0)=0.5
$$

이다. 정답이 $1$이므로

$$
L_{\mathrm{BCE}}
=-\ln0.5
=\ln2
\approx0.693
$$

이고

$$
\frac{\partial L}{\partial z}
=p-y
=0.5-1
=-0.5
$$

이다. 따라서

$$
\frac{\partial L}{\partial w}
=\frac{\partial L}{\partial z}
\frac{\partial z}{\partial w}
=(-0.5)(2)
=-1
$$

$$
\frac{\partial L}{\partial b}
=\frac{\partial L}{\partial z}
\frac{\partial z}{\partial b}
=(-0.5)(1)
=-0.5
$$

이다.

두 그래디언트가 다른 것은 모순이 아니다. 첫 문제는 연속값 $5$와 선형 출력 $2$ 사이의 제곱거리를 재고, 둘째 문제는 정답 사건에 준 확률 $0.5$의 음의 로그가능도를 잰다. **손실의 정의와 현재 파라미터 위치가 다르면 지형의 단위와 기울기도 달라진다.** 그래디언트는 보편적인 “틀림의 양”이 아니라 선택한 목적 함수가 현재 위치에서 변하는 비율이다.
