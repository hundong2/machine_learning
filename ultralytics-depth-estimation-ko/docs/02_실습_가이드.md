# 단계별 실습 가이드

## 실습 0. 환경 확인

```powershell
python scripts/check_environment.py
```

확인 질문:

1. CUDA를 사용할 수 있는가?
2. 설치된 Ultralytics가 `8.4.115` 이상인가?
3. 실습 장치로 `cpu`와 `0` 중 무엇을 선택해야 하는가?

## 실습 1. 공식 예제 이미지 추론

```powershell
python scripts/predict_depth.py `
  --source "https://ultralytics.com/images/bus.jpg" `
  --model yolo26n-depth.pt `
  --device cpu
```

출력 로그에서 유효 픽셀의 최소값, 중앙값, 평균값, 최대값과 중심 픽셀의 깊이를 확인합니다. 최솟값과 최댓값은 이상치의 영향을 크게 받으므로 장면의 전형적인 거리는 중앙값이 더 안정적으로 보여 줍니다.

관찰 과제:

- `depth_colored.png`와 `depth_metric.png`의 색 의미가 왜 반대인가?
- 하늘이나 반사면의 값이 믿을 만한가?
- 버스, 사람, 배경 건물의 상대적 순서가 자연스러운가?

## 실습 2. 내 이미지와 관심 좌표 분석

```powershell
python scripts/predict_depth.py `
  --source ".\my_scene.jpg" `
  --point 320 240 `
  --metric-max 30 `
  --output-dir ".\outputs\my_scene"
```

`--point X Y`는 원본 이미지 좌표계의 한 픽셀 깊이를 출력합니다. 한 픽셀 값은 잡음에 민감하므로 실제 응용에서는 관심 영역의 중앙값을 사용하는 편이 좋습니다.

도전 과제: `predict_depth.py`에 `--roi X1 Y1 X2 Y2` 옵션을 추가해 영역 내 유효 깊이의 중앙값을 출력해 보세요.

## 실습 3. NumPy 깊이 맵 분석

```python
from pathlib import Path
import numpy as np

depth = np.load(Path("outputs/depth_raw.npy"))
valid = np.isfinite(depth) & (depth > 0)

print("shape:", depth.shape)
print("dtype:", depth.dtype)
print("valid ratio:", valid.mean())
print("p10/p50/p90:", np.percentile(depth[valid], [10, 50, 90]))
```

과제:

- `depth < 3.0`인 픽셀을 장애물 후보 마스크로 만들어 보세요.
- 작은 고립 영역을 제거하기 위해 morphology opening을 적용해 보세요.
- 임곗값 2 m, 3 m, 5 m에서 마스크 면적 비율을 비교해 보세요.

## 실습 4. 사용자 데이터셋 구조 검사

데이터를 공식 형식으로 배치한 뒤 검사합니다.

```powershell
python scripts/validate_depth_dataset.py --root D:\datasets\my_depth
```

검사기는 다음을 확인합니다.

- `images/train`, `images/val`, `depth/train`, `depth/val` 존재 여부
- 각 RGB 이미지에 대응하는 `.npy` 파일 존재 여부
- 깊이 배열이 2차원인지, 이미지 해상도와 일치하는지
- dtype, 유효값 비율, 음수·NaN·무한대 포함 여부
- 깊이 파일만 있고 이미지가 없는 고아 파일 여부

## 실습 5. Depth8로 학습 흐름 익히기

먼저 1 epoch으로 파이프라인만 확인합니다.

```powershell
yolo depth train model=yolo26n-depth.pt data=depth8.yaml epochs=1 imgsz=640 device=cpu
```

GPU가 있으면 `device=0`을 사용합니다. 이 실험은 모델 품질 향상이 목적이 아니라 다운로드, 데이터 로딩, 손실 계산, 체크포인트 저장 흐름을 확인하는 스모크 테스트입니다.

정식 예시는 100 epochs입니다.

```powershell
yolo depth train model=yolo26n-depth.pt data=depth8.yaml epochs=100 imgsz=640 device=0
```

## 실습 6. 사용자 데이터 미세조정

```powershell
yolo depth train `
  model=yolo26s-depth.pt `
  data=D:\datasets\my_depth\dataset.yaml `
  epochs=20 `
  imgsz=640 `
  optimizer=AdamW `
  lr0=0.0001 `
  warmup_bias_lr=0.0001 `
  device=0
```

데이터가 작을 때는 학습/검증 장면이 거의 같아지는 누수를 특히 조심합니다. 같은 동영상의 인접 프레임을 무작위로 나누기보다 촬영 장소나 시퀀스 단위로 분할하세요.

## 실습 7. 검증, 보정, 내보내기

```powershell
yolo depth val model=path\to\best.pt data=D:\datasets\my_depth\dataset.yaml imgsz=768 device=0
yolo export model=path\to\best.pt format=onnx imgsz=768
```

Python에서 스케일만 보정하려면:

```python
from ultralytics import YOLO

model = YOLO("path/to/best.pt")
model.calibrate(data=r"D:\datasets\my_depth\dataset.yaml")
model.save("best-calibrated.pt")
```

보정 전후에 같은 고정 검증 세트로 상대 구조와 절대 오차를 모두 비교하세요.
