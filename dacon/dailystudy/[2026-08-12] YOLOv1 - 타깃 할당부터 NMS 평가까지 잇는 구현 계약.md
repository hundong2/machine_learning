## 1. 원본과 1회차에서 이번에 확장하는 것

원본은 YOLOv1 출력이 $S\times S\times(5B+C)$라는 점과 SSE 손실의 큰 구조를 설명한다. 그러나 실제 구현 전에 다음 경계를 고정해야 한다.

| 원본 또는 흔한 축약 | 이번 구현 계약 |
| --- | --- |
| 합의 upper bound를 $S^2$, $B$로 표기 | index가 0부터 시작하면 마지막 index는 각각 $S^2-1$, $B-1$이다. 코드에서는 shape와 mask로 합의 범위를 고정한다. |
| `Linear(1024, S*S*(5B+C))`만 제시 | 이는 head 예시일 뿐 완전한 YOLOv1 backbone 재현이 아니다. 오늘은 head 입출력과 파이프라인을 독립 테스트한다. |
| 객체 중심이 속한 cell이 책임짐 | 같은 cell에 여러 중심이 들어오면 YOLOv1 target 한 벌로는 모두 표현할 수 없다. collision policy가 필요하다. |
| 책임 없는 상자는 철저히 무시 | 좌표와 class에는 참여하지 않지만 no-object confidence 항에는 참여한다. |
| confidence는 객체 확률과 IoU의 곱 | 학습 target은 책임 predictor에서 현재 예측과 정답의 IoU다. 추론에는 정답이 없으므로 model confidence만 사용한다. |
| NMS로 중복 제거 | class별인지 class-agnostic인지, score 동점 규칙과 최대 후보 수까지 계약에 포함해야 한다. |
| mAP가 궁극의 단일 정확도 | IoU threshold, 보간 규칙, class 평균 범위에 따라 값이 달라진다. evaluator 버전을 함께 기록한다. |

1회차 Part 1은 좌표식과 손실 직관을 설명했다. 오늘 새로 추가하는 핵심은 다음과 같다.

1. collision을 세고 실패시키는 target builder
2. raw tensor부터 책임 mask까지 이어지는 실행 가능한 loss
3. class별 NMS와 all-points interpolated AP
4. 빈 이미지와 경계값을 포함한 dependency-free test harness
5. 고정 seed 학습의 exact replay와 loss ablation

## 2. annotation에서 cell target으로

### 2.1 입력 계약

이미지 하나의 annotation은 다음 shape을 사용한다.

```text
[M, 5] = [class_id, cx, cy, width, height]
```

모든 좌표는 resize 이후 이미지에 대해 $[0,1]$로 정규화한다. class id는 $0\le k<C$인 정수다. 유효한 상자는 다음 조건을 만족한다.

$$
0 \le c_x \le 1,\quad 0 \le c_y \le 1
$$

$$
0 < w \le 1,\quad 0 < h \le 1
$$

중심이 정확히 1인 annotation을 그대로 두면 $\lfloor S\cdot1\rfloor=S$가 되어 배열 밖을 가리킨다. 따라서 cell index는 다음처럼 clamp한다.

$$
c=\min(\lfloor S c_x\rfloor,S-1)
$$

$$
r=\min(\lfloor S c_y\rfloor,S-1)
$$

cell 안 offset은 다음과 같다.

$$
t_x=S c_x-c,\qquad t_y=S c_y-r
$$

### 2.2 출력 계약

target builder는 세 tensor와 collision 수를 반환한다.

| 이름 | shape | dtype | 의미 |
| --- | --- | --- | --- |
| `target_box` | `[N,S,S,4]` | `float32` | `tx,ty,w,h` |
| `target_class` | `[N,S,S,C]` | `float32` | one-hot class |
| `object_mask` | `[N,S,S]` | `bool` | 객체를 기록한 cell |
| `collisions` | scalar | integer | 같은 cell에 추가로 들어온 객체 수 |

`target_box`에는 predictor 축이 없다. YOLOv1의 cell class target은 한 벌이고, 어느 predictor가 좌표를 맡을지는 현재 예측의 IoU를 보고 loss 안에서 정한다.

### 2.3 충돌 정책

중심이 같은 cell에 들어온 두 객체를 마지막 annotation으로 조용히 덮어쓰면 annotation 순서가 학습 target을 바꾼다. 오늘 구현은 기본적으로 `collision="error"`를 사용한다. 데이터 감사 단계에서는 오류로 중단하고 충돌률을 기록한다.

$$
\text{collision rate}
=
\frac{\text{충돌로 표현하지 못한 객체 수}}
{\text{전체 유효 객체 수}}
$$

교육용 ablation에서는 `largest` 정책도 비교할 수 있다. 같은 cell에서는 면적 $wh$가 큰 객체를 유지하지만, 이것은 모델의 구조적 한계를 감추는 임시 정책이지 정답 복구가 아니다.

## 3. 수작업으로 assignment 검산하기

$S=2$이고 정답이 다음과 같다고 하자.

$$
g=(c_x,c_y,w,h)=(0.75,0.25,0.40,0.20)
$$

cell은 다음과 같다.

$$
c=\lfloor2\cdot0.75\rfloor=1,\qquad
r=\lfloor2\cdot0.25\rfloor=0
$$

offset은 다음과 같다.

$$
t_x=2\cdot0.75-1=0.5,\qquad
t_y=2\cdot0.25-0=0.5
$$

따라서 `target_box[0, 0, 1]`은 `[0.5, 0.5, 0.4, 0.2]`다. 다시 이미지 좌표로 복원하면 다음과 같다.

$$
c_x=\frac{c+t_x}{S}=\frac{1+0.5}{2}=0.75
$$

$$
c_y=\frac{r+t_y}{S}=\frac{0+0.5}{2}=0.25
$$

### NumPy oracle

다음은 **실행 가능한 독립 검증 예제**다. PyTorch 구현을 호출하지 않고 assignment와 round trip을 검사한다.

```python
import numpy as np


def encode_one(box, grid_size):
    cx, cy, width, height = map(float, box)
    if not (0.0 <= cx <= 1.0 and 0.0 <= cy <= 1.0):
        raise ValueError("center must be in [0, 1]")
    if not (0.0 < width <= 1.0 and 0.0 < height <= 1.0):
        raise ValueError("width and height must be in (0, 1]")
    col = min(int(np.floor(grid_size * cx)), grid_size - 1)
    row = min(int(np.floor(grid_size * cy)), grid_size - 1)
    target = np.array(
        [grid_size * cx - col, grid_size * cy - row, width, height],
        dtype=np.float64,
    )
    return row, col, target


def decode_one(row, col, target, grid_size):
    tx, ty, width, height = map(float, target)
    return np.array(
        [(col + tx) / grid_size, (row + ty) / grid_size, width, height]
    )


box = np.array([0.75, 0.25, 0.40, 0.20])
row, col, encoded = encode_one(box, grid_size=2)
decoded = decode_one(row, col, encoded, grid_size=2)
assert (row, col) == (0, 1)
assert np.allclose(encoded, [0.5, 0.5, 0.4, 0.2])
assert np.allclose(decoded, box)

# 오른쪽·아래 경계도 마지막 cell로 clamp한다.
edge_row, edge_col, edge = encode_one([1.0, 1.0, 0.1, 0.1], 2)
assert (edge_row, edge_col) == (1, 1)
assert np.allclose(edge[:2], [1.0, 1.0])
print("numpy oracle passed:", row, col, encoded.tolist())
```

`tx=1`은 반열린 cell 구간만 허용하는 구현에서는 거부할 수 있다. 여기서는 annotation 중심의 닫힌 구간 $[0,1]$을 받아 마지막 cell의 오른쪽·아래 경계로 보존한다. 학습 augmentation이 좌표를 만들 때는 보통 $[0,1)$로 clamp해 이 특수값을 피하는 편이 단순하다.

## 4. raw head의 shape와 layout

PyTorch convolution head는 보통 다음 shape을 출력한다.

$$
R\in\mathbb{R}^{N\times(5B+C)\times S\times S}
$$

사람이 읽기 쉬운 논리 view로 바꾸면 다음과 같다.

$$
P=\operatorname{permute}(R,0,2,3,1)
\in\mathbb{R}^{N\times S\times S\times(5B+C)}
$$

마지막 축을 분리한다.

| slice | shape | 활성화 | 뜻 |
| --- | --- | --- | --- |
| `[..., :4*B]` | `[N,S,S,B,4]` | `sigmoid` | `tx,ty,w,h` |
| `[..., 4*B:5*B]` | `[N,S,S,B]` | `sigmoid` | confidence |
| `[..., 5*B:]` | `[N,S,S,C]` | `softmax` | 조건부 class 확률 |

오늘의 작은 구현은 수치 안정성과 단순한 경계 보장을 위해 $w,h$에도 sigmoid를 사용한다. 이는 원 논문의 parameterization을 그대로 복제한 것이 아니다. 책임 mask와 loss 구조를 검증하는 교육용 변형이며 checkpoint에 `box_activation=sigmoid`를 기록해야 한다.

예를 들어 $N=8$, $S=7$, $B=2$, $C=20$이면 raw 출력은 `[8,30,7,7]`, 논리 view는 `[8,7,7,30]`이다.

## 5. 책임 predictor와 다섯 손실 항

### 5.1 cell 책임과 predictor 책임

`object_mask[n,r,c]=True`는 해당 cell에 객체가 있다는 뜻이다. 그 cell의 $B$개 predictor 중 좌표와 object confidence를 학습할 하나는 현재 예측 box와 정답 box의 IoU가 가장 큰 predictor다.

$$
j^{*}_{nrc}=\operatorname*{argmax}_{j\in\{0,\ldots,B-1\}}
\operatorname{IoU}(b_{nrcj},g_{nrc})
$$

$$
m_{resp,nrcj}=m_{cell,nrc}\mathbb{1}[j=j^{*}_{nrc}]
$$

`argmax` 선택 자체에는 gradient를 흘리지 않는다. 선택한 predictor의 좌표와 confidence에는 gradient가 흐른다.

### 5.2 좌표와 크기

중심 offset 손실은 다음과 같다.

$$
L_{xy}=\lambda_{coord}
\sum m_{resp}
\left[(t_x-\hat t_x)^2+(t_y-\hat t_y)^2\right]
$$

크기 손실은 큰 상자의 절대 오차가 지배하지 않도록 제곱근 공간에서 계산한다.

$$
L_{wh}=\lambda_{coord}
\sum m_{resp}
\left[(\sqrt{w}-\sqrt{\hat w})^2
+(\sqrt{h}-\sqrt{\hat h})^2\right]
$$

구현에서는 $\sqrt{0}$ 부근 gradient를 피하기 위해 작은 $\varepsilon$로 clamp한다.

### 5.3 confidence

책임 predictor의 confidence target은 현재 box와 정답의 IoU다.

$$
L_{obj}=\sum m_{resp}(q-\hat q)^2
$$

책임이 없는 모든 predictor의 confidence target은 0이다.

$$
L_{noobj}=\lambda_{noobj}\sum(1-m_{resp})\hat q^2
$$

여기에는 객체가 있는 cell의 비책임 predictor도 포함된다. 이 점을 빼먹으면 한 객체 cell에서 여러 predictor가 동시에 높은 confidence를 내기 쉽다.

### 5.4 class

class target은 predictor별이 아니라 객체 cell별 한 벌이다.

$$
L_{cls}=\sum m_{cell}\sum_{k=0}^{C-1}(p_k-\hat p_k)^2
$$

전체 손실은 positive cell 수 $N_{pos}$로 나눈다. 빈 batch에서도 0으로 나누지 않도록 분모를 1 이상으로 고정한다.

$$
L=\frac{L_{xy}+L_{wh}+L_{obj}+L_{noobj}+L_{cls}}
{\max(N_{pos},1)}
$$

원 논문과 수치까지 비교할 때는 reduction도 원 논문 구현에 맞춰야 한다. 오늘의 정규화는 batch 크기와 객체 수가 바뀔 때 gradient scale을 덜 흔들리게 하는 명시적 구현 선택이다.

## 6. 실행 가능한 PyTorch 학습·평가 파이프라인

다음 코드는 **실행 가능한 교육용 완전 예제**다. 작은 MLP head를 고정 synthetic batch에 학습하고, target assignment, loss, decode, class별 NMS, AP, 재현성 검사를 한 번에 수행한다. 실제 YOLOv1 backbone과 VOC 학습을 재현하는 코드는 아니지만 파이프라인의 tensor 계약은 끝까지 연결한다.

```python
import math
import random

import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F


def seed_everything(seed):
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    torch.use_deterministic_algorithms(True)


def cxcywh_to_xyxy(boxes):
    cx, cy, width, height = boxes.unbind(-1)
    return torch.stack(
        [cx - width / 2, cy - height / 2,
         cx + width / 2, cy + height / 2],
        dim=-1,
    )


def box_iou_aligned(left, right, eps=1e-9):
    left = cxcywh_to_xyxy(left)
    right = cxcywh_to_xyxy(right)
    top_left = torch.maximum(left[..., :2], right[..., :2])
    bottom_right = torch.minimum(left[..., 2:], right[..., 2:])
    intersection = (bottom_right - top_left).clamp_min(0).prod(-1)
    left_area = (left[..., 2:] - left[..., :2]).clamp_min(0).prod(-1)
    right_area = (right[..., 2:] - right[..., :2]).clamp_min(0).prod(-1)
    union = left_area + right_area - intersection
    return intersection / union.clamp_min(eps)


def build_targets(annotations, grid_size, classes, collision="error"):
    batch = len(annotations)
    target_box = torch.zeros(batch, grid_size, grid_size, 4)
    target_class = torch.zeros(batch, grid_size, grid_size, classes)
    object_mask = torch.zeros(batch, grid_size, grid_size, dtype=torch.bool)
    collisions = 0

    for n, image_targets in enumerate(annotations):
        for class_id, cx, cy, width, height in image_targets:
            class_id = int(class_id)
            if not 0 <= class_id < classes:
                raise ValueError("class id is out of range")
            if not (0 <= cx <= 1 and 0 <= cy <= 1):
                raise ValueError("center is out of range")
            if not (0 < width <= 1 and 0 < height <= 1):
                raise ValueError("invalid box size")
            col = min(int(grid_size * cx), grid_size - 1)
            row = min(int(grid_size * cy), grid_size - 1)
            encoded = torch.tensor(
                [grid_size * cx - col, grid_size * cy - row, width, height]
            )

            if object_mask[n, row, col]:
                collisions += 1
                if collision == "error":
                    raise ValueError(f"cell collision at image={n}, row={row}, col={col}")
                if collision != "largest":
                    raise ValueError("unknown collision policy")
                old_area = target_box[n, row, col, 2:].prod().item()
                if width * height <= old_area:
                    continue

            target_box[n, row, col] = encoded
            target_class[n, row, col].zero_()
            target_class[n, row, col, class_id] = 1.0
            object_mask[n, row, col] = True
    return target_box, target_class, object_mask, collisions


def split_predictions(raw, boxes, classes):
    if raw.ndim != 4 or raw.shape[1] != 5 * boxes + classes:
        raise ValueError("raw head shape mismatch")
    logical = raw.permute(0, 2, 3, 1)
    box = logical[..., : 4 * boxes].reshape(*logical.shape[:3], boxes, 4)
    confidence = logical[..., 4 * boxes : 5 * boxes]
    class_logits = logical[..., 5 * boxes :]
    return box.sigmoid(), confidence.sigmoid(), class_logits


def decode_grid_boxes(encoded):
    grid_size = encoded.shape[1]
    rows, cols = torch.meshgrid(
        torch.arange(grid_size, device=encoded.device),
        torch.arange(grid_size, device=encoded.device),
        indexing="ij",
    )
    center_x = (encoded[..., 0] + cols[None, :, :, None]) / grid_size
    center_y = (encoded[..., 1] + rows[None, :, :, None]) / grid_size
    return torch.stack(
        [center_x, center_y, encoded[..., 2], encoded[..., 3]], dim=-1
    )


def yolo_loss(raw, target_box, target_class, object_mask, boxes, classes,
              lambda_coord=5.0, lambda_noobj=0.5):
    encoded, confidence, class_logits = split_predictions(raw, boxes, classes)
    predicted_global = decode_grid_boxes(encoded)

    grid_size = raw.shape[-1]
    rows, cols = torch.meshgrid(
        torch.arange(grid_size, device=raw.device),
        torch.arange(grid_size, device=raw.device),
        indexing="ij",
    )
    target_global = target_box.clone()
    target_global[..., 0] = (target_box[..., 0] + cols) / grid_size
    target_global[..., 1] = (target_box[..., 1] + rows) / grid_size

    iou = box_iou_aligned(
        predicted_global,
        target_global.unsqueeze(-2).expand_as(predicted_global),
    )
    best = iou.detach().argmax(-1)
    responsible = F.one_hot(best, boxes).bool() & object_mask.unsqueeze(-1)

    expanded_target = target_box.unsqueeze(-2).expand_as(encoded)
    xy_error = (encoded[..., :2] - expanded_target[..., :2]).square().sum(-1)
    wh_error = (
        encoded[..., 2:].clamp_min(1e-6).sqrt()
        - expanded_target[..., 2:].clamp_min(1e-6).sqrt()
    ).square().sum(-1)
    coord = lambda_coord * ((xy_error + wh_error) * responsible).sum()

    objectness_target = iou.detach()
    object_loss = ((confidence - objectness_target).square() * responsible).sum()
    no_object_loss = lambda_noobj * (
        confidence.square() * (~responsible)
    ).sum()
    class_probability = class_logits.softmax(-1)
    class_loss = (
        (class_probability - target_class).square().sum(-1) * object_mask
    ).sum()
    positive_count = object_mask.sum().clamp_min(1)
    total = (coord + object_loss + no_object_loss + class_loss) / positive_count
    parts = {
        "coord": coord.detach() / positive_count,
        "object": object_loss.detach() / positive_count,
        "no_object": no_object_loss.detach() / positive_count,
        "class": class_loss.detach() / positive_count,
    }
    return total, parts, responsible


def pairwise_iou_xyxy(one, many, eps=1e-9):
    top_left = torch.maximum(one[:2], many[:, :2])
    bottom_right = torch.minimum(one[2:], many[:, 2:])
    intersection = (bottom_right - top_left).clamp_min(0).prod(-1)
    one_area = (one[2:] - one[:2]).clamp_min(0).prod()
    many_area = (many[:, 2:] - many[:, :2]).clamp_min(0).prod(-1)
    return intersection / (one_area + many_area - intersection).clamp_min(eps)


def nms(boxes, scores, threshold):
    # stable=True와 index tie-break로 동점 결과도 재현한다.
    order = torch.argsort(scores, descending=True, stable=True)
    keep = []
    while order.numel() > 0:
        current = int(order[0])
        keep.append(current)
        if order.numel() == 1:
            break
        rest = order[1:]
        order = rest[pairwise_iou_xyxy(boxes[current], boxes[rest]) <= threshold]
    return torch.tensor(keep, dtype=torch.long)


def decode_detections(raw, boxes, classes, score_threshold=0.25,
                      nms_threshold=0.5):
    encoded, confidence, class_logits = split_predictions(raw, boxes, classes)
    global_boxes = decode_grid_boxes(encoded)
    xyxy = cxcywh_to_xyxy(global_boxes).clamp(0, 1)
    class_probability = class_logits.softmax(-1)
    scores = confidence.unsqueeze(-1) * class_probability.unsqueeze(-2)

    results = []
    for n in range(raw.shape[0]):
        image_results = []
        flat_boxes = xyxy[n].reshape(-1, 4)
        flat_scores = scores[n].reshape(-1, classes)
        for class_id in range(classes):
            selected = flat_scores[:, class_id] >= score_threshold
            candidate_boxes = flat_boxes[selected]
            candidate_scores = flat_scores[selected, class_id]
            if candidate_scores.numel() == 0:
                continue
            kept = nms(candidate_boxes, candidate_scores, nms_threshold)
            for index in kept:
                image_results.append(
                    (class_id, float(candidate_scores[index]), candidate_boxes[index])
                )
        image_results.sort(key=lambda item: (-item[1], item[0]))
        results.append(image_results)
    return results


def interpolated_ap(recalls, precisions):
    recalls = np.concatenate(([0.0], np.asarray(recalls), [1.0]))
    precisions = np.concatenate(([0.0], np.asarray(precisions), [0.0]))
    for index in range(len(precisions) - 2, -1, -1):
        precisions[index] = max(precisions[index], precisions[index + 1])
    changed = np.where(recalls[1:] != recalls[:-1])[0]
    return float(np.sum((recalls[changed + 1] - recalls[changed]) * precisions[changed + 1]))


class TinyYolo(nn.Module):
    def __init__(self, input_dim=6, grid_size=2, boxes=2, classes=2):
        super().__init__()
        self.grid_size = grid_size
        self.channels = 5 * boxes + classes
        self.net = nn.Sequential(
            nn.Linear(input_dim, 32), nn.Tanh(),
            nn.Linear(32, grid_size * grid_size * self.channels),
        )

    def forward(self, features):
        raw = self.net(features)
        return raw.reshape(-1, self.channels, self.grid_size, self.grid_size)
```

### 구현 해석

- target builder는 annotation 순서 의존 collision을 기본적으로 오류 처리한다.
- `responsible.sum()==object_mask.sum()`이므로 객체 cell마다 정확히 한 predictor만 좌표를 맡는다.
- class loss는 cell별 한 번만 계산한다.
- no-object loss는 `~responsible` 전체에 적용한다.
- 재현성 검사는 loss history와 parameter를 `torch.equal`로 비교한다.
- ablation은 전체 loss가 아니라 객체 cell의 encoded box MAE를 비교한다.
- `decode_detections`는 class별 NMS를 적용하며, AP golden은 evaluator 계산 자체를 독립 검증한다.

실제 데이터셋에서는 학습용 augmentation, multi-worker loader, mixed precision, checkpoint resume, validation 전체 AP가 추가되어야 한다. 특히 synthetic batch 과적합은 구조 테스트이지 실제 정확도 증거가 아니다.

## 7. AP 계산을 loss와 분리하기

검출 loss가 낮아도 threshold와 NMS 뒤 AP가 높다는 보장은 없다. 평가 단계는 다음 순서를 가진다.

1. raw head를 `cxcywh`, confidence, class probability로 decode한다.
2. class score $s_{jk}=q_jp_k$를 계산한다.
3. score threshold 아래 후보를 버린다.
4. class별 NMS를 적용한다.
5. image·class별로 score 내림차순 정렬한다.
6. 아직 매칭되지 않은 정답 중 IoU가 threshold 이상인 최선의 상자와 일대일 매칭한다.
7. 누적 TP·FP로 precision과 recall을 만든다.
8. precision envelope 아래 면적을 적분해 AP를 구한다.

$$
\operatorname{precision}(k)=\frac{\operatorname{TP}(k)}{\operatorname{TP}(k)+\operatorname{FP}(k)}
$$

$$
\operatorname{recall}(k)=\frac{\operatorname{TP}(k)}{N_{gt}}
$$

$$
\operatorname{AP}=\sum_i(R_{i+1}-R_i)P_{interp}(R_{i+1})
$$

`AP@0.5`, COCO식 `AP@[0.5:0.95]`, 11-point AP는 같은 숫자가 아니다. evaluator 이름과 version을 실험 metadata에 남긴다. 정답이 없는 class를 평균에 포함할지도 명시한다.

## 8. C++17 golden contract

다음은 **C++17에서 실행 가능한 예제**다. 외부 tensor library 없이 cell assignment와 round trip을 검증한다.

```cpp
#include <algorithm>
#include <array>
#include <cassert>
#include <cmath>
#include <iomanip>
#include <iostream>

struct Encoded {
    int row;
    int col;
    std::array<double, 4> box;
};

Encoded Encode(const std::array<double, 4>& box, int grid_size) {
    const double cx = box[0];
    const double cy = box[1];
    if (cx < 0.0 || cx > 1.0 || cy < 0.0 || cy > 1.0 ||
        box[2] <= 0.0 || box[2] > 1.0 || box[3] <= 0.0 || box[3] > 1.0) {
        throw std::invalid_argument("invalid normalized box");
    }
    const int col = std::min(static_cast<int>(std::floor(grid_size * cx)), grid_size - 1);
    const int row = std::min(static_cast<int>(std::floor(grid_size * cy)), grid_size - 1);
    return {row, col, {grid_size * cx - col, grid_size * cy - row, box[2], box[3]}};
}

std::array<double, 4> Decode(const Encoded& value, int grid_size) {
    return {
        (value.col + value.box[0]) / grid_size,
        (value.row + value.box[1]) / grid_size,
        value.box[2],
        value.box[3]
    };
}

int main() {
    const std::array<double, 4> original{0.75, 0.25, 0.40, 0.20};
    const Encoded encoded = Encode(original, 2);
    const auto decoded = Decode(encoded, 2);
    assert(encoded.row == 0 && encoded.col == 1);
    for (std::size_t i = 0; i < original.size(); ++i) {
        assert(std::abs(original[i] - decoded[i]) < 1e-12);
    }
    std::cout << encoded.row << " " << encoded.col << " "
              << std::fixed << std::setprecision(2)
              << encoded.box[0] << " " << encoded.box[1] << "\n";
}
```

예상 출력은 `0 1 0.50 0.50`이다.

## 9. C# golden contract

다음은 **C#에서 실행 가능한 예제**다. `float` 대신 `double`을 사용해 C++ golden과 tolerance를 맞춘다.

```csharp
using System;

public sealed class Encoded
{
    public int Row { get; }
    public int Col { get; }
    public double[] Box { get; }

    public Encoded(int row, int col, double[] box)
    {
        Row = row;
        Col = col;
        Box = box;
    }
}

public static class YoloContract
{
    static Encoded Encode(double[] box, int gridSize)
    {
        double cx = box[0], cy = box[1];
        if (cx < 0.0 || cx > 1.0 || cy < 0.0 || cy > 1.0 ||
            box[2] <= 0.0 || box[2] > 1.0 || box[3] <= 0.0 || box[3] > 1.0)
            throw new ArgumentException("invalid normalized box");
        int col = Math.Min((int)Math.Floor(gridSize * cx), gridSize - 1);
        int row = Math.Min((int)Math.Floor(gridSize * cy), gridSize - 1);
        return new Encoded(row, col, new[] {
            gridSize * cx - col, gridSize * cy - row, box[2], box[3]
        });
    }

    static double[] Decode(Encoded value, int gridSize)
    {
        return new[] {
            (value.Col + value.Box[0]) / gridSize,
            (value.Row + value.Box[1]) / gridSize,
            value.Box[2], value.Box[3]
        };
    }

    public static void Main()
    {
        double[] original = { 0.75, 0.25, 0.40, 0.20 };
        Encoded encoded = Encode(original, 2);
        double[] decoded = Decode(encoded, 2);
        if (encoded.Row != 0 || encoded.Col != 1)
            throw new Exception("cell mismatch");
        for (int i = 0; i < original.Length; ++i)
            if (Math.Abs(original[i] - decoded[i]) >= 1e-12)
                throw new Exception("round trip mismatch");
        Console.WriteLine(
            "{0} {1} {2:F2} {3:F2}",
            encoded.Row, encoded.Col, encoded.Box[0], encoded.Box[1]
        );
    }
}
```

예상 출력은 C++과 같은 `0 1 0.50 0.50`이다.

## 10. 프레임워크 간 shape·layout·dtype 대응

| 경계 | PyTorch Python | C++ 런타임 예 | C# 런타임 예 | 확인할 것 |
| --- | --- | --- | --- | --- |
| image | `[N,3,H,W]`, `float32` | `NCHW` 연속 buffer | `DenseTensor<float>` 또는 array | RGB/BGR, scale, mean/std |
| raw head | `[N,5B+C,S,S]` | backend가 준 layout | ONNX Runtime output shape | channel 순서 |
| logical view | `[N,S,S,5B+C]` | index helper | index helper | 실제 copy 여부 |
| box | normalized `cxcywh` | `double` golden, `float` 배포 | `double` golden, `float` 배포 | resize·letterbox 역변환 |
| class id | `int64` | `int32_t` | `int` | 0-based 여부 |
| score | `float32` | `float` | `float` | sigmoid·softmax 적용 위치 |
| NMS index | `int64` | `int32_t` | `int` | stable tie-break |

`permute`는 stride만 바꾸는 view일 수 있다. 이후 `reshape`가 암묵적 copy를 만들 수 있으므로 profiler에서 확인한다. ONNX export의 raw output을 유지하고 후처리를 애플리케이션에 두면 threshold와 NMS를 바꾸기 쉽다. 반대로 NMS까지 graph에 넣으면 배포 인터페이스는 단순해지지만 backend별 지원과 동점 규칙 차이가 생길 수 있다.

## 11. 테스트·디버깅 전략

### 11.1 target builder 단위 테스트

- 중심 `(0,0)`은 cell `(0,0)`에 들어간다.
- 중심 `(1,1)`은 cell `(S-1,S-1)`에 clamp된다.
- 음수 크기, 0 크기, 범위 밖 class는 실패한다.
- 빈 annotation은 모두 배경인 target을 만든다.
- 같은 cell의 두 객체는 기본 정책에서 실패한다.
- `largest` 정책은 더 큰 면적의 객체를 보존하고 collision을 1 증가시킨다.

### 11.2 loss 단위 테스트

- 객체 cell 수와 책임 predictor 수가 같다.
- 비책임 predictor의 좌표 gradient는 0이다.
- 객체가 없는 batch에서도 confidence gradient와 loss가 유한하다.
- 완벽한 좌표에서 coordinate loss는 tolerance 안에서 0이다.
- predictor 순서를 바꾸면 best index는 바뀌어도 최소 IoU 선택 결과는 같다.
- `lambda_coord=0`이면 box 관련 parameter gradient가 사라지는지 확인한다.

### 11.3 decode·NMS·AP 단위 테스트

- encode 후 decode가 원래 normalized box를 복원한다.
- clipping 이후 `x1<=x2`, `y1<=y2`인지 확인한다.
- 같은 class의 높은 IoU 중복은 하나만 남는다.
- 다른 class의 겹친 box는 class별 NMS에서 둘 다 남는다.
- 같은 score에서는 원래 index 순서가 유지된다.
- 정답 0개, 예측 0개, 둘 다 0개인 evaluator 동작을 명시한다.
- AP golden은 detector output과 분리해 작은 TP·FP 배열로 검사한다.

### 11.4 디버깅 지도

| 증상 | 먼저 볼 tensor·metric | 흔한 원인 |
| --- | --- | --- |
| loss가 줄지만 box가 cell 모서리에 몰림 | `tx,ty` histogram | global center를 cell offset target으로 잘못 사용 |
| 두 predictor confidence가 모두 큼 | `responsible`과 no-object mask | 객체 cell의 비책임 predictor를 no-object loss에서 제외 |
| class loss가 $B$배 큼 | class loss reduction 축 | predictor별로 class loss를 중복 계산 |
| 작은 객체 recall이 0 | collision rate, cell occupancy | 격자가 거칠고 같은 cell 충돌이 많음 |
| AP가 실행마다 다름 | score 동점과 sort stability | 불안정 sort 또는 backend NMS tie-break 차이 |
| 배포 box가 일정 비율로 이동 | resize metadata | letterbox padding 역변환 누락 |
| AMP에서 `NaN` | `sqrt(w)`, IoU union | 음수·0 크기, 작은 분모, FP16 누적 |
| 빈 이미지 loss가 0 | no-object mask | 배경 confidence 학습을 통째로 누락 |

## 12. 성능·메모리·수치 안정성

raw 출력 원소 수는 다음과 같다.

$$
M=N S^2(5B+C)
$$

$N=32$, $S=7$, $B=2$, $C=20$이면 $M=47{,}040$이고 FP32 raw output은 약 184 KiB다. 오늘의 작은 출력 자체보다 backbone activation과 optimizer state가 훨씬 크다. 그러나 최신 dense detector에서 여러 scale과 많은 후보를 사용하면 decode와 NMS 임시 buffer가 커질 수 있다.

- IoU와 loss 누적은 FP32로 계산한다.
- `sqrt` 입력은 작은 양수로 clamp한다.
- 퇴화 상자는 dataset 단계에서 거부하고 decode 뒤에도 제거한다.
- threshold를 NMS 전에 적용해 후보 수를 제한하되 AP 영향을 측정한다.
- class별 loop는 $C$가 크면 병목이므로 batched NMS 또는 top-k prefilter를 검토한다.
- GPU inference 시간에는 H2D copy, decode, NMS, D2H copy를 모두 포함한다.
- 평균 FPS뿐 아니라 p50, p95, p99 latency와 후보 수 분포를 기록한다.
- `torch.compile`, ONNX, TensorRT 비교에서는 raw output의 숫자와 최종 검출을 각각 비교한다.

| collision `error` vs `largest` | annotation order | collision rate, recall | 데이터 손실을 얼마나 숨기는가? |
| class별 vs class-agnostic NMS | raw prediction | class별 recall | 겹친 다른 class를 지우는가? |
| score threshold 0.01 vs 0.25 | NMS threshold | AP, latency | 후보 제한과 recall trade-off는? |
| $S=7$ vs $S=14$ | backbone capacity | collision rate, memory | 더 촘촘한 grid가 병목을 줄이는가? |

한 번에 하나의 요인만 바꾸고, AP 차이뿐 아니라 target collision과 후보 수도 함께 기록한다. $S$를 바꾸면 head parameter와 receptive field가 달라질 수 있으므로 완전한 인과 비교라고 과장하지 않는다.

## 14. 실무 실패 사례

### 사례 A: annotation 순서가 모델 성능을 바꿈

같은 cell에 두 객체가 들어왔고 target array에 차례로 대입했다. CSV 정렬 순서가 바뀌자 남는 객체가 달라져 학습 결과도 바뀌었다.

대응은 collision을 먼저 오류로 만들고 비율·class·크기별 분포를 보고하는 것이다. YOLOv1을 유지해야 한다면 정책을 명시하고 manifest hash와 함께 저장한다.

### 사례 B: letterbox를 되돌리지 않은 배포

학습은 정사각형 letterbox를 사용했지만 서비스는 raw output을 원본 해상도에 바로 곱했다. 상자가 padding 방향으로 일정하게 이동했다.

대응은 resize scale과 네 방향 padding을 request metadata로 보존하고, `model normalized -> resized pixel -> original pixel` 순서의 golden test를 둔다.

### 사례 C: 검증에는 class별 NMS, 서비스에는 전체 NMS

검증 AP는 정상인데 사람과 자전거처럼 겹치는 다른 class 중 하나가 서비스에서 사라졌다. class-agnostic NMS가 원인이었다.

대응은 후처리 config를 model artifact의 일부로 배포하고 raw output과 최종 detection을 모두 canary 비교한다.

### 사례 D: loss가 작아져 성공으로 판단

no-object cell이 압도적으로 많아 confidence를 모두 0에 가깝게 내는 모델도 평균 loss를 낮출 수 있었다. positive recall은 0이었다.

대응은 각 손실 항, positive confidence, negative confidence, 책임 IoU, AP와 recall을 따로 기록한다.

## 15. 배포 관점

### artifact 계약

- 입력 이름, shape, dtype, color order
- resize·letterbox와 normalization
- raw channel schema `box -> confidence -> class`
- $S$, $B$, $C$와 class map hash
- box activation과 coordinate convention
- score 계산, threshold, top-k, NMS 정책
- original image 좌표로의 역변환
- evaluator version과 golden input/output

### canary와 모니터링

- class별 detection count와 confidence histogram
- NMS 전후 후보 수
- clipping 또는 퇴화 상자 비율
- p50·p95·p99 end-to-end latency
- input 해상도·aspect ratio drift
- annotation이 생기는 환경에서는 class별 precision·recall과 AP

raw tensor drift와 최종 detection drift를 분리한다. raw는 같은데 결과가 다르면 후처리나 runtime 문제다. raw부터 다르면 전처리, graph 변환, quantization 또는 model artifact를 의심한다.

ONNX와 대상 runtime package는 이 문서의 최소 환경에 설치되어 있다고 가정하지 않는다. 설치되어 있지 않으면 PyTorch raw output과 독립 NumPy·C++·C# golden으로 경계를 검증하고, ONNX export·runtime parity는 미검증으로 명시한다. 배포 승인 전에는 실제 target runtime에서 별도 검증해야 한다.

## 17. 연습문제

### 문제 1

$S=4$이고 중심이 $(c_x,c_y)=(0.625,0.875)$인 객체의 cell과 offset을 구하라.

### 문제 2

객체가 있는 한 cell에 $B=2$ predictor가 있고 정답과의 IoU가 각각 0.3, 0.7이다. 어떤 mask가 1이며 각 predictor가 받는 loss 항을 설명하라.

### 문제 3

같은 cell에 면적 0.02와 0.05인 객체가 들어왔다. `error`와 `largest` 정책의 결과를 비교하라.

### 문제 4

같은 class의 상자 A와 B의 IoU가 0.8이고 score가 각각 0.9, 0.7이다. NMS threshold가 0.5일 때 결과는 무엇인가? 두 상자가 다른 class라면 class별 NMS 결과는 어떻게 달라지는가?

### 문제 5

정답 두 개에 대해 score 순서의 예측이 TP, FP, TP였다. 누적 precision과 recall을 구하라.

### 문제 6

학습 loss와 AP가 모두 재현 가능한데 서비스 상자만 오른쪽으로 이동한다. 가장 먼저 비교할 세 경계를 적어라.

## 18. 해답

### 해답 1

$$
c=\lfloor4\cdot0.625\rfloor=2,\qquad
r=\lfloor4\cdot0.875\rfloor=3
$$

$$
t_x=4\cdot0.625-2=0.5,\qquad
t_y=4\cdot0.875-3=0.5
$$

따라서 cell은 `(row=3, col=2)`, offset은 `(0.5,0.5)`다.

### 해답 2

두 번째 predictor의 `responsible`만 1이다. 두 번째는 좌표, object confidence 항을 받고 첫 번째는 좌표 손실을 받지 않는다. 첫 번째 confidence는 비책임 predictor이므로 no-object confidence 항을 받는다. class 손실은 predictor별이 아니라 cell별 한 번 계산한다.

### 해답 3

`error`는 target 생성을 중단하고 collision 위치를 보고한다. `largest`는 면적 0.05인 객체만 보존하고 collision counter를 1 올린다. 어느 정책도 두 객체를 모두 표현하지 못한다.

### 해답 4

같은 class이면 A를 먼저 유지하고 IoU 0.8인 B를 제거한다. 다른 class이면 class별 NMS의 서로 다른 그룹에 있으므로 둘 다 남는다.

### 해답 5

정답 수가 2이므로 누적 값은 다음과 같다.

| 순위 | 결과 | precision | recall |
| --- | --- | --- | --- |
| 1 | TP | $1/1=1$ | $1/2=0.5$ |
| 2 | FP | $1/2=0.5$ | $1/2=0.5$ |
| 3 | TP | $2/3$ | $2/2=1$ |

보간 AP 계산 규칙에 따라 precision envelope를 만든 뒤 recall 증가 구간의 면적을 더한다. 오늘 코드의 all-points 방식에서는 $5/6$이다.

### 해답 6

첫째, RGB/BGR와 resize·letterbox 전처리 metadata를 비교한다. 둘째, raw model output을 같은 입력에서 비교한다. 셋째, normalized box를 resized pixel과 original pixel로 되돌리는 후처리식을 비교한다. raw가 같고 최종 좌표만 다르면 model보다 후처리를 먼저 의심한다.

## 핵심 요약

- YOLOv1 target은 객체 중심이 속한 cell에 `tx,ty,w,h`와 class 한 벌을 기록한다.
- 같은 cell의 여러 객체는 표현할 수 없으므로 collision을 오류나 명시적 정책으로 다뤄야 한다.
- cell 책임과 predictor 책임은 다르며 객체 cell마다 IoU가 가장 큰 predictor 하나가 좌표를 맡는다.
- 비책임 predictor도 no-object confidence loss에는 참여한다.
- train과 inference는 raw channel schema, activation, coordinate convention을 공유해야 한다.
- NMS와 AP는 loss와 독립된 테스트 대상으로 두고 동점·빈 입력·class 정책을 고정한다.
- 재현성은 seed 선언이 아니라 loss history, parameter, target manifest의 재실행 비교로 확인한다.
- 배포에서는 raw output과 최종 detection을 분리 비교해야 전처리·model·후처리 문제를 빠르게 격리할 수 있다.
