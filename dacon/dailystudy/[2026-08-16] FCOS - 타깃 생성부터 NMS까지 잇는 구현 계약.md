## 오늘의 질문

FCOS를 실제로 학습시키려면 “anchor가 없다”는 문장보다 다음 계약이 중요하다.

```text
FPN features -> level별 point 생성 -> GT 후보 행렬
             -> inside + center sampling + regression range
             -> 최소 면적 tie-break -> class/LTRB/center-ness target
             -> classification + box + center-ness loss
             -> decode -> score 결합 -> class별 NMS -> 평가
```

1회차 글은 point, `LTRB`, center-ness의 직관과 수식을 설명했다. 이번 글은 같은 설명을 반복하지 않고 target assigner, head, loss, decode, NMS를 하나의 실행 가능한 계약으로 묶는다.

## 학습 목표

이 글을 마치면 다음을 할 수 있다.

1. 모든 FPN 위치와 모든 정답의 후보 행렬을 만들고 mask 순서를 테스트한다.
2. center sampling과 level별 regression range를 독립적으로 켜고 끈다.
3. 겹친 정답에서 최소 면적 tie-break를 결정적으로 구현한다.
4. classification, box, center-ness 출력을 같은 point 순서로 flatten한다.
5. positive가 없는 image에서도 유한한 classification loss를 계산한다.
6. decode, score 결합, class별 NMS까지 평가 경로를 실행한다.
7. NumPy oracle과 PyTorch 학습 경로를 골든 값으로 교차 검증한다.
8. Python, C++17, C#의 좌표·shape·dtype 계약을 맞춘다.
9. 재현성, mixed precision, 메모리, ONNX 배포 실패를 진단한다.

## 선수 지식과 기호

- FPN과 stride
- sigmoid Focal Loss와 binary cross entropy
- `XYXY` 박스와 IoU
- PyTorch autograd와 optimizer
- NMS와 confidence threshold

| 기호 | 뜻 |
| --- | --- |
| $N$ | batch 크기 |
| $K$ | foreground class 수 |
| $L$ | FPN level 수 |
| $H_l,W_l$ | level $l$의 feature 높이와 너비 |
| $Q_l=H_lW_l$ | level $l$의 point 수 |
| $Q=\sum_lQ_l$ | 모든 level의 point 수 |
| $G$ | 한 image의 정답 박스 수 |
| $s_l$ | level $l$의 입력 영상 기준 stride |
| $p_q=(x_q,y_q)$ | point $q$의 입력 영상 좌표 |
| $d_{qg}=(l,t,r,b)$ | point $q$에서 정답 $g$의 네 변까지 거리 |
| $z^{cls}$ | class logit |
| $z^{ctr}$ | center-ness logit |

좌표는 연속적인 `XYXY=(x0,y0,x1,y1)`, feature는 `NCHW`, 펼친 point 순서는 level 우선 뒤 각 level의 행 우선 `y,x` 순서로 고정한다. 경계가 정확히 박스 위인 point는 이 글에서 positive에 포함한다.

## 1. 원본과 1회차에서 이번에 확장하는 것

원본 [02-06.FCOS_DETR.md](../05.ImageClassification/02-06.FCOS_DETR.md)와 1회차 FCOS 문서는 개념을 이해하기에 충분하다. 학습 코드를 만들 때는 다음 경계를 더 명시해야 한다.

| 축약된 설명 | 이번 구현 계약 |
| --- | --- |
| 예측 거리가 음수이면 background | target은 예측이 아니라 고정 point와 GT의 기하로 배정한다. regression 출력은 `ReLU`로 음수가 아니게 만든다. |
| 박스 안 point는 모두 positive | `inside`, center sampling, level range를 차례로 적용하고 겹치면 최소 면적 GT를 선택한다. |
| center-ness를 class score에 곱해 학습 | class Focal Loss와 center-ness BCE는 분리해 학습하고 추론 순위에서 결합한다. |
| FCOS는 NMS가 필요 없음 | 고전적 FCOS 추론에는 class별 NMS가 남는다. NMS 없는 집합 예측은 다음 Part의 DETR 주제다. |
| 모든 loss를 단순 평균 | classification은 유효 위치, box와 center-ness는 positive만 모으고 global positive 수로 정규화한다. |
| multi-level은 tensor를 이어 붙이면 끝 | point, stride, range, class, box, center-ness가 같은 flatten 순서를 가져야 한다. |
| center sampling은 center-ness와 동일 | 전자는 positive 후보 mask이고 후자는 positive 품질 target이다. |

원문의 “각 픽셀”은 입력 raw pixel이 아니라 보통 FPN feature의 spatial location을 뜻한다. 또한 anchor의 scale·aspect-ratio 열거는 없어지지만 stride, point, regression range라는 기하 기준까지 사라지는 것은 아니다.

## 2. target assigner를 행렬로 유도하기

### 2.1 point 생성

level $l$에서 feature index $(i,j)$의 중심은 다음과 같다.

$$
x=s_l\left(i+\frac{1}{2}\right)
$$

$$
y=s_l\left(j+\frac{1}{2}\right)
$$

level별 point tensor와 이어 붙인 tensor의 shape는 다음과 같다.

$$
P_l\in\mathbb{R}^{Q_l\times2},\qquad
P\in\mathbb{R}^{Q\times2}
$$

head output을 `[N,C,H,W] -> [N,H,W,C] -> [N,Q_l,C]`로 펼친다면 point도 `meshgrid(indexing="ij")` 뒤 행 우선으로 펼쳐야 한다. `x,y`와 `row,column`을 바꾸면 정사각형 입력의 일부 테스트는 우연히 통과하므로 비정사각 feature를 포함한다.

### 2.2 모든 point와 모든 GT의 `LTRB`

$P$를 `[Q,1,2]`, GT 박스를 `[1,G,4]`로 broadcast하면 다음 후보 행렬을 한 번에 얻는다.

$$
l_{qg}=x_q-x_{0,g}
$$

$$
t_{qg}=y_q-y_{0,g}
$$

$$
r_{qg}=x_{1,g}-x_q
$$

$$
b_{qg}=y_{1,g}-y_q
$$

$$
D\in\mathbb{R}^{Q\times G\times4}
$$

이 글은 경계를 포함하므로 inside mask는 다음과 같다.

$$
M^{inside}_{qg}
=
\mathbb{1}\left[\min(d_{qg})\ge0\right]
$$

### 2.3 center sampling

정답 중심 $(c_x,c_y)$와 radius 계수 $\rho$를 이용한다. level별 반경은 $R_q=\rho s_q$이고, 중심 영역은 원래 GT와 교집합을 취한다.

$$
x^{center}_0=\max(x_0,c_x-R_q)
$$

$$
y^{center}_0=\max(y_0,c_y-R_q)
$$

$$
x^{center}_1=\min(x_1,c_x+R_q)
$$

$$
y^{center}_1=\min(y_1,c_y+R_q)
$$

point가 이 교집합 안에 있을 때만 $M^{center}_{qg}=1$로 둔다. radius를 pixel 상수로 두면 level마다 의미가 달라진다. 반드시 그 point의 stride를 곱한다.

### 2.4 FPN regression range

각 후보의 대표 거리를 다음으로 둔다.

$$
d^{max}_{qg}=\max(l_{qg},t_{qg},r_{qg},b_{qg})
$$

point $q$가 속한 level의 범위를 $(m_q,M_q]$로 정하면 다음 mask를 얻는다.

$$
M^{range}_{qg}
=
\mathbb{1}[m_q<d^{max}_{qg}\le M_q]
$$

첫 level의 lower bound만 0을 포함해야 한다면 구현에서 `lower <= dmax`와 `lower < dmax` 중 하나를 명시적으로 선택한다. 경계 64가 두 level에 동시에 들어가거나 어느 level에도 들어가지 않는 테스트를 추가한다.

### 2.5 최소 면적 tie-break

최종 후보 mask는 다음 논리곱이다.

$$
M_{qg}
=
M^{inside}_{qg}
M^{center}_{qg}
M^{range}_{qg}
$$

후보가 아닌 GT의 면적을 무한대로 바꾼 뒤 `argmin`하면 겹친 후보 중 작은 GT를 고를 수 있다.

$$
g_q^*
=
\arg\min_g
\begin{cases}
A_g,&M_{qg}=1\\
+\infty,&M_{qg}=0
\end{cases}
$$

모든 값이 무한대라면 background다. 면적이 같은 GT의 순서까지 재현하려면 정답을 stable order로 유지하고 최초 index를 선택한다.

### 2.6 center-ness target

선택된 positive의 거리로 다음 값을 만든다.

$$
c^*
=
\sqrt{
\frac{\min(l,r)}{\max(l,r)}
\frac{\min(t,b)}{\max(t,b)}
}
$$

분모가 0인 경계 point는 `eps`로 clamp한다. 실제 학습에서는 center sampling이 경계 positive를 대부분 제거하지만 수치 계약은 별도로 안전해야 한다.

## 3. NumPy oracle: assigner를 PyTorch 밖에서 검증하기

다음 코드는 **실행 가능한 독립 검증 예제**다. 작은 행렬을 사용해 point 순서, 최소 면적 tie-break, range, center-ness를 확인한다.

```python
import numpy as np


def make_points(height, width, stride):
    ys = (np.arange(height, dtype=np.float64) + 0.5) * stride
    xs = (np.arange(width, dtype=np.float64) + 0.5) * stride
    grid_y, grid_x = np.meshgrid(ys, xs, indexing="ij")
    return np.stack([grid_x.reshape(-1), grid_y.reshape(-1)], axis=1)


def assign_fcos(points, strides, ranges, boxes, labels, radius=1.5):
    points = np.asarray(points, dtype=np.float64)
    strides = np.asarray(strides, dtype=np.float64)
    ranges = np.asarray(ranges, dtype=np.float64)
    boxes = np.asarray(boxes, dtype=np.float64)
    labels = np.asarray(labels, dtype=np.int64)

    q = points.shape[0]
    if boxes.shape[0] == 0:
        return (
            np.zeros(q, dtype=np.int64),
            np.zeros((q, 4), dtype=np.float64),
            np.zeros(q, dtype=np.float64),
        )

    x = points[:, None, 0]
    y = points[:, None, 1]
    l = x - boxes[None, :, 0]
    t = y - boxes[None, :, 1]
    r = boxes[None, :, 2] - x
    b = boxes[None, :, 3] - y
    distances = np.stack([l, t, r, b], axis=-1)
    inside = distances.min(axis=-1) >= 0.0

    centers = 0.5 * (boxes[:, :2] + boxes[:, 2:])
    reach = radius * strides[:, None]
    center_x0 = np.maximum(boxes[None, :, 0], centers[None, :, 0] - reach)
    center_y0 = np.maximum(boxes[None, :, 1], centers[None, :, 1] - reach)
    center_x1 = np.minimum(boxes[None, :, 2], centers[None, :, 0] + reach)
    center_y1 = np.minimum(boxes[None, :, 3], centers[None, :, 1] + reach)
    in_center = (
        (x >= center_x0)
        & (y >= center_y0)
        & (x <= center_x1)
        & (y <= center_y1)
    )

    max_distance = distances.max(axis=-1)
    in_range = (
        (max_distance > ranges[:, None, 0])
        & (max_distance <= ranges[:, None, 1])
    )

    valid = inside & in_center & in_range
    areas = (boxes[:, 2] - boxes[:, 0]) * (boxes[:, 3] - boxes[:, 1])
    candidate_areas = np.where(valid, areas[None, :], np.inf)
    chosen = candidate_areas.argmin(axis=1)
    positive = np.isfinite(candidate_areas[np.arange(q), chosen])

    class_targets = np.zeros(q, dtype=np.int64)
    class_targets[positive] = labels[chosen[positive]]
    box_targets = np.zeros((q, 4), dtype=np.float64)
    box_targets[positive] = distances[np.arange(q)[positive], chosen[positive]]

    center_targets = np.zeros(q, dtype=np.float64)
    d = box_targets[positive]
    horizontal = np.minimum(d[:, 0], d[:, 2]) / np.maximum(d[:, 0], d[:, 2])
    vertical = np.minimum(d[:, 1], d[:, 3]) / np.maximum(d[:, 1], d[:, 3])
    center_targets[positive] = np.sqrt(horizontal * vertical)
    return class_targets, box_targets, center_targets


points = make_points(height=2, width=3, stride=8)
np.testing.assert_array_equal(
    points,
    [[4.0, 4.0], [12.0, 4.0], [20.0, 4.0],
     [4.0, 12.0], [12.0, 12.0], [20.0, 12.0]],
)

strides = np.full(6, 8.0)
ranges = np.tile(np.array([[0.0, 64.0]]), (6, 1))
boxes = np.array([[0.0, 0.0, 24.0, 16.0], [8.0, 0.0, 16.0, 16.0]])
labels = np.array([1, 2])
classes, ltrb, center = assign_fcos(points, strides, ranges, boxes, labels)

# (12, 4)와 (12, 12)는 두 GT에 속하지만 작은 두 번째 GT를 선택한다.
np.testing.assert_array_equal(classes, [1, 2, 1, 1, 2, 1])
np.testing.assert_allclose(ltrb[1], [4.0, 4.0, 4.0, 12.0])
np.testing.assert_allclose(center[1], np.sqrt(1.0 / 3.0))

empty = assign_fcos(points, strides, ranges, np.empty((0, 4)), np.empty(0))
assert (empty[0] == 0).all()
assert np.isfinite(empty[1]).all() and np.isfinite(empty[2]).all()
print("numpy FCOS assigner passed:", classes.tolist(), round(center[1], 6))
```

이 oracle은 속도보다 의미가 우선이다. 실제 GPU assigner와 같은 작은 입력을 넣어 class, `LTRB`, center-ness를 모두 비교하면 framework 구현의 broadcast·index 오류를 빨리 찾을 수 있다.

## 4. head와 flatten shape 계약

### 4.1 level별 출력

공유 tower를 쓰는 간단한 FCOS head의 level별 출력은 다음과 같다.

$$
Z_l^{cls}\in\mathbb{R}^{N\times K\times H_l\times W_l}
$$

$$
D_l\in\mathbb{R}^{N\times4\times H_l\times W_l}
$$

$$
Z_l^{ctr}\in\mathbb{R}^{N\times1\times H_l\times W_l}
$$

flatten 계약은 다음과 같다.

```text
class: [N,K,H,W] -> [N,H,W,K] -> [N,H*W,K]
box:   [N,4,H,W] -> [N,H,W,4] -> [N,H*W,4]
ctr:   [N,1,H,W] -> [N,H,W,1] -> [N,H*W]
point: meshgrid(y,x) -> stack(x,y) -> [H*W,2]
```

모든 level을 낮은 stride부터 이어 붙인다. `zip(features, strides, ranges)`의 config 순서와 FPN dictionary 순서가 다르면 학습은 실행되지만 엉뚱한 point에 target이 붙는다.

### 4.2 regression 단위

이 글의 head는 `ReLU` 뒤 거리를 **pixel 단위**로 직접 예측한다. 다른 구현은 feature-cell 단위 거리를 예측하고 level scale을 곱한다.

$$
d^{pixel}_l=s_l d^{cell}_l
$$

어느 쪽도 가능하지만 assigner, loss, decode, ONNX consumer가 같은 단위를 써야 한다. output 이름이나 model metadata에 `bbox_unit=pixel`을 기록한다.

## 5. 손실 함수와 정규화

class target은 background를 0번으로 두고 foreground label을 `1...K`로 둔다. sigmoid head의 one-hot tensor에는 background column이 없다.

$$
Y^{cls}\in\{0,1\}^{N\times Q\times K}
$$

classification은 모든 유효 point, box와 center-ness는 positive point만 사용한다.

$$
L_{cls}
=
\frac{\sum_{nqk}\operatorname{FL}(z^{cls}_{nqk},y_{nqk})}
{\max(1,N_+)}
$$

positive point의 predicted box $\hat B_q$와 target box $B_q$는 point에서 decode한 뒤 IoU 계열 손실로 비교한다.

$$
L_{box}
=
\frac{\sum_{q\in\mathcal P}c_q^*\left(1-\operatorname{IoU}(\hat B_q,B_q)\right)}
{\max(\epsilon,\sum_{q\in\mathcal P}c_q^*)}
$$

$$
L_{ctr}
=
\frac{\sum_{q\in\mathcal P}\operatorname{BCEWithLogits}(z_q^{ctr},c_q^*)}
{\max(1,N_+)}
$$

center-ness로 box loss를 가중할지는 구현 선택이다. config와 실험표에 남긴다. 분산 학습에서는 worker별 $N_+$가 아니라 all-reduce한 global positive 수를 사용해야 gradient scale이 world size와 image 구성에 따라 흔들리지 않는다.

positive가 0인 batch에서는 다음 정책을 사용한다.

- classification negative loss는 유지한다.
- box와 center-ness는 graph 연결을 유지한 0으로 만든다.
- 분모는 1로 clamp한다.
- optimizer step 뒤 모든 parameter와 optimizer state가 유한한지 확인한다.

## 6. PyTorch: 학습과 평가를 한 경로로 실행하기

다음은 **실행 가능한 축소 구현**이다. backbone과 FPN 대신 재현 가능한 synthetic feature를 사용하지만 head, target, loss, optimizer, decode, class별 NMS까지 실제로 실행한다.

```python
import math
import torch
from torch import nn
from torch.nn import functional as F


torch.manual_seed(7)
torch.use_deterministic_algorithms(True)


def points_for_feature(feature, stride):
    height, width = feature.shape[-2:]
    ys = (torch.arange(height, device=feature.device, dtype=feature.dtype) + 0.5) * stride
    xs = (torch.arange(width, device=feature.device, dtype=feature.dtype) + 0.5) * stride
    grid_y, grid_x = torch.meshgrid(ys, xs, indexing="ij")
    return torch.stack([grid_x.reshape(-1), grid_y.reshape(-1)], dim=1)


def assign_targets(points, strides, ranges, boxes, labels, radius=1.5):
    count = points.shape[0]
    if boxes.numel() == 0:
        return (
            torch.zeros(count, dtype=torch.long, device=points.device),
            points.new_zeros((count, 4)),
            points.new_zeros(count),
        )

    x, y = points[:, None, 0], points[:, None, 1]
    distances = torch.stack(
        [x - boxes[None, :, 0], y - boxes[None, :, 1],
         boxes[None, :, 2] - x, boxes[None, :, 3] - y],
        dim=-1,
    )
    inside = distances.amin(dim=-1) >= 0

    centers = 0.5 * (boxes[:, :2] + boxes[:, 2:])
    reach = radius * strides[:, None]
    center_x0 = torch.maximum(boxes[None, :, 0], centers[None, :, 0] - reach)
    center_y0 = torch.maximum(boxes[None, :, 1], centers[None, :, 1] - reach)
    center_x1 = torch.minimum(boxes[None, :, 2], centers[None, :, 0] + reach)
    center_y1 = torch.minimum(boxes[None, :, 3], centers[None, :, 1] + reach)
    in_center = (
        (x >= center_x0) & (y >= center_y0)
        & (x <= center_x1) & (y <= center_y1)
    )

    maximum = distances.amax(dim=-1)
    in_range = (maximum > ranges[:, None, 0]) & (maximum <= ranges[:, None, 1])
    valid = inside & in_center & in_range
    areas = (boxes[:, 2] - boxes[:, 0]) * (boxes[:, 3] - boxes[:, 1])
    candidate_areas = torch.where(valid, areas[None, :], torch.inf)
    best_area, chosen = candidate_areas.min(dim=1)
    positive = torch.isfinite(best_area)

    class_target = torch.zeros(count, dtype=torch.long, device=points.device)
    class_target[positive] = labels[chosen[positive]]
    box_target = points.new_zeros((count, 4))
    row = torch.arange(count, device=points.device)
    box_target[positive] = distances[row[positive], chosen[positive]]
    center_target = points.new_zeros(count)
    d = box_target[positive]
    if d.numel():
        horizontal = d[:, [0, 2]].amin(1) / d[:, [0, 2]].amax(1).clamp_min(1e-6)
        vertical = d[:, [1, 3]].amin(1) / d[:, [1, 3]].amax(1).clamp_min(1e-6)
        center_target[positive] = torch.sqrt((horizontal * vertical).clamp_min(0))
    return class_target, box_target, center_target


class FCOSHead(nn.Module):
    def __init__(self, channels, classes):
        super().__init__()
        self.class_tower = nn.Sequential(
            nn.Conv2d(channels, channels, 3, padding=1), nn.ReLU(),
        )
        self.box_tower = nn.Sequential(
            nn.Conv2d(channels, channels, 3, padding=1), nn.ReLU(),
        )
        self.classifier = nn.Conv2d(channels, classes, 3, padding=1)
        self.box_regression = nn.Conv2d(channels, 4, 3, padding=1)
        self.center = nn.Conv2d(channels, 1, 3, padding=1)
        prior = 0.01
        nn.init.constant_(self.classifier.bias, -math.log((1.0 - prior) / prior))

    def forward(self, features):
        outputs = []
        for feature in features:
            class_feature = self.class_tower(feature)
            box_feature = self.box_tower(feature)
            outputs.append((
                self.classifier(class_feature),
                F.relu(self.box_regression(box_feature)),
                self.center(box_feature),
            ))
        return outputs


def flatten_outputs(outputs):
    class_all, box_all, center_all = [], [], []
    for class_raw, box_raw, center_raw in outputs:
        class_all.append(class_raw.permute(0, 2, 3, 1).flatten(1, 2))
        box_all.append(box_raw.permute(0, 2, 3, 1).flatten(1, 2))
        center_all.append(center_raw.permute(0, 2, 3, 1).flatten(1))
    return tuple(torch.cat(values, dim=1) for values in (class_all, box_all, center_all))


def focal_logits(logits, targets, alpha=0.25, gamma=2.0):
    bce = F.binary_cross_entropy_with_logits(logits, targets, reduction="none")
    probability = logits.sigmoid()
    pt = targets * probability + (1.0 - targets) * (1.0 - probability)
    alpha_t = targets * alpha + (1.0 - targets) * (1.0 - alpha)
    return alpha_t * (1.0 - pt).pow(gamma) * bce


def decode(points, distances):
    return torch.stack(
        [points[:, 0] - distances[:, 0], points[:, 1] - distances[:, 1],
         points[:, 0] + distances[:, 2], points[:, 1] + distances[:, 3]],
        dim=1,
    )


def box_iou_aligned(first, second):
    top_left = torch.maximum(first[:, :2], second[:, :2])
    bottom_right = torch.minimum(first[:, 2:], second[:, 2:])
    intersection = (bottom_right - top_left).clamp_min(0).prod(dim=1)
    area_first = (first[:, 2:] - first[:, :2]).clamp_min(0).prod(dim=1)
    area_second = (second[:, 2:] - second[:, :2]).clamp_min(0).prod(dim=1)
    return intersection / (area_first + area_second - intersection).clamp_min(1e-6)


def losses(class_logits, box_distances, center_logits, points, targets, classes):
    class_target, box_target, center_target = targets
    positive = class_target > 0
    one_hot = class_logits.new_zeros(class_logits.shape)
    if positive.any():
        one_hot[positive, class_target[positive] - 1] = 1.0
    normalizer = positive.sum().clamp_min(1).to(class_logits.dtype)
    class_loss = focal_logits(class_logits, one_hot).sum() / normalizer

    if positive.any():
        predicted_boxes = decode(points[positive], box_distances[positive])
        target_boxes = decode(points[positive], box_target[positive])
        iou_loss = 1.0 - box_iou_aligned(predicted_boxes, target_boxes)
        weights = center_target[positive]
        box_loss = (iou_loss * weights).sum() / weights.sum().clamp_min(1e-6)
        center_loss = F.binary_cross_entropy_with_logits(
            center_logits[positive], center_target[positive], reduction="sum"
        ) / normalizer
    else:
        box_loss = box_distances.sum() * 0.0
        center_loss = center_logits.sum() * 0.0
    total = class_loss + box_loss + center_loss
    return total, {"class": class_loss, "box": box_loss, "center": center_loss}


def pairwise_iou(box, boxes):
    top_left = torch.maximum(box[:2], boxes[:, :2])
    bottom_right = torch.minimum(box[2:], boxes[:, 2:])
    intersection = (bottom_right - top_left).clamp_min(0).prod(dim=1)
    area_box = (box[2:] - box[:2]).clamp_min(0).prod()
    area_boxes = (boxes[:, 2:] - boxes[:, :2]).clamp_min(0).prod(dim=1)
    return intersection / (area_box + area_boxes - intersection).clamp_min(1e-6)


def nms(boxes, scores, threshold=0.5):
    order = scores.argsort(descending=True)
    keep = []
    while order.numel():
        current = order[0]
        keep.append(current)
        if order.numel() == 1:
            break
        remaining = order[1:]
        order = remaining[pairwise_iou(boxes[current], boxes[remaining]) <= threshold]
    return torch.stack(keep) if keep else torch.empty(0, dtype=torch.long)


def postprocess(class_logits, box_distances, center_logits, points, threshold=0.05):
    class_probability = class_logits.sigmoid()
    center_probability = center_logits.sigmoid()[:, None]
    ranking_score = torch.sqrt(class_probability * center_probability)
    boxes = decode(points, box_distances)
    detections = []
    for class_index in range(class_logits.shape[1]):
        selected = ranking_score[:, class_index] >= threshold
        if selected.any():
            kept = nms(boxes[selected], ranking_score[selected, class_index])
            detections.append((
                boxes[selected][kept],
                ranking_score[selected, class_index][kept],
                torch.full((kept.numel(),), class_index + 1, dtype=torch.long),
            ))
    return detections


features = [torch.randn(1, 8, 4, 5), torch.randn(1, 8, 2, 3)]
strides_by_level = [8.0, 16.0]
ranges_by_level = [(0.0, 64.0), (64.0, float("inf"))]
points_by_level = [points_for_feature(f, s) for f, s in zip(features, strides_by_level)]
points = torch.cat(points_by_level)
strides = torch.cat([
    points_l.new_full((len(points_l),), stride)
    for points_l, stride in zip(points_by_level, strides_by_level)
])
ranges = torch.cat([
    points_l.new_tensor([bounds]).repeat(len(points_l), 1)
    for points_l, bounds in zip(points_by_level, ranges_by_level)
])

boxes = torch.tensor([[5.0, 5.0, 27.0, 29.0], [30.0, 8.0, 70.0, 46.0]])
labels = torch.tensor([1, 2])
targets = assign_targets(points, strides, ranges, boxes, labels)
head = FCOSHead(channels=8, classes=2)
optimizer = torch.optim.SGD(head.parameters(), lr=0.01, momentum=0.9)

optimizer.zero_grad(set_to_none=True)
raw_outputs = head(features)
class_logits, box_distances, center_logits = flatten_outputs(raw_outputs)
assert class_logits.shape == (1, 26, 2)
assert box_distances.shape == (1, 26, 4)
assert center_logits.shape == (1, 26)
total, parts = losses(
    class_logits[0], box_distances[0], center_logits[0], points, targets, classes=2
)
assert torch.isfinite(total)
total.backward()
assert all(p.grad is None or torch.isfinite(p.grad).all() for p in head.parameters())
optimizer.step()

# 빈 image에서도 negative classification gradient는 남고 나머지는 안전한 0이다.
empty_targets = assign_targets(points, strides, ranges, boxes[:0], labels[:0])
empty_total, empty_parts = losses(
    class_logits[0], box_distances[0], center_logits[0], points, empty_targets, classes=2
)
assert empty_parts["class"] > 0
assert empty_parts["box"] == 0 and empty_parts["center"] == 0
assert torch.isfinite(empty_total)

# 평가 경로 smoke test: 학습 초기 prior에서는 threshold를 낮춰 shape만 확인한다.
detections = postprocess(
    class_logits[0].detach(), box_distances[0].detach(),
    center_logits[0].detach(), points, threshold=0.001,
)
assert all(item[0].shape[1] == 4 for item in detections)
print(
    "torch FCOS passed:", tuple(class_logits.shape),
    "positive=", int((targets[0] > 0).sum()),
    "loss=", round(float(total.detach()), 6),
)
```

이 예제의 synthetic feature는 설명용 데이터지만 코드는 실제 실행된다. 실제 학습기에서는 image마다 길이가 다른 GT를 list로 유지하고 batch loop 또는 padded GT mask로 assigner를 호출한다.

## 7. C++17 예제: 좌표와 center-ness 골든 값

다음은 **실행 가능한 C++17 예제**다. 추론 consumer가 같은 `LTRB -> XYXY`와 center-ness 계약을 사용하는지 확인한다.

```cpp
#include <array>
#include <cassert>
#include <cmath>
#include <iomanip>
#include <iostream>

using Box = std::array<double, 4>;

Box encode(const std::array<double, 2>& point, const Box& box) {
    return {point[0] - box[0], point[1] - box[1],
            box[2] - point[0], box[3] - point[1]};
}

Box decode(const std::array<double, 2>& point, const Box& distance) {
    return {point[0] - distance[0], point[1] - distance[1],
            point[0] + distance[2], point[1] + distance[3]};
}

double centerness(const Box& distance) {
    const double horizontal = std::min(distance[0], distance[2]) /
                              std::max(distance[0], distance[2]);
    const double vertical = std::min(distance[1], distance[3]) /
                            std::max(distance[1], distance[3]);
    return std::sqrt(horizontal * vertical);
}

int main() {
    const std::array<double, 2> point{12.0, 4.0};
    const Box box{8.0, 0.0, 16.0, 16.0};
    const Box distance = encode(point, box);
    const Box recovered = decode(point, distance);
    for (int index = 0; index < 4; ++index) {
        assert(std::abs(recovered[index] - box[index]) < 1e-12);
    }
    assert(std::abs(centerness(distance) - std::sqrt(1.0 / 3.0)) < 1e-12);
    std::cout << std::fixed << std::setprecision(6)
              << distance[0] << " " << distance[1] << " "
              << distance[2] << " " << distance[3] << " "
              << centerness(distance) << "\n";
}
```

예상 출력은 `4.000000 4.000000 4.000000 12.000000 0.577350`이다.

## 8. C# 예제: 같은 배포 계약

다음은 **실행 가능한 C# 예제**다.

```csharp
using System;

public static class FcosGolden
{
    static double[] Encode(double[] point, double[] box)
    {
        return new[] {
            point[0] - box[0], point[1] - box[1],
            box[2] - point[0], box[3] - point[1]
        };
    }

    static double[] Decode(double[] point, double[] distance)
    {
        return new[] {
            point[0] - distance[0], point[1] - distance[1],
            point[0] + distance[2], point[1] + distance[3]
        };
    }

    static double Centerness(double[] distance)
    {
        double horizontal = Math.Min(distance[0], distance[2]) /
                            Math.Max(distance[0], distance[2]);
        double vertical = Math.Min(distance[1], distance[3]) /
                          Math.Max(distance[1], distance[3]);
        return Math.Sqrt(horizontal * vertical);
    }

    public static void Main()
    {
        double[] point = { 12.0, 4.0 };
        double[] box = { 8.0, 0.0, 16.0, 16.0 };
        double[] distance = Encode(point, box);
        double[] recovered = Decode(point, distance);
        for (int index = 0; index < 4; ++index)
        {
            if (Math.Abs(recovered[index] - box[index]) >= 1e-12)
                throw new Exception("round trip failed");
        }
        double center = Centerness(distance);
        if (Math.Abs(center - Math.Sqrt(1.0 / 3.0)) >= 1e-12)
            throw new Exception("center-ness failed");
        Console.WriteLine(
            $"{distance[0]:F6} {distance[1]:F6} " +
            $"{distance[2]:F6} {distance[3]:F6} {center:F6}"
        );
    }
}
```

Python, C++, C#이 같은 다섯 숫자를 출력하면 최소한 좌표 순서와 center-ness 식이 일치한다. 실제 consumer 테스트에는 ONNX 출력 fixture를 넣어 동일한 decode와 NMS 결과도 비교한다.

## 9. framework 간 shape·layout·dtype 대응

| 의미 | PyTorch 학습 | ONNX tensor | C++ consumer | C# consumer |
| --- | --- | --- | --- | --- |
| 입력 image | `[N,3,H,W]`, `float32` | `NCHW`, `float32` | contiguous `NCHW` | `DenseTensor<float>` 등 |
| class raw | `[N,K,H_l,W_l]` | level별 또는 concat | `[N,Q,K]`로 변환 | `[N,Q,K]`로 변환 |
| box raw | `[N,4,H_l,W_l]` | 단위 metadata 필요 | `[N,Q,4]`, `LTRB` | `[N,Q,4]`, `LTRB` |
| center raw | `[N,1,H_l,W_l]` | logits 유지 | sigmoid 후 결합 | sigmoid 후 결합 |
| point | `[Q,2]`, `XY` | graph 내부 또는 상수 | `float32 XY` | `float XY` |
| decode 결과 | `[M,4]`, `XYXY` | pixel 좌표 권장 | half-open 여부 고정 | half-open 여부 고정 |
| class label | `int64`, `1...K` | output은 `int64` 또는 `int32` | API에 맞춰 변환 | `long` 또는 `int` |

주의할 차이는 다음과 같다.

- OpenCV image는 기본 `HWC/BGR/uint8`이므로 RGB 변환, scale, mean/std, transpose가 필요하다.
- ONNX Runtime C#과 C++의 tensor storage는 row-major지만 shape metadata만 믿고 `NCHW`를 `NHWC`로 읽으면 안 된다.
- 학습의 `float16` box decode는 큰 좌표에서 정밀도를 잃을 수 있다. 후처리는 `float32`로 승격한다.
- NMS API가 `XYXY`, `XYWH`, inclusive pixel 좌표 중 무엇을 기대하는지 확인한다.
- label을 0-based로 바꾸는 consumer라면 모델의 `1...K`와 API의 `0...K-1` 변환을 경계에서 한 번만 한다.

## 10. 테스트와 디버깅 전략

### 10.1 단위 테스트 우선순위

1. 비정사각 feature에서 point 순서와 첫·마지막 좌표를 확인한다.
2. `encode -> decode` round trip을 여러 임의 박스에서 확인한다.
3. 박스 경계, center 영역 경계, regression range 경계의 부등호를 고정한다.
4. 큰 GT 안의 작은 GT가 최소 면적 tie-break로 선택되는지 본다.
5. GT 0개, point 0개, positive 0개가 유한 loss를 내는지 본다.
6. ignore padding point가 classification loss에 참여하지 않는지 본다.
7. level 순서를 바꾸면 테스트가 실패하도록 stride와 range를 golden으로 묶는다.
8. decode 뒤 score threshold와 NMS가 class별로 독립인지 확인한다.
9. 같은 seed의 두 학습 run이 loss history와 parameter를 재현하는지 확인한다.

### 10.2 증상에서 원인으로 가는 표

| 증상 | 우선 의심 | 확인 방법 |
| --- | --- | --- |
| 박스가 대각선으로 뒤집힘 | `x,y`와 `row,column` 혼동 | 비정사각 feature golden |
| coarse level 박스가 지나치게 작음 | cell 단위를 pixel로 decode | stride를 한 번만 곱했는지 확인 |
| positive가 거의 없음 | range 또는 center radius 단위 오류 | mask별 후보 수를 로그로 분해 |
| 작은 객체 recall이 낮음 | FPN level 순서·range 경계 | 객체 크기별 positive histogram |
| loss가 image마다 크게 출렁임 | point 수로 `mean` 또는 local positive 정규화 | global $N_+$ 로그 |
| class score는 높은데 박스 품질이 낮음 | center score 미결합 또는 target 오류 | class·center·IoU 상관 비교 |
| NMS 후 다른 class도 사라짐 | class-agnostic NMS 사용 | class별 fixture |
| padding 영역에 검출 발생 | valid image mask 누락 | padded location score 검사 |

### 10.3 gradient 경계 테스트

- target assigner는 GT로부터 만든 불연속 label이므로 일반적으로 autograd graph 밖에 둔다.
- classification tower에는 class loss만, regression tower에는 box와 center loss가 흐르는지 hook으로 확인한다.
- `positive.any()`가 거짓일 때 Python 분기가 distributed compile graph를 불안정하게 만들면 masked tensor 연산으로 바꾼다.
- regression에 `ReLU`를 쓰면 0 이하 pre-activation의 gradient가 막힐 수 있다. `exp`, learnable scale, `softplus`와 ablation한다.

한 번에 한 축만 바꾸고 AP뿐 아니라 assigner 통계를 함께 기록한다.

| 실험 | 고정할 것 | 함께 볼 지표 |
| --- | --- | --- |

| range 경계 변경 | FPN, resize | level별 positive histogram |

재현 manifest에는 다음을 저장한다.

- FPN level 순서, stride, range, center radius
- loss 종류와 normalization, distributed world size
- seed, deterministic flag, library·driver version
- checkpoint SHA와 optimizer·scheduler state
- score 결합식, threshold, pre-NMS top-k, NMS threshold

## 12. 성능·메모리·수치 안정성

### 12.1 assigner 메모리

완전한 거리 tensor $D$는 $QG4$개 원소다. `float32`일 때 대략 다음 바이트를 쓴다.

$$
\operatorname{bytes}(D)=4QG\times4
$$

$Q=100{,}000$, $G=200$이면 거리 tensor만 약 320 MB다. 여기에 mask와 후보 면적이 추가된다. 대응 방법은 다음과 같다.

- image별로 처리해 batch 축의 padded GT 낭비를 줄인다.
- point 또는 GT 축을 chunk한다.
- `LTRB` 네 장을 모두 오래 보관하지 않고 mask를 만든 뒤 필요한 target만 gather한다.
- CPU assigner와 GPU assigner의 end-to-end latency를 실제 dataloader 조건에서 비교한다.
- empty GT는 broadcast 전에 빠르게 반환한다.

### 12.2 mixed precision

- Focal Loss는 확률에 `log`를 직접 적용하지 말고 logits 기반 BCE를 쓴다.
- IoU의 작은 union과 center-ness 분모는 `clamp_min`한다.
- `float16`의 `inf` mask와 큰 거리 곱셈을 확인하고 assigner는 필요하면 `float32`로 유지한다.
- `exp` regression은 overflow할 수 있으므로 pre-activation clamp 또는 scale parameter를 검토한다.
- loss가 finite여도 decoded box가 finite인지 optimizer step마다 별도 표본 검사한다.

### 12.3 추론 비용

NMS에 넘길 후보 수는 latency를 좌우한다. 일반적인 순서는 다음과 같다.

1. sigmoid class와 center score를 결합한다.
2. level별 score threshold를 적용한다.
3. level별 pre-NMS top-k를 선택한다.
4. decode하고 image bounds로 clip한다.
5. 작은 박스를 제거한다.
6. class별 batched NMS를 적용한다.
7. image당 최대 검출 수를 자른다.

threshold 전에 모든 class의 모든 box를 materialize하면 $QK$ 메모리가 커진다. top-k index를 먼저 구하고 필요한 point와 class만 decode하는 편이 낫다.

## 13. 실무 실패 사례

### 실패 1: augmentation 뒤 빈 박스를 남김

random crop 뒤 폭이나 높이가 0인 GT가 남았다. 면적 0이 최소 면적 tie-break에서 모든 point를 빼앗고 center-ness가 `0/0`이 되었다.

해결은 augmentation 직후 `x1 > x0`, `y1 > y0`, finite 좌표, 최소 크기를 검사하고 제거한 수를 로그로 남기는 것이다.

### 실패 2: FPN dictionary 순서가 바뀜

backbone refactor 뒤 feature가 `P5,P4,P3` 순서로 반환됐지만 stride config는 `8,16,32`였다. shape는 모두 합법이어서 crash 없이 성능만 무너졌다.

해결은 level 이름을 key로 stride·range와 결합하고, 각 level 첫 point와 feature shape를 checkpoint metadata에 기록하는 것이다.

### 실패 3: 분산 worker별 정규화

어떤 GPU는 crowded image, 다른 GPU는 empty image를 받아 local positive 수가 크게 달랐다. worker별로 loss를 나눈 뒤 gradient를 평균하자 sample 기여가 의도와 달라졌다.

해결은 positive count를 all-reduce하고 world size 정책까지 포함해 전역 분모를 검증하는 것이다.

### 실패 4: 배포에서 score 식이 달라짐

Python 평가기는 $\sqrt{p_{cls}p_{ctr}}$, C# consumer는 $p_{cls}p_{ctr}$를 threshold했다. 순위는 같아도 절대 score가 달라 threshold와 calibration이 깨졌다.

해결은 score 결합을 graph 안에 넣거나 metadata와 공통 fixture로 고정하는 것이다.

### 실패 5: class-agnostic NMS로 서로 다른 객체 제거

같은 위치의 사람과 자전거 박스가 높은 IoU를 가져 class-agnostic NMS에서 하나가 사라졌다. metric code는 class별 NMS를 사용해 offline과 production 결과가 달랐다.

해결은 NMS 정책을 모델 버전의 일부로 관리하고 같은 raw output fixture를 모든 runtime에서 비교하는 것이다.

## 14. 배포 관점

### 14.1 export 경계 선택

두 가지 경계가 있다.

| 경계 | 장점 | 위험 |
| --- | --- | --- |
| raw logits·distance 출력 | threshold와 NMS를 runtime에 맞게 최적화 | consumer마다 decode·score가 달라질 수 있음 |
| decode·NMS 포함 출력 | 단일 의미 계약 | dynamic shape, NMS op 지원, threshold 변경이 어려움 |

어느 경계를 택하든 다음 metadata를 저장한다.

- input layout, color order, normalization, resize·padding
- level names, strides, flatten order
- box unit과 format, 좌표 경계 규칙
- score 결합식과 class label offset
- pre-NMS top-k, threshold, NMS 종류와 threshold
- dynamic height·width 지원 범위
- opset, runtime, precision, calibration dataset hash

### 14.2 배포 골든 테스트

1. 비정사각 입력 한 장을 고정한다.
2. Python에서 level별 raw tensor hash와 shape를 저장한다.
3. point, score, decode box의 중간 fixture를 저장한다.
4. C++과 C#에서 top-k index, class, box, score를 tolerance 안에서 비교한다.
5. NMS tie score의 안정 순서를 명시한다.
6. empty detection과 최대 detection을 모두 테스트한다.
7. CPU `float32`, GPU `float32`, 선택한 reduced precision의 허용 오차를 따로 둔다.

## 17. 해답

### 해답 1

$$
x=8(2+0.5)=20,\qquad y=8(1+0.5)=12
$$

따라서 `(20,12)`다.

### 해답 2

$$
(l,t,r,b)=(16,8,8,24)
$$

$$
c^*=\sqrt{\frac{8}{16}\frac{8}{24}}
=\sqrt{\frac{1}{6}}
\approx0.408248
$$

### 해답 3

면적이 더 작은 GT B를 선택한다. 두 GT의 class label, B에 대한 `LTRB`, B에서 계산한 center-ness가 target이 된다.

### 해답 4

빈 image는 실제 배경 표본이다. classification negative를 제거하면 false positive를 억제할 학습 신호를 잃는다. 반면 box와 center-ness는 대응하는 positive target이 없으므로 0이 맞다. graph 연결을 유지한 0을 사용하면 distributed·compiled 경로가 안정적이다.

### 해답 5

실제 pixel distance는 `(64,96,128,160)`이어야 한다. C++이 `(2,3,4,5)`를 그대로 pixel로 쓰면 폭과 높이가 약 32배 작은 박스를 만든다. 단위를 metadata와 fixture로 고정해야 한다.

### 해답 6

$$
50{,}000\times100\times4\times4
=80{,}000{,}000\ \text{bytes}
$$

약 80 MB다. boolean mask와 후보 면적 tensor는 별도다.

## 핵심 요약

1. FCOS의 구현 핵심은 anchor 부재가 아니라 point·stride·range의 일관된 좌표 계약이다.
2. assigner는 `inside -> center sampling -> range -> 최소 면적` 순서로 후보를 줄인다.
3. class, box, center-ness, point는 같은 level·spatial flatten 순서를 가져야 한다.
4. classification은 모든 유효 point, box와 center-ness는 positive만 학습한다.
5. empty image에서도 negative classification signal과 유한한 graph를 유지한다.
6. decode 뒤 class와 center score를 같은 식으로 결합하고 class별 NMS를 적용한다.
7. NumPy oracle과 C++·C# fixture가 좌표·단위·dtype 오류를 빠르게 드러낸다.
8. global positive 정규화, chunked assigner, pre-NMS top-k가 분산 안정성과 메모리·지연시간을 좌우한다.
9. score 식, label offset, box unit, NMS 정책은 모델 artifact의 일부다.
